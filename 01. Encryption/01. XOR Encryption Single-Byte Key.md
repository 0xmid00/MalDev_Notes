## XOR Encryption using Single-Byte Key

Applies XOR to each byte of the data using a single-byte key.

**Usage**

Call `XorByOneKey` with the data buffer, its size, and a single-byte key.

- `IN PBYTE pShellcode` Base address of the data to encrypt.
- `IN SIZE_T sShellcodeSize` Size of the data in bytes.
- `IN BYTE bKey` Single-byte XOR key.

**Return Value**

`VOID` Modifies `pShellcode` in place and does not return a value.

**External Files**

- `Windows.h` `BYTE`, `PBYTE`, `SIZE_T`, `VOID`

### Code

```c
#include <Windows.h>

/*
    XOR each byte of the data with a single-byte key.

    - pShellcode      : Base address of the data to encrypt.
    - sShellcodeSize  : Size of the data in bytes.
    - bKey            : Single-byte XOR key.
*/
VOID XorByOneKey(
    IN PBYTE pShellcode,
    IN SIZE_T sShellcodeSize,
    IN BYTE bKey
)
{
    if (pShellcode == NULL || sShellcodeSize == 0)
        return;

    for (size_t i = 0; i < sShellcodeSize; i++)
    {
        pShellcode[i] = pShellcode[i] ^ bKey;
    }
}
```

**Example**

```c
unsigned char pShellcode[]   = { 0xFC, 0x48, 0x83, 0xE4, 0xF0, 0xE5 };
SIZE_T        sShellcodeSize = sizeof(pShellcode);
BYTE          bKey           = 0x5A;

// Encrypt the payload in place. XOR is symmetric, so the same call
// with the same key reverses it (see the matching Decryption note).
XorByOneKey(pShellcode, sShellcodeSize, bKey);
```
