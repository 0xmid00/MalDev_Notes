## AES256-CBC Payload Decryption via Tiny-AES

Decrypts an AES256-CBC encrypted payload buffer in place using the [tiny-AES-c](https://github.com/kokke/tiny-AES-c) library without any WinAPI cryptographic calls. `AES_init_ctx_iv` reinitialises the cipher context with the original key and IV, and `AES_CBC_decrypt_buffer` recovers the plaintext directly in the supplied ciphertext buffer. The input buffer must already be a multiple of 16 bytes, as produced by the matching encryption function.

**Usage**

Call `TinyAesDecryptPayload` with the original 32-byte key, the original 16-byte IV, and the ciphertext buffer and its size. Because `AES_CBC_decrypt_buffer` operates in place, `pCipherTextData` contains the recovered plaintext after a successful call.

- `IN PBYTE pKey`  32-byte AES256 key; must match the key used during encryption.
- `IN PBYTE pIv`  16-byte IV; must match the IV used during encryption.
- `IN/OUT PBYTE pCipherTextData`  Base address of the encrypted buffer; overwritten in place with the decrypted plaintext.
- `IN SIZE_T sCipherTextSize`  Size of `pCipherTextData` in bytes; must be a multiple of 16.

**Return Value**

`BOOL`  Returns `TRUE` on success or `FALSE` if any required pointer is `NULL` or if the buffer size is not a multiple of 16 bytes.

**External Files**

- [aes.h](<0.files/18.AES Encryption via Tiny-AES/aes.h>) / [aes.c](<0.files/18.AES Encryption via Tiny-AES/aes.c>)  ⚠️ Must be added manually — set `#define AES256 1` in `aes.h` and add `aes.c` to the project. Provides `AES_init_ctx_iv()`, `AES_CBC_decrypt_buffer()`.
- `windows.h`  `PBYTE`, `BOOL`, `SIZE_T`, `IN`, `OUT`

### Code

```c
#include <windows.h>
#include "aes.h"

// aes.h must have AES256 enabled:
//   //#define AES128 1
//   //#define AES192 1
//   #define AES256 1

#define KEYSIZE   32    // 32-byte key for AES256.
#define IVSIZE    16    // 16-byte IV for CBC mode.


BOOL TinyAesDecryptPayload(IN PBYTE pKey, IN PBYTE pIv, IN OUT PBYTE pCipherTextData, IN SIZE_T sCipherTextSize)
{
    if (pKey == NULL || pIv == NULL || pCipherTextData == NULL || sCipherTextSize == 0)
        return FALSE;

    // Tiny-AES does not support padding; the buffer must be a multiple of 16 bytes.
    if (sCipherTextSize % 16 != 0)
        return FALSE;

    struct AES_ctx ctx;

    // Reinitialise the Tiny-AES context with the same key and IV used during encryption.
    AES_init_ctx_iv(
        &ctx,   // AES context structure to initialise.
        pKey,   // 32-byte AES256 key; must match the encryption key.
        pIv     // 16-byte IV; must match the encryption IV.
    );

    // Decrypt the buffer in place; plaintext overwrites the ciphertext.
    AES_CBC_decrypt_buffer(
        &ctx,               // Initialised AES context.
        pCipherTextData,    // Buffer to decrypt; modified in place.
        sCipherTextSize     // Size in bytes; must be a multiple of 16.
    );

    return TRUE;
}
```

**Example**

```c
#include "aes.h"  // From the 18.AES Encryption via Tiny-AES/ asset folder.

unsigned char pKey[32]       = { 0 };  // Must match the encryption key.
unsigned char pIv[16]        = { 0 };  // Must match the encryption IV.
unsigned char pCipherText[] = { 0x12, 0x34, 0x56, 0x78, 0x9A, 0xBC, 0xCD, 0xEF,
                                0x01, 0x23, 0x45, 0x67, 0x89, 0xAB, 0xCD, 0xEF };  // 16 bytes.

// Decrypt the buffer in place — plaintext overwrites the ciphertext.
TinyAesDecryptPayload(pKey, pIv, pCipherText, sizeof(pCipherText));
```
