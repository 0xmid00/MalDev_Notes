## XOR Decryption using Repeating Key

Reverses the repeating-key XOR transformation by applying the same multi-byte key in the same sequence.

**Usage**

Call `XorByInputKey` with the encrypted data, its size, the same key, and the key size used during encryption.

- `IN PBYTE pShellcode` Base address of the encrypted data.
- `IN SIZE_T sShellcodeSize` Size of the data in bytes.
- `IN PBYTE bKey` Address of the same multi-byte XOR key.
- `IN SIZE_T sKeySize` Size of the key in bytes.

**Return Value**

`VOID` Restores the original data in `pShellcode` and does not return a value.

**External Files**

- `Windows.h` `BYTE`, `PBYTE`, `SIZE_T`, `VOID`

### Code

```c
#include <Windows.h>

/*
    XOR each byte using the same multi-byte key repeatedly.

    XOR is reversible, so applying the identical key sequence
    again restores the original data.

    - pShellcode      : Base address of the encrypted data.
    - sShellcodeSize  : Size of the data in bytes.
    - bKey            : Address of the same key used for encryption.
    - sKeySize        : Size of the key in bytes.
*/
VOID XorByInputKey(
    IN PBYTE pShellcode,
    IN SIZE_T sShellcodeSize,
    IN PBYTE bKey,
    IN SIZE_T sKeySize
)
{
    if (pShellcode == NULL || bKey == NULL ||
        sShellcodeSize == 0 || sKeySize == 0)
        return;

    for (size_t i = 0, j = 0; i < sShellcodeSize; i++, j++)
    {
        if (j >= sKeySize)
        {
            j = 0;
        }

        pShellcode[i] = pShellcode[i] ^ bKey[j];
    }
}
```

**Example**

```c
// Payload produced by the Encryption note (plaintext XOR repeating 4-byte key).
unsigned char pShellcode[]   = { 0xA6, 0xED, 0xD9, 0x41, 0xAA, 0x40 };
SIZE_T        sShellcodeSize = sizeof(pShellcode);

unsigned char bKey[] = { 0x5A, 0xA5, 0x5A, 0xA5 };  // Same key used during encryption.
SIZE_T        sKeySize = sizeof(bKey);

// Re-apply the same repeating-key XOR to recover the original plaintext.
XorByInputKey(pShellcode, sShellcodeSize, bKey, sKeySize);
```
