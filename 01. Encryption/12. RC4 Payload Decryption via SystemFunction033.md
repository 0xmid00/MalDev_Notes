## RC4 Payload Decryption via SystemFunction033

Decrypts an RC4-encrypted payload buffer in place using the undocumented Windows NTAPI `SystemFunction033` exported from `Advapi32.dll`. Because RC4 is a symmetric stream cipher, the decryption call is structurally identical to encryption: the same API, the same `USTRING` layout, and the same key recover the original plaintext.

**Usage**

Call `Rc4DecryptionViaSystemFunc033` with the key, the encrypted payload buffer, and their respective sizes. Because `SystemFunction033` operates in place, `pPayloadData` holds the decrypted plaintext after a successful call.

- `IN PBYTE pRc4Key`  The RC4 key originally used during encryption; must match exactly.
- `IN/OUT PBYTE pPayloadData`  Base address of the ciphertext buffer; overwritten in place with the decrypted output.
- `IN DWORD dwRc4KeySize`  Size of `pRc4Key` in bytes.
- `IN DWORD sPayloadSize`  Size of `pPayloadData` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` on success or `FALSE` if `SystemFunction033` returns a non-zero `NTSTATUS` error code.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `DWORD`, `NTSTATUS`, `PVOID`, `NTAPI`, `IN`, `OUT`, `LoadLibraryA()`, `GetProcAddress()`
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>

typedef struct
{
    DWORD Length;           // Size of the buffer to decrypt.
    DWORD MaximumLength;    // Maximum size of the buffer; typically equal to Length.
    PVOID Buffer;           // Base address of the buffer to decrypt.

} USTRING;

typedef NTSTATUS(NTAPI* fnSystemFunction033)(
    struct USTRING* Data,   // USTRING describing the buffer to decrypt.
    struct USTRING* Key     // USTRING describing the key used for decryption.
);


BOOL Rc4DecryptionViaSystemFunc033(IN PBYTE pRc4Key, IN OUT PBYTE pPayloadData, IN DWORD dwRc4KeySize, IN DWORD sPayloadSize)
{
    NTSTATUS STATUS = NULL;

    USTRING Key = {
        .Buffer        = pRc4Key,       // RC4 key material; must match the key used during encryption.
        .Length        = dwRc4KeySize,
        .MaximumLength = dwRc4KeySize
    };

    USTRING Data = {
        .Buffer        = pPayloadData,  // Ciphertext buffer; overwritten in place with plaintext.
        .Length        = sPayloadSize,
        .MaximumLength = sPayloadSize
    };

    fnSystemFunction033 SystemFunction033 = (fnSystemFunction033)GetProcAddress(
        LoadLibraryA("Advapi32"),   // DLL that exports SystemFunction033.
        "SystemFunction033"         // Undocumented NTAPI RC4 routine; identical call path for decryption.
    );

    if ((STATUS = SystemFunction033(&Data, &Key)) != 0x0) {
        printf("[!] SystemFunction033 FAILED With Error: 0x%0.8X \n", STATUS);
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
unsigned char pRc4Key[]      = { 0x5A, 0xA5, 0x5A, 0xA5 };  // Must match the encryption key.
unsigned char pPayloadData[] = { 0x12, 0x34, 0x56, 0x78, 0x9A, 0xBC };  // Output of the Encryption note.

// Decrypt the payload in place — pPayloadData becomes the plaintext.
if (!Rc4DecryptionViaSystemFunc033(pRc4Key, pPayloadData,
                                   sizeof(pRc4Key), sizeof(pPayloadData))) {
    printf("[!] Rc4DecryptionViaSystemFunc033 failed\n");
}
```
