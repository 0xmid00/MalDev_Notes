## RC4 Payload Encryption via SystemFunction033

Encrypts a payload buffer in place using the undocumented Windows NTAPI `SystemFunction033` exported from `Advapi32.dll`. The function resolves the API address at runtime via `GetProcAddress`, populates two `USTRING` structures for the key and data, and calls `SystemFunction033` directly. `SystemFunction033` takes the same parameters as `SystemFunction032` but initialises the `USTRING` structures with the key first.

**Usage**

Call `Rc4EncryptionViaSystemFunc033` with the key, the plaintext payload buffer, and their respective sizes. Because `SystemFunction033` operates in place, `pPayloadData` holds the encrypted result after a successful call.

- `IN PBYTE pRc4Key`  The RC4 key used during encryption.
- `IN/OUT PBYTE pPayloadData`  Base address of the plaintext buffer; overwritten in place with the encrypted output.
- `IN DWORD dwRc4KeySize`  Size of `pRc4Key` in bytes.
- `IN DWORD sPayloadSize`  Size of `pPayloadData` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` on success or `FALSE` if `SystemFunction033` returns a non-zero `NTSTATUS` error code.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `DWORD`, `NTSTATUS`, `PVOID`, `NTAPI`, `IN`, `OUT`, `LoadLibraryA()`, `GetProcAddress()`
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>

typedef struct
{
    DWORD Length;           // Size of the buffer to encrypt.
    DWORD MaximumLength;    // Maximum size of the buffer; typically equal to Length.
    PVOID Buffer;           // Base address of the buffer to encrypt.

} USTRING;

typedef NTSTATUS(NTAPI* fnSystemFunction033)(
    struct USTRING* Data,   // USTRING describing the buffer to encrypt.
    struct USTRING* Key     // USTRING describing the key used for encryption.
);


BOOL Rc4EncryptionViaSystemFunc033(IN PBYTE pRc4Key, IN OUT PBYTE pPayloadData, IN DWORD dwRc4KeySize, IN DWORD sPayloadSize)
{
    NTSTATUS STATUS = NULL;

    USTRING Key = {
        .Buffer        = pRc4Key,       // RC4 key material used to drive the cipher.
        .Length        = dwRc4KeySize,
        .MaximumLength = dwRc4KeySize
    };

    USTRING Data = {
        .Buffer        = pPayloadData,  // Plaintext buffer; overwritten in place with ciphertext.
        .Length        = sPayloadSize,
        .MaximumLength = sPayloadSize
    };

    fnSystemFunction033 SystemFunction033 = (fnSystemFunction033)GetProcAddress(
        LoadLibraryA("Advapi32"),   // DLL that exports SystemFunction033.
        "SystemFunction033"         // Undocumented NTAPI RC4 routine.
    );

    if ((STATUS = SystemFunction033(&Data, &Key)) != 0x0) {
        printf("[!] SystemFunction033 FAILED With Error: 0x%0.8X \n", STATUS);
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
unsigned char pRc4Key[]      = { 0x5A, 0xA5, 0x5A, 0xA5 };
unsigned char pPayloadData[] = { 0xFC, 0x48, 0x83, 0xE4, 0xF0, 0xE5 };

// Encrypt the payload in place — pPayloadData becomes the ciphertext.
if (!Rc4EncryptionViaSystemFunc033(pRc4Key, pPayloadData,
                                   sizeof(pRc4Key), sizeof(pPayloadData))) {
    printf("[!] Rc4EncryptionViaSystemFunc033 failed\n");
}
```
