## XOR Encryption using Index-Based Key

Applies XOR to each byte using the base key combined with the current byte index.

**Usage**

Call `XorByiKeys` with the data buffer, its size, and the base key.

- `IN PBYTE pShellcode` Base address of the data to encrypt.
- `IN SIZE_T sShellcodeSize` Size of the data in bytes.
- `IN BYTE bKey` Base byte used to derive the XOR value for each position.

**Return Value**

`VOID` Modifies `pShellcode` in place and does not return a value.

**External Files**

- `Windows.h` `BYTE`, `PBYTE`, `SIZE_T`, `VOID`

### Code

```c
#include <Windows.h>

/*
    XOR each byte using the key combined with its index.

    - pShellcode      : Base address of the data to encrypt.
    - sShellcodeSize  : Size of the data in bytes.
    - bKey            : Base byte used to derive the XOR value.
*/
VOID XorByiKeys(
    IN PBYTE pShellcode,
    IN SIZE_T sShellcodeSize,
    IN BYTE bKey
)
{
    if (pShellcode == NULL || sShellcodeSize == 0)
        return;

    for (size_t i = 0; i < sShellcodeSize; i++)
    {
        pShellcode[i] = pShellcode[i] ^ (bKey + i);
    }
}
```

**Example**

```c
unsigned char pShellcode[]   = { 0xFC, 0x48, 0x83, 0xE4, 0xF0, 0xE5 };
SIZE_T        sShellcodeSize = sizeof(pShellcode);
BYTE          bKey           = 0x5A;

// Encrypt the payload in place using an index-derived key per byte.
// The same call with the same base key reverses it (see the Decryption note).
XorByiKeys(pShellcode, sShellcodeSize, bKey);
```
