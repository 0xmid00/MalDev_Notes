## RC4 Payload Decryption - Method 1

Decrypts an RC4-encrypted payload buffer. Because RC4 is a symmetric stream cipher, the same `rc4Init` and `rc4Cipher` functions used for encryption are applied in identical fashion to recover the original plaintext.

**Usage**

Call `Rc4DecryptPayload` with the key and its size, the ciphertext buffer to decrypt, the output plaintext buffer, and the payload size.

- `IN PBYTE pRc4Key`  The RC4 key originally used during encryption; must match exactly.
- `IN PBYTE pCiphertext`  Base address of the encrypted payload buffer to decrypt.
- `OUT PBYTE pPlaintext`  Caller-allocated buffer that receives the decrypted output; must be at least `sPayloadSize` bytes.
- `IN DWORD dwRc4KeySize`  Size of `pRc4Key` in bytes.
- `IN DWORD sPayloadSize`  Size of `pCiphertext` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` on success or `FALSE` if a required pointer argument is `NULL`.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `DWORD`, `IN`, `OUT`
- `string.h`  `strlen()`

### Code

```c
#include <windows.h>
#include <string.h>

typedef struct
{
    unsigned int  i;
    unsigned int  j;
    unsigned char s[256];

} Rc4Context;


void rc4Init(Rc4Context* context, const unsigned char* key, size_t length)
{
    unsigned int  i;
    unsigned int  j;
    unsigned char temp;

    if (context == NULL || key == NULL)
        return;

    context->i = 0;
    context->j = 0;

    for (i = 0; i < 256; i++)
        context->s[i] = i;

    for (i = 0, j = 0; i < 256; i++)
    {
        j = (j + context->s[i] + key[i % length]) % 256;

        temp           = context->s[i];
        context->s[i] = context->s[j];
        context->s[j] = temp;
    }
}


void rc4Cipher(Rc4Context* context, const unsigned char* input, unsigned char* output, size_t length)
{
    unsigned char  temp;
    unsigned int   i = context->i;
    unsigned int   j = context->j;
    unsigned char* s = context->s;

    while (length > 0)
    {
        i = (i + 1) % 256;
        j = (j + s[i]) % 256;

        temp = s[i];
        s[i] = s[j];
        s[j] = temp;

        if (input != NULL && output != NULL)
        {
            *output = *input ^ s[(s[i] + s[j]) % 256];
            input++;
            output++;
        }

        length--;
    }

    context->i = i;
    context->j = j;
}


BOOL Rc4DecryptPayload(IN PBYTE pRc4Key, IN PBYTE pCiphertext, OUT PBYTE pPlaintext, IN DWORD dwRc4KeySize, IN DWORD sPayloadSize)
{
    if (pRc4Key == NULL || pCiphertext == NULL || pPlaintext == NULL)
        return FALSE;

    Rc4Context ctx = { 0 };

    rc4Init(
        &ctx,           // Pointer to the Rc4Context structure to initialize.
        pRc4Key,        // Key used to rebuild the S-box permutation for decryption.
        dwRc4KeySize    // Length of the key in bytes.
    );

    rc4Cipher(
        &ctx,           // Initialized RC4 context carrying the S-box state.
        pCiphertext,    // Input buffer containing the encrypted payload.
        pPlaintext,     // Output buffer that receives the decrypted plaintext.
        sPayloadSize    // Number of bytes to decrypt.
    );

    return TRUE;
}
```

**Example**

```c
unsigned char pRc4Key[]     = { 0x5A, 0xA5, 0x5A, 0xA5 };  // Must match the encryption key.
unsigned char pCiphertext[] = { 0x12, 0x34, 0x56, 0x78, 0x9A, 0xBC };  // Output of the Encryption note.
unsigned char pPlaintext[6] = { 0 };

// Decrypt the ciphertext back into the original plaintext.
if (!Rc4DecryptPayload(pRc4Key, pCiphertext, pPlaintext,
                       sizeof(pRc4Key), sizeof(pCiphertext))) {
    printf("[!] Rc4DecryptPayload failed\n");
}
```
