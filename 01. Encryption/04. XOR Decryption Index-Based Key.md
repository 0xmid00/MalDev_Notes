## XOR Decryption using Index-Based Key

Reverses the index-based XOR transformation by generating the same key value for each byte position.

**Usage**

Call `XorByiKeys` with the encrypted data, its size, and the same base key used for encryption.

- `IN PBYTE pShellcode` Base address of the encrypted data.
- `IN SIZE_T sShellcodeSize` Size of the data in bytes.
- `IN BYTE bKey` The same base key used during encryption.

**Return Value**

`VOID` Restores the original data in `pShellcode` and does not return a value.

**External Files**

- `Windows.h` `BYTE`, `PBYTE`, `SIZE_T`, `VOID`

### Code

```c
#include <Windows.h>

/*
    XOR each byte using the same index-derived key.

    The same transformation reverses the encryption:
        (data ^ (key + i)) ^ (key + i) = data

    - pShellcode      : Base address of the encrypted data.
    - sShellcodeSize  : Size of the data in bytes.
    - bKey            : The same base key used during encryption.
*/
VOID XorByiKeys(
    IN PBYTE pShellcode,
    IN SIZE_T sShellcodeSize,
    IN BYTE bKey
)
{
    if (pShellcode == NULL || sShellcodeSize == 0)
        return;

    for (size_t i = 0; i < sShellcodeSize; i++)
    {
        pShellcode[i] = pShellcode[i] ^ (bKey + i);
    }
}
```

**Example**

```c
// Payload produced by the Encryption note (plaintext XOR (0x5A + i)).
unsigned char pShellcode[]   = { 0xA6, 0x13, 0xDF, 0xB9, 0xAE, 0xBA };
SIZE_T        sShellcodeSize = sizeof(pShellcode);
BYTE          bKey           = 0x5A;  // Must match the base key used during encryption.

// Re-apply the same index-derived XOR to recover the original plaintext.
XorByiKeys(pShellcode, sShellcodeSize, bKey);
```
