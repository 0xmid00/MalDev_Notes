## XOR Encryption using Repeating Key

Applies XOR to each byte using the bytes of a multi-byte key repeatedly.

**Usage**

Call `XorByInputKey` with the data buffer, its size, the key buffer, and the key size.

- `IN PBYTE pShellcode` Base address of the data to encrypt.
- `IN SIZE_T sShellcodeSize` Size of the data in bytes.
- `IN PBYTE bKey` Address of the multi-byte XOR key.
- `IN SIZE_T sKeySize` Size of the key in bytes.

**Return Value**

`VOID` Modifies `pShellcode` in place and does not return a value.

**External Files**

- `Windows.h` `BYTE`, `PBYTE`, `SIZE_T`, `VOID`

### Code

```c
#include <Windows.h>

/*
    XOR each byte using a multi-byte key repeatedly.

    - pShellcode      : Base address of the data to encrypt.
    - sShellcodeSize  : Size of the data in bytes.
    - bKey            : Address of the key bytes.
    - sKeySize        : Size of the key in bytes.
*/
VOID XorByInputKey(
    IN PBYTE pShellcode,
    IN SIZE_T sShellcodeSize,
    IN PBYTE bKey,
    IN SIZE_T sKeySize
)
{
    if (pShellcode == NULL || bKey == NULL ||
        sShellcodeSize == 0 || sKeySize == 0)
        return;

    for (size_t i = 0, j = 0; i < sShellcodeSize; i++, j++)
    {
        if (j >= sKeySize)
        {
            j = 0;
        }

        pShellcode[i] = pShellcode[i] ^ bKey[j];
    }
}
```

**Example**

```c
unsigned char pShellcode[]   = { 0xFC, 0x48, 0x83, 0xE4, 0xF0, 0xE5 };
SIZE_T        sShellcodeSize = sizeof(pShellcode);

unsigned char bKey[] = { 0x5A, 0xA5, 0x5A, 0xA5 };  // 4-byte repeating key.
SIZE_T        sKeySize = sizeof(bKey);

// Encrypt the payload in place using the multi-byte key, repeated as needed.
// The same call with the same key reverses it (see the Decryption note).
XorByInputKey(pShellcode, sShellcodeSize, bKey, sKeySize);
```
