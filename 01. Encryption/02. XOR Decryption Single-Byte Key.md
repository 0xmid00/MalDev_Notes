## XOR Decryption using Single-Byte Key

Reverses a single-byte XOR transformation by applying the same key to each byte again.

**Usage**

Call `XorByOneKey` with the XOR-transformed data, its size, and the same key originally used for encryption.

- `IN PBYTE pShellcode` Base address of the encrypted data.
- `IN SIZE_T sShellcodeSize` Size of the data in bytes.
- `IN BYTE bKey` The same single-byte XOR key used during encryption.

**Return Value**

`VOID` Restores the original data in `pShellcode` and does not return a value.

**External Files**

- `Windows.h` `BYTE`, `PBYTE`, `SIZE_T`, `VOID`

### Code

```c
#include <Windows.h>

/*
    XOR each byte of the encrypted data with the same key.

    XOR is reversible:
        (data ^ key) ^ key = data

    - pShellcode      : Base address of the encrypted data.
    - sShellcodeSize  : Size of the data in bytes.
    - bKey            : The same single-byte XOR key used for encryption.
*/
VOID XorByOneKey(
    IN PBYTE pShellcode,
    IN SIZE_T sShellcodeSize,
    IN BYTE bKey
)
{
    if (pShellcode == NULL || sShellcodeSize == 0)
        return;

    for (size_t i = 0; i < sShellcodeSize; i++)
    {
        pShellcode[i] = pShellcode[i] ^ bKey;
    }
}
```

**Example**

```c
// Payload produced by the Encryption note (plaintext XOR 0x5A).
unsigned char pShellcode[]   = { 0xA6, 0x12, 0xD9, 0xBE, 0xAA, 0xBF };
SIZE_T        sShellcodeSize = sizeof(pShellcode);
BYTE          bKey           = 0x5A;  // Must match the encryption key.

// Re-apply the same single-byte XOR to recover the original plaintext.
XorByOneKey(pShellcode, sShellcodeSize, bKey);
```
