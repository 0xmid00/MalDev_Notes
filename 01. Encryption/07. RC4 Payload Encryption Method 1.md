## RC4 Payload Encryption  - Method 1

Encrypts a plaintext payload buffer in place using the RC4 stream cipher. Initializes the cipher context with `rc4Init` and processes the data with `rc4Cipher`.

**Usage**

Call `Rc4EncryptPayload` with the key and its size, the plaintext buffer, the output ciphertext buffer, and the payload size.

- `IN PBYTE pRc4Key`  The RC4 key used to initialize the cipher's S-box permutation.
- `IN PBYTE pPlaintext`  Base address of the plaintext payload buffer to encrypt.
- `OUT PBYTE pCiphertext`  Caller-allocated buffer that receives the encrypted output; must be at least `sPayloadSize` bytes.
- `IN DWORD dwRc4KeySize`  Size of `pRc4Key` in bytes.
- `IN DWORD sPayloadSize`  Size of `pPlaintext` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` on success or `FALSE` if a required pointer argument is `NULL`.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `DWORD`, `IN`, `OUT`
- `string.h`  `strlen()`

### Code

```c
#include <windows.h>
#include <string.h>

typedef struct
{
    unsigned int  i;
    unsigned int  j;
    unsigned char s[256];

} Rc4Context;


void rc4Init(Rc4Context* context, const unsigned char* key, size_t length)
{
    unsigned int  i;
    unsigned int  j;
    unsigned char temp;

    if (context == NULL || key == NULL)
        return;

    context->i = 0;
    context->j = 0;

    for (i = 0; i < 256; i++)
        context->s[i] = i;

    for (i = 0, j = 0; i < 256; i++)
    {
        j = (j + context->s[i] + key[i % length]) % 256;

        temp           = context->s[i];
        context->s[i] = context->s[j];
        context->s[j] = temp;
    }
}


void rc4Cipher(Rc4Context* context, const unsigned char* input, unsigned char* output, size_t length)
{
    unsigned char  temp;
    unsigned int   i = context->i;
    unsigned int   j = context->j;
    unsigned char* s = context->s;

    while (length > 0)
    {
        i = (i + 1) % 256;
        j = (j + s[i]) % 256;

        temp = s[i];
        s[i] = s[j];
        s[j] = temp;

        if (input != NULL && output != NULL)
        {
            *output = *input ^ s[(s[i] + s[j]) % 256];
            input++;
            output++;
        }

        length--;
    }

    context->i = i;
    context->j = j;
}


BOOL Rc4EncryptPayload(IN PBYTE pRc4Key, IN PBYTE pPlaintext, OUT PBYTE pCiphertext, IN DWORD dwRc4KeySize, IN DWORD sPayloadSize)
{
    if (pRc4Key == NULL || pPlaintext == NULL || pCiphertext == NULL)
        return FALSE;

    Rc4Context ctx = { 0 };

    rc4Init(
        &ctx,           // Pointer to the Rc4Context structure to initialize.
        pRc4Key,        // Key used to build the S-box permutation.
        dwRc4KeySize    // Length of the key in bytes.
    );

    rc4Cipher(
        &ctx,           // Initialized RC4 context carrying the S-box state.
        pPlaintext,     // Input buffer containing the plaintext payload.
        pCiphertext,    // Output buffer that receives the encrypted result.
        sPayloadSize    // Number of bytes to encrypt.
    );

    return TRUE;
}
```

**Example**

```c
unsigned char pRc4Key[]     = { 0x5A, 0xA5, 0x5A, 0xA5 };
unsigned char pPlaintext[]  = { 0xFC, 0x48, 0x83, 0xE4, 0xF0, 0xE5 };
unsigned char pCiphertext[6] = { 0 };

// Encrypt the plaintext into pCiphertext; the same call decrypts it.
if (!Rc4EncryptPayload(pRc4Key, pPlaintext, pCiphertext,
                       sizeof(pRc4Key), sizeof(pPlaintext))) {
    printf("[!] Rc4EncryptPayload failed\n");
}
```
