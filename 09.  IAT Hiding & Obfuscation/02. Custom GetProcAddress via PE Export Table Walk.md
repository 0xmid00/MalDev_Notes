## Custom GetProcAddress via PE Export Table Walk

Resolves an exported function address by manually walking the PE export table of a loaded module — no call to `GetProcAddress` is made. Starting from `hModule` (the DLL's base address in memory), the function navigates the DOS header → NT headers → Optional header → `IMAGE_EXPORT_DIRECTORY`, then iterates `AddressOfNames` to find the target function name with `strcmp`. The matching entry's index into `AddressOfNameOrdinals` yields the ordinal, which in turn indexes `AddressOfFunctions` to produce the final VA. Because `GetProcAddress` is never called, it does not appear in the IAT as a result of this resolution.

**Usage**

Call `GetProcAddressReplacement` with a module handle (e.g. from `GetModuleHandleA`) and the null-terminated name of the exported function to find. Cast the returned `FARPROC` to the matching typedef before calling.

- `IN HMODULE hModule`  Base address of the loaded DLL whose export table is to be walked.
- `IN LPCSTR lpApiName`  Null-terminated name of the exported function to resolve.

**Return Value**

`FARPROC`  Returns the VA of the matching exported function, or `NULL` if the DOS/NT signature check fails or the function name is not found in the export table.

**External Files**

- `windows.h`  `HMODULE`, `FARPROC`, `PBYTE`, `PDWORD`, `PWORD`, `PVOID`, `DWORD`, `WORD`, `CHAR`, `IN`, `PIMAGE_DOS_HEADER`, `PIMAGE_NT_HEADERS`, `IMAGE_OPTIONAL_HEADER`, `PIMAGE_EXPORT_DIRECTORY`, `GetModuleHandleA()`
- `string.h`  `strcmp()`

### Code

```c
#include <windows.h>
#include <string.h>


FARPROC GetProcAddressReplacement(IN HMODULE hModule, IN LPCSTR lpApiName)
{
    // Cast to PBYTE so RVA arithmetic (pBase + RVA) compiles without error.
    PBYTE pBase = (PBYTE)hModule;

    // ── DOS Header ────────────────────────────────────────────────────────────
    PIMAGE_DOS_HEADER pImgDosHdr = (PIMAGE_DOS_HEADER)pBase;
    if (pImgDosHdr->e_magic != IMAGE_DOS_SIGNATURE)     // Validate MZ signature.
        return NULL;

    // ── NT Headers ────────────────────────────────────────────────────────────
    // e_lfanew is the RVA of IMAGE_NT_HEADERS from the start of the file.
    PIMAGE_NT_HEADERS pImgNtHdrs = (PIMAGE_NT_HEADERS)(pBase + pImgDosHdr->e_lfanew);
    if (pImgNtHdrs->Signature != IMAGE_NT_SIGNATURE)    // Validate PE signature.
        return NULL;

    // ── Optional Header ───────────────────────────────────────────────────────
    IMAGE_OPTIONAL_HEADER ImgOptHdr = pImgNtHdrs->OptionalHeader;

    // ── Export Directory ──────────────────────────────────────────────────────
    // DataDirectory[IMAGE_DIRECTORY_ENTRY_EXPORT].VirtualAddress is an RVA;
    // add pBase to convert to a VA.
    PIMAGE_EXPORT_DIRECTORY pImgExportDir = (PIMAGE_EXPORT_DIRECTORY)(
        pBase + ImgOptHdr.DataDirectory[IMAGE_DIRECTORY_ENTRY_EXPORT].VirtualAddress
    );

    // ── Export Table Arrays ───────────────────────────────────────────────────
    // All three members are RVAs; add pBase to each to get the VA of the array.

    // Array of RVAs — each element points to the name string of one exported function.
    PDWORD FunctionNameArray    = (PDWORD)(pBase + pImgExportDir->AddressOfNames);

    // Array of RVAs — each element points to the address of one exported function.
    // Indexed by ordinal, NOT by the loop counter i.
    PDWORD FunctionAddressArray = (PDWORD)(pBase + pImgExportDir->AddressOfFunctions);

    // Array of WORDs — each element is the ordinal of the function at index i.
    // Use FunctionOrdinalArray[i] to index into FunctionAddressArray.
    PWORD  FunctionOrdinalArray = (PWORD) (pBase + pImgExportDir->AddressOfNameOrdinals);

    // ── Search Loop ───────────────────────────────────────────────────────────
    // Iterate up to NumberOfFunctions times — one iteration per exported name.
    for (DWORD i = 0; i < pImgExportDir->NumberOfFunctions; i++) {

        // Resolve the name string for this export entry (RVA → VA → string).
        CHAR* pFunctionName = (CHAR*)(pBase + FunctionNameArray[i]);

        // Resolve the function's VA:
        //   1. FunctionOrdinalArray[i]          → ordinal of this named export.
        //   2. FunctionAddressArray[ordinal]     → RVA of the function.
        //   3. pBase + RVA                       → VA of the function.
        PVOID pFunctionAddress = (PVOID)(pBase + FunctionAddressArray[FunctionOrdinalArray[i]]);

        // Compare the current export name against the requested name.
        if (strcmp(lpApiName, pFunctionName) == 0)
            return (FARPROC)pFunctionAddress;   // Match found — return the VA.
    }

    return NULL;    // Function name not found in the export table.
}
```

**Example**

```c
// ── Resolve NtAllocateVirtualMemory without calling GetProcAddress ──

typedef NTSTATUS(NTAPI* fnNtAllocateVirtualMemory)(
    HANDLE    ProcessHandle,
    PVOID*    BaseAddress,
    ULONG_PTR ZeroBits,
    PSIZE_T   RegionSize,
    ULONG     AllocationType,
    ULONG     Protect
);

HMODULE hNtdll = GetModuleHandleA("NTDLL.DLL");

fnNtAllocateVirtualMemory pNtAllocateVirtualMemory =
    (fnNtAllocateVirtualMemory)GetProcAddressReplacement(hNtdll, "NtAllocateVirtualMemory");

// ── Resolve VirtualAllocEx from Kernel32 ──

typedef LPVOID(WINAPI* fnVirtualAllocEx)(HANDLE, LPVOID, SIZE_T, DWORD, DWORD);

fnVirtualAllocEx pVirtualAllocEx =
    (fnVirtualAllocEx)GetProcAddressReplacement(
        GetModuleHandleA("KERNEL32.DLL"), "VirtualAllocEx"
    );

// ── Verify against the real GetProcAddress ──
// Both should print the same address.
printf("[+] Real    GetProcAddress : 0x%p \n", GetProcAddress(hNtdll, "NtAllocateVirtualMemory"));
printf("[+] Custom  GetProcAddress : 0x%p \n", GetProcAddressReplacement(hNtdll, "NtAllocateVirtualMemory"));
```
