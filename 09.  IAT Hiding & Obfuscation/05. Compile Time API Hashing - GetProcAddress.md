## Compile Time API Hashing via Djb2 + GetProcAddressH

Resolves exported API functions by hash at runtime without storing any function name string in the binary. A `constexpr` Djb2 hash of the target function name is computed at compile time using `CTIME_HASHA` / `CTIME_HASHW` and stored in a named variable. `GetProcAddressH` then walks the PE export table and compares each exported name's runtime hash against the pre-computed value. The initial hash seed `g_KEY` is derived from `__TIME__` via `RandomCompileTimeSeed`, so the hash changes on every compilation, preventing security solutions from using hard-coded hash values as IoCs.

> **C++ only.** This technique requires the `constexpr` keyword which is not available in C. Create the project as a C++ file (`.cpp`) in Visual Studio.

**Usage**

1. Declare compile-time hash variables with `CTIME_HASHA(FunctionName)` or `CTIME_HASHW(FunctionName)` at file scope — this creates a `constexpr` variable named `FunctionName_Rotr32A` or `FunctionName_Rotr32W`.
2. Call `GetProcAddressH` with the module handle and the generated variable as the hash argument.
3. Cast the returned `FARPROC` to the matching typedef and call it.

- `IN HMODULE hModule`  Base address of the loaded DLL whose export table is to be walked.
- `IN DWORD dwApiNameHash`  Compile-time hash of the target function name, produced by `CTIME_HASHA` or `CTIME_HASHW`.

**Return Value**

`FARPROC`  Returns the VA of the matching exported function, or `NULL` if the DOS/NT signature check fails or no hash matches.

**External Files**

- `windows.h`  `HMODULE`, `FARPROC`, `PBYTE`, `PDWORD`, `PWORD`, `PVOID`, `DWORD`, `ULONG`, `INT`, `CHAR`, `IN`, `PIMAGE_DOS_HEADER`, `PIMAGE_NT_HEADERS`, `IMAGE_OPTIONAL_HEADER`, `PIMAGE_EXPORT_DIRECTORY`
- `winternl.h`  `IMAGE_NT_HEADERS`, `IMAGE_OPTIONAL_HEADER`

### Code

```cpp
#include <windows.h>
#include <winternl.h>

#define SEED    5   // Bit-shift amount used in Djb2 hash iterations.


// ─────────────────────────────────────────────────────────────────────────────
// Compile-time random seed derived from the build timestamp (__TIME__).
// Each compilation of the binary produces a different g_KEY, which means
// the hash values change on every build — preventing static IoC fingerprinting.
// ─────────────────────────────────────────────────────────────────────────────
constexpr int RandomCompileTimeSeed(void)
{
    return '0' * -40271 +
        __TIME__[7] * 1    +    // Seconds (ones digit).
        __TIME__[6] * 10   +    // Seconds (tens digit).
        __TIME__[4] * 60   +    // Minutes (ones digit).
        __TIME__[3] * 600  +    // Minutes (tens digit).
        __TIME__[1] * 3600 +    // Hours   (ones digit).
        __TIME__[0] * 36000;    // Hours   (tens digit).
}

// Global compile-time key — changes every time the project is rebuilt.
constexpr auto g_KEY = RandomCompileTimeSeed() % 0xFF;


// ─────────────────────────────────────────────────────────────────────────────
// Compile-time Djb2 hashing functions (constexpr).
// Seeded with g_KEY so the output differs on every compilation.
// ─────────────────────────────────────────────────────────────────────────────

// ASCII variant — hashes a narrow string at compile time.
constexpr DWORD HashStringDjb2A(const char* String)
{
    ULONG Hash = (ULONG)g_KEY;
    INT   c    = 0;
    while ((c = *String++))
        Hash = ((Hash << SEED) + Hash) + c;    // Hash = Hash * 33 + c
    return Hash;
}

// Wide variant — hashes a wide string at compile time.
constexpr DWORD HashStringDjb2W(const wchar_t* String)
{
    ULONG Hash = (ULONG)g_KEY;
    INT   c    = 0;
    while ((c = *String++))
        Hash = ((Hash << SEED) + Hash) + c;
    return Hash;
}


// ─────────────────────────────────────────────────────────────────────────────
// Runtime hashing macros.
// Used inside GetProcAddressH to hash each exported function name at runtime
// so it can be compared against a pre-computed compile-time hash.
// ─────────────────────────────────────────────────────────────────────────────
#define RTIME_HASHA(API)  HashStringDjb2A((const char*)     (API))
#define RTIME_HASHW(API)  HashStringDjb2W((const wchar_t*)  (API))


// ─────────────────────────────────────────────────────────────────────────────
// Compile-time hashing macros.
// Each macro declares a constexpr variable that holds the hash of the
// function name string, evaluated entirely at compile time.
//
// CTIME_HASHA(MessageBoxA)
//   → constexpr auto MessageBoxA_Rotr32A = HashStringDjb2A("MessageBoxA");
//
// CTIME_HASHW(MessageBoxW)
//   → constexpr auto MessageBoxW_Rotr32W = HashStringDjb2W(L"MessageBoxW");
//
// The ## operator concatenates the API name with the suffix to form the
// variable name. The # operator stringizes the API name into a string literal.
// ─────────────────────────────────────────────────────────────────────────────
#define CTIME_HASHA(API)  constexpr auto API##_Rotr32A = HashStringDjb2A((const char*)    #API);
#define CTIME_HASHW(API)  constexpr auto API##_Rotr32W = HashStringDjb2W((const wchar_t*) L#API);


// ─────────────────────────────────────────────────────────────────────────────
// GetProcAddressH — export table walk using hash comparison.
//
// Identical to the string-based GetProcAddressReplacement except the exported
// function name is hashed at runtime with RTIME_HASHA and compared against the
// caller-supplied compile-time hash dwApiNameHash. No function name string is
// stored or compared directly — only 32-bit integer values are compared.
// ─────────────────────────────────────────────────────────────────────────────
FARPROC GetProcAddressH(IN HMODULE hModule, IN DWORD dwApiNameHash)
{
    PBYTE pBase = (PBYTE)hModule;

    // ── DOS Header ────────────────────────────────────────────────────────────
    PIMAGE_DOS_HEADER pImgDosHdr = (PIMAGE_DOS_HEADER)pBase;
    if (pImgDosHdr->e_magic != IMAGE_DOS_SIGNATURE)     // Validate MZ signature.
        return NULL;

    // ── NT Headers ────────────────────────────────────────────────────────────
    PIMAGE_NT_HEADERS pImgNtHdrs = (PIMAGE_NT_HEADERS)(pBase + pImgDosHdr->e_lfanew);
    if (pImgNtHdrs->Signature != IMAGE_NT_SIGNATURE)    // Validate PE signature.
        return NULL;

    // ── Optional Header ───────────────────────────────────────────────────────
    IMAGE_OPTIONAL_HEADER ImgOptHdr = pImgNtHdrs->OptionalHeader;

    // ── Export Directory ──────────────────────────────────────────────────────
    PIMAGE_EXPORT_DIRECTORY pImgExportDir = (PIMAGE_EXPORT_DIRECTORY)(
        pBase + ImgOptHdr.DataDirectory[IMAGE_DIRECTORY_ENTRY_EXPORT].VirtualAddress
    );

    // ── Export Table Arrays ───────────────────────────────────────────────────
    PDWORD FunctionNameArray    = (PDWORD)(pBase + pImgExportDir->AddressOfNames);
    PDWORD FunctionAddressArray = (PDWORD)(pBase + pImgExportDir->AddressOfFunctions);
    PWORD  FunctionOrdinalArray = (PWORD) (pBase + pImgExportDir->AddressOfNameOrdinals);

    // ── Hash-based Search Loop ────────────────────────────────────────────────
    for (DWORD i = 0; i < pImgExportDir->NumberOfFunctions; i++) {

        // Resolve the exported function's name string (RVA → VA → string).
        CHAR* pFunctionName     = (CHAR*)(pBase + FunctionNameArray[i]);

        // Resolve the exported function's address via its ordinal.
        PVOID pFunctionAddress  = (PVOID)(pBase + FunctionAddressArray[FunctionOrdinalArray[i]]);

        // Hash the exported name at runtime and compare against the
        // compile-time hash supplied by the caller — no string in the binary.
        if (dwApiNameHash == RTIME_HASHA(pFunctionName))
            return (FARPROC)pFunctionAddress;
    }

    return NULL;
}
```

**Example**

```cpp
// ── Step 1: declare compile-time hash variables at file scope ──────────────

CTIME_HASHA(MessageBoxA)    // creates: constexpr auto MessageBoxA_Rotr32A = ...
CTIME_HASHW(MessageBoxW)    // creates: constexpr auto MessageBoxW_Rotr32W = ...


// ── Step 2: define matching typedefs ──────────────────────────────────────

typedef int(WINAPI* fnMessageBoxA)(HWND, LPCSTR,  LPCSTR,  UINT);
typedef int(WINAPI* fnMessageBoxW)(HWND, LPCWSTR, LPCWSTR, UINT);


// ── Step 3: load the DLL, resolve by hash, and call ───────────────────────

HMODULE hUser32 = LoadLibraryA("USER32.DLL");

// Pass the compile-time variable as the hash — no "MessageBoxA" string needed.
fnMessageBoxA pMessageBoxA = (fnMessageBoxA)GetProcAddressH(hUser32, MessageBoxA_Rotr32A);
fnMessageBoxW pMessageBoxW = (fnMessageBoxW)GetProcAddressH(hUser32, MessageBoxW_Rotr32W);

pMessageBoxA(NULL, "Building Malware With Maldev", "Wow",    MB_OK | MB_ICONINFORMATION);
pMessageBoxW(NULL, L"Malware Is Bad For Your Health", L"Danger", MB_OK | MB_ICONWARNING);


// ── Optional: print hash values to verify they change per compilation ──────

// printf("[i] MessageBoxA_Rotr32A : 0x%0.8X \n", MessageBoxA_Rotr32A);
// printf("[i] MessageBoxW_Rotr32W : 0x%0.8X \n", MessageBoxW_Rotr32W);
```
