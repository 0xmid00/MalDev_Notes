## API Hooking Using Windows APIs (SetWindowsHookEx)

Installs a system-wide event hook using `SetWindowsHookExW` to intercept and monitor Windows messages without modifying any function's prologue bytes. Unlike trampoline-based hooking, `SetWindowsHookEx` does not redirect function execution — instead it fires a caller-supplied `HOOKPROC` callback every time the specified event type occurs. The hook is installed inside a dedicated thread; a `GetMessageW` + `DefWindowProcW` loop processes unhandled system messages to prevent input lag. The global hook handle `g_hMouseHook` is passed to `UnhookWindowsHookEx` from the main thread to cleanly remove the hook after `MONITOR_TIME` milliseconds. The example monitors `WH_MOUSE_LL` (low-level mouse) events but the same pattern applies to any supported hook type such as `WH_KEYBOARD_LL`.

**Usage**

Pass `MouseClicksLogger` to `CreateThread` as the thread entry point. In the main thread call `WaitForSingleObject` for the desired duration, then call `UnhookWindowsHookEx(g_hMouseHook)` to remove the hook. To monitor a different event replace `WH_MOUSE_LL` with any supported `idHook` constant and update `HookCallback` to handle the relevant `wParam` messages.

- No parameters — `MouseClicksLogger` is used as an `LPTHREAD_START_ROUTINE` and takes no arguments. The hook handle is shared via the global `g_hMouseHook`.

**Return Value**

`MouseClicksLogger` → `BOOL`  Returns `TRUE` if the hook was installed and the message loop ran successfully, otherwise `FALSE` if `SetWindowsHookExW` fails.

**External Files**

- `windows.h`  `HHOOK`, `LRESULT`, `WPARAM`, `LPARAM`, `BOOL`, `HANDLE`, `DWORD`, `MSG`, `HOOKPROC`, `SetWindowsHookExW()`, `CallNextHookEx()`, `UnhookWindowsHookEx()`, `GetMessageW()`, `DefWindowProcW()`, `CreateThread()`, `WaitForSingleObject()`, `GetLastError()`
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>

#define MONITOR_TIME    20000   // Duration in milliseconds to monitor events.

// Global hook handle — shared between the hook thread and the main thread.
// Set by SetWindowsHookExW inside MouseClicksLogger; read by UnhookWindowsHookEx in main.
HHOOK g_hMouseHook = NULL;


// ── Hook Callback ─────────────────────────────────────────────────────────────
// Executed by the OS every time a WH_MOUSE_LL event fires.
// Must match the HOOKPROC signature: LRESULT CALLBACK fn(int, WPARAM, LPARAM).
// Always call CallNextHookEx at the end to pass the event to the next hook in
// the chain — skipping this causes other applications' hooks to malfunction.
LRESULT HookCallback(int nCode, WPARAM wParam, LPARAM lParam)
{
    // wParam carries the mouse message identifier.
    if (wParam == WM_LBUTTONDOWN)
        printf("[ # ] Left Mouse Click \n");

    if (wParam == WM_RBUTTONDOWN)
        printf("[ # ] Right Mouse Click \n");

    if (wParam == WM_MBUTTONDOWN)
        printf("[ # ] Middle Mouse Click \n");

    // Pass the hook information to the next hook procedure in the chain.
    // First parameter NULL: let the OS determine the next hook handle.
    return CallNextHookEx(NULL, nCode, wParam, lParam);
}


// ── Hook Thread Entry Point ───────────────────────────────────────────────────
// Installs the hook and runs a message loop to process unhandled system events.
// Must run in its own thread so the message loop does not block the main thread.
BOOL MouseClicksLogger()
{
    MSG Msg = { 0 };

    // Install the low-level mouse hook system-wide.
    // WH_MOUSE_LL: intercept mouse input events before the system processes them.
    // NULL hmod:   not required for low-level global hooks.
    // NULL dwThreadId: 0 associates the hook with all existing threads (global).
    g_hMouseHook = SetWindowsHookExW(
        WH_MOUSE_LL,            // Hook type: low-level mouse events.
        (HOOKPROC)HookCallback, // Callback to invoke on each mouse event.
        NULL,                   // DLL handle: not required for LL global hooks.
        NULL                    // Thread ID: 0 = system-wide hook.
    );
    if (!g_hMouseHook) {
        printf("[!] SetWindowsHookExW Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Message loop: GetMessageW retrieves queued messages for this thread.
    // DefWindowProcW processes each message with the default window procedure,
    // ensuring the system handles events correctly and mouse input stays responsive.
    // Without this loop the WH_MOUSE_LL hook causes noticeable mouse lag.
    while (GetMessageW(&Msg, NULL, NULL, NULL)) {
        DefWindowProcW(
            Msg.hwnd,       // Window handle associated with the message.
            Msg.message,    // Message identifier (e.g. WM_LBUTTONDOWN).
            Msg.wParam,     // Additional message information (button/key).
            Msg.lParam      // Additional message information (coordinates/flags).
        );
    }

    return TRUE;
}
```

**Example**

```c
HANDLE  hThread     = NULL;
DWORD   dwThreadId  = NULL;

// Start the hook thread — MouseClicksLogger installs the hook and runs the loop.
hThread = CreateThread(
    NULL,                                       // Default security attributes.
    NULL,                                       // Default stack size.
    (LPTHREAD_START_ROUTINE)MouseClicksLogger,  // Thread entry: installs hook + message loop.
    NULL,                                       // No parameter needed.
    NULL,                                       // Run immediately.
    &dwThreadId                                 // Receives the thread ID.
);

if (hThread) {
    printf("\t<<>> Thread %d Monitoring Mouse Clicks For %d Seconds <<>>\n\n",
           dwThreadId, (MONITOR_TIME / 1000));

    // Block main thread for MONITOR_TIME milliseconds, then continue.
    WaitForSingleObject(hThread, MONITOR_TIME);
}

// Remove the hook after the monitoring period ends.
if (g_hMouseHook && !UnhookWindowsHookEx(g_hMouseHook)) {
    printf("[!] UnhookWindowsHookEx Failed With Error : %d \n", GetLastError());
}


// ── Supported idHook values (replace WH_MOUSE_LL to change event type) ───────
//
// WH_MOUSE_LL    — low-level mouse input (clicks, movement, scroll)
// WH_KEYBOARD_LL — low-level keyboard input (keystrokes)
// WH_CALLWNDPROC — messages sent to a window procedure
// WH_CBT         — computer-based training events (window create/destroy/focus)
// WH_SHELL       — shell events (application activation, task bar changes)
```

**Parameter Sources**

No external parameter sources — the hook type, callback, and monitor duration are compile-time constants supplied directly by the caller.
