## API Hooking Trampoline via Detours Library

Intercepts a target Windows API at runtime using the Microsoft Detours library. `InstallHook` replaces the first bytes of `MessageBoxA` with a trampoline jump to `MyMessageBoxA` — the detour function — by opening a Detours transaction, calling `DetourAttach`, and committing. `Unhook` reverses the patch through the same transaction model using `DetourDetach`. The original unhook pointer `g_pMessageBoxA` is used inside `MyMessageBoxA` to call the real function without triggering an infinite loop.

> **Requires the Detours static library.** See the Build section below before compiling.

**Usage**

Call `InstallHook` to activate the hook and `Unhook` to remove it. Between calls, any invocation of `MessageBoxA` in the process will execute `MyMessageBoxA` instead. Replace `MyMessageBoxA` and the `g_pMessageBoxA` global with the target function and its matching typedef to hook a different API.

- No parameters — the target function pointer (`g_pMessageBoxA`) and detour function (`MyMessageBoxA`) are global.

**Return Value**

`InstallHook` / `Unhook` → `BOOL`  Returns `TRUE` if all four Detours transaction steps succeed, otherwise `FALSE`.

**External Files**

- [detours.h](<0.files/API Hooking Detours/detours.h>)  ⚠️ Must be added manually — copy from `Detours\include\` after building the library. Provides `DetourTransactionBegin()`, `DetourUpdateThread()`, `DetourAttach()`, `DetourDetach()`, `DetourTransactionCommit()`.
- [detoursx64.lib](<0.files/API Hooking Detours/detoursx64.lib>)  ⚠️ Must be added manually — built from `Detours\lib.X64\detours.lib`. Linked via `#pragma comment`.
- [detoursx86.lib](<0.files/API Hooking Detours/detoursx86.lib>)  ⚠️ Must be added manually — built from `Detours\lib.X86\detours.lib`. Linked via `#pragma comment`.
- `windows.h`  `HWND`, `LPCSTR`, `UINT`, `INT`, `BOOL`, `DWORD`, `PVOID`, `WINAPI`, `GetCurrentThread()`, `GetLastError()`
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>
#include "detours.h"

// Link the correct Detours static lib depending on target architecture.
#ifdef _M_X64
#pragma comment(lib, "detoursx64.lib")
#endif
#ifdef _M_IX86
#pragma comment(lib, "detoursx86.lib")
#endif


// ── Target Function Typedef ───────────────────────────────────────────────────
// Must match the exact signature of the function being hooked.
typedef INT(WINAPI* fnMessageBoxA)(HWND hWnd, LPCSTR lpText, LPCSTR lpCaption, UINT uType);


// ── Original Function Pointer (Global) ───────────────────────────────────────
// Initialised to the real MessageBoxA before any hook is installed.
// After DetourAttach this pointer is updated by Detours to point to the
// trampoline — calling it from inside MyMessageBoxA invokes the real API
// without re-entering the hook (no infinite loop).
// Also passed to DetourAttach / DetourDetach as the target to hook/unhook.
fnMessageBoxA g_pMessageBoxA = MessageBoxA;


// ── Detour Function ───────────────────────────────────────────────────────────
// Runs instead of MessageBoxA when the hook is active.
// Must match the hooked function's return type and parameters.
// Call g_pMessageBoxA (not MessageBoxA) to invoke the real API.
INT WINAPI MyMessageBoxA(HWND hWnd, LPCSTR lpText, LPCSTR lpCaption, UINT uType)
{
    // Inspect or log the original caller-supplied parameters.
    printf("[+] Original Parameters : \n");
    printf("\t - lpText    : %s\n", lpText);
    printf("\t - lpCaption : %s\n", lpCaption);

    // Call the real MessageBoxA via the trampoline — NOT MessageBoxA directly.
    // Calling MessageBoxA here would re-enter this hook and loop infinitely.
    return g_pMessageBoxA(hWnd, "Malware Development Is Cool", "Hooked MsgBox", uType);
}


// ── Hook Installation ─────────────────────────────────────────────────────────
// Opens a Detours transaction, enlists the current thread, attaches the hook,
// and commits. The actual byte-patch is applied only on DetourTransactionCommit.
BOOL InstallHook()
{
    DWORD dwDetoursErr = NULL;

    // Step 1 — begin a new transaction.
    if ((dwDetoursErr = DetourTransactionBegin()) != NO_ERROR) {
        printf("[!] DetourTransactionBegin Failed With Error : %d \n", dwDetoursErr);
        return FALSE;
    }

    // Step 2 — enlist the current thread so Detours can fix up its stack frames.
    if ((dwDetoursErr = DetourUpdateThread(GetCurrentThread())) != NO_ERROR) {
        printf("[!] DetourUpdateThread Failed With Error : %d \n", dwDetoursErr);
        return FALSE;
    }

    // Step 3 — queue the hook: redirect g_pMessageBoxA → MyMessageBoxA.
    // Detours updates g_pMessageBoxA to point to the trampoline stub.
    if ((dwDetoursErr = DetourAttach((PVOID)&g_pMessageBoxA, MyMessageBoxA)) != NO_ERROR) {
        printf("[!] DetourAttach Failed With Error : %d \n", dwDetoursErr);
        return FALSE;
    }

    // Step 4 — commit: the byte-patch is written to MessageBoxA's prologue now.
    if ((dwDetoursErr = DetourTransactionCommit()) != NO_ERROR) {
        printf("[!] DetourTransactionCommit Failed With Error : %d \n", dwDetoursErr);
        return FALSE;
    }

    return TRUE;
}


// ── Hook Removal ──────────────────────────────────────────────────────────────
// Same transaction model as InstallHook but uses DetourDetach to queue removal.
// The original bytes are restored to MessageBoxA's prologue on commit.
BOOL Unhook()
{
    DWORD dwDetoursErr = NULL;

    // Step 1 — begin a new transaction.
    if ((dwDetoursErr = DetourTransactionBegin()) != NO_ERROR) {
        printf("[!] DetourTransactionBegin Failed With Error : %d \n", dwDetoursErr);
        return FALSE;
    }

    // Step 2 — enlist the current thread.
    if ((dwDetoursErr = DetourUpdateThread(GetCurrentThread())) != NO_ERROR) {
        printf("[!] DetourUpdateThread Failed With Error : %d \n", dwDetoursErr);
        return FALSE;
    }

    // Step 3 — queue the unhook: remove the redirect from g_pMessageBoxA.
    if ((dwDetoursErr = DetourDetach((PVOID)&g_pMessageBoxA, MyMessageBoxA)) != NO_ERROR) {
        printf("[!] DetourDetach Failed With Error : %d \n", dwDetoursErr);
        return FALSE;
    }

    // Step 4 — commit: the original prologue bytes are restored now.
    if ((dwDetoursErr = DetourTransactionCommit()) != NO_ERROR) {
        printf("[!] DetourTransactionCommit Failed With Error : %d \n", dwDetoursErr);
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
// ── Before hook: real MessageBoxA runs ───────────────────────────────────────
MessageBoxA(NULL, "What Do You Think About me?", "Original MsgBox", MB_OK | MB_ICONQUESTION);

// ── Install hook ──────────────────────────────────────────────────────────────
printf("[i] Installing The Hook ... ");
if (!InstallHook())
    return -1;
printf("[+] DONE \n");

// ── Hooked: MyMessageBoxA runs instead ───────────────────────────────────────
MessageBoxA(NULL, "i am  Bad", "Original MsgBox", MB_OK | MB_ICONWARNING);

// ── Remove hook ───────────────────────────────────────────────────────────────
printf("[i] Removing The Hook ... ");
if (!Unhook())
    return -1;
printf("[+] DONE \n");

// ── After unhook: real MessageBoxA runs again ─────────────────────────────────
MessageBoxA(NULL, "Normal MsgBox Again", "Original MsgBox", MB_OK | MB_ICONINFORMATION);
```

**Build — Detours Static Library**

Before compiling any project that uses Detours, both the 64-bit and 32-bit `.lib` files must be built from source.

**1. Clone the repository**
```cmd
git clone https://github.com/microsoft/Detours C:\dev\Detours
```

**2. Build x64**

Open **"x64 Native Tools Command Prompt for VS 2022"** from the Start menu, then:
```cmd
cd C:\dev\Detours
nmake
```
Outputs:
```
C:\dev\Detours\include\detours.h      ← header (bitness-independent)
C:\dev\Detours\lib.X64\detours.lib    ← 64-bit static lib
```

**3. Build x86**

Open a **fresh** **"x86 Native Tools Command Prompt for VS 2022"** (do not reuse the x64 prompt), then:
```cmd
cd C:\dev\Detours
nmake
```
Outputs:
```
C:\dev\Detours\lib.X86\detours.lib    ← 32-bit static lib
```

**4. Add to Visual Studio project**

Copy `detours.h` to your project folder and copy both `.lib` files (renamed `detoursx64.lib` and `detoursx86.lib`) to your project folder. The `#pragma comment` directives in the snippet link the correct one automatically based on the selected platform.

For additional help adding `.lib` files see [Microsoft's linker input documentation](https://learn.microsoft.com/en-us/cpp/build/reference/dot-lib-files-as-linker-input?view=msvc-170).

**Parameter Sources**

No external parameter sources — the target function pointer and detour function are global variables initialised at compile time.
