## API Hooking via MinHook Library

Intercepts a target Windows API at runtime using the lightweight MinHook library. `InstallHook` initialises the MinHook internal structure with `MH_Initialize`, creates the hook with `MH_CreateHook` — which also sets the trampoline pointer `g_pMessageBoxA` — and activates it with `MH_EnableHook`. `Unhook` deactivates the hook with `MH_DisableHook` and cleans up with `MH_Uninitialize`. Unlike the Detours library, MinHook requires no transactions. The trampoline pointer `g_pMessageBoxA` is initialised by `MH_CreateHook` itself (not manually) and is used inside `MyMessageBoxA` to call the real API without triggering an infinite loop.

> **Requires the MinHook static library.** See the Build section below before compiling.

**Usage**

Call `InstallHook` to activate the hook and `Unhook` to remove it. Between calls, any invocation of `MessageBoxA` in the process will execute `MyMessageBoxA` instead. Replace `MyMessageBoxA`, `g_pMessageBoxA`, and the `&MessageBoxA` target pointer with the desired function to hook a different API.

- No parameters — the target function pointer (`g_pMessageBoxA`) and detour function (`MyMessageBoxA`) are global.

**Return Value**

`InstallHook` / `Unhook` → `BOOL`  Returns `TRUE` if all MinHook steps succeed, otherwise `FALSE`.

**External Files**

- [MinHook.h](<0.files/API Hooking MinHook/MinHook.h>)  ⚠️ Must be added manually — copy from `minhook\include\` after building the library. Provides `MH_Initialize()`, `MH_CreateHook()`, `MH_EnableHook()`, `MH_DisableHook()`, `MH_Uninitialize()`, `MH_STATUS`, `MH_OK`.
- [libMinHook.x64.lib](<0.files/API Hooking MinHook/libMinHook.x64.lib>)  ⚠️ Must be added manually — built from the MinHook source. Linked via `#pragma comment` for x64.
- [libMinHook.x86.lib](<0.files/API Hooking MinHook/libMinHook.x86.lib>)  ⚠️ Must be added manually — built from the MinHook source. Linked via `#pragma comment` for x86.
- `windows.h`  `HWND`, `LPCSTR`, `UINT`, `INT`, `BOOL`, `DWORD`, `WINAPI`, `GetLastError()`
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>
#include "MinHook.h"

// Link the correct MinHook static lib depending on target architecture.
#ifdef _M_X64
#pragma comment(lib, "libMinHook.x64.lib")
#endif
#ifdef _M_IX86
#pragma comment(lib, "libMinHook.x86.lib")
#endif


// ── Target Function Typedef ───────────────────────────────────────────────────
// Must match the exact signature of the function being hooked.
typedef INT(WINAPI* fnMessageBoxA)(HWND hWnd, LPCSTR lpText, LPCSTR lpCaption, UINT uType);


// ── Original Function Pointer (Global) ───────────────────────────────────────
// Initialised to NULL — MH_CreateHook fills this in with the trampoline address.
// Calling g_pMessageBoxA from inside MyMessageBoxA invokes the real API
// without re-entering the hook (no infinite loop).
fnMessageBoxA g_pMessageBoxA = NULL;


// ── Detour Function ───────────────────────────────────────────────────────────
// Runs instead of MessageBoxA when the hook is active.
// Must match the hooked function's return type and parameters.
// Call g_pMessageBoxA (not MessageBoxA) to invoke the real API.
INT WINAPI MyMessageBoxA(HWND hWnd, LPCSTR lpText, LPCSTR lpCaption, UINT uType)
{
    // Inspect or log the original caller-supplied parameters.
    printf("[+] Original Parameters : \n");
    printf("\t - lpText    : %s\n", lpText);
    printf("\t - lpCaption : %s\n", lpCaption);

    // Call the real MessageBoxA via the trampoline — NOT MessageBoxA directly.
    // Calling MessageBoxA here would re-enter this hook and loop infinitely.
    return g_pMessageBoxA(hWnd, "Maldev Academy Is The Best", "Hooked MsgBox", uType);
}


// ── Hook Installation ─────────────────────────────────────────────────────────
// Initialises MinHook, creates the hook (which also sets g_pMessageBoxA to the
// trampoline), and enables it. MH_Initialize must be called only once per process.
BOOL InstallHook()
{
    DWORD dwMinHookErr = NULL;

    // Step 1 — initialise MinHook's internal HOOK_ENTRY structure.
    // Must be called once before any MH_CreateHook calls.
    if ((dwMinHookErr = MH_Initialize()) != MH_OK) {
        printf("[!] MH_Initialize Failed With Error : %d \n", dwMinHookErr);
        return FALSE;
    }

    // Step 2 — create the hook.
    //   &MessageBoxA   — address of the target function to hook.
    //   &MyMessageBoxA — address of the detour function to run instead.
    //   &g_pMessageBoxA — receives the trampoline pointer for calling the real API.
    if ((dwMinHookErr = MH_CreateHook(&MessageBoxA, &MyMessageBoxA, (LPVOID*)&g_pMessageBoxA)) != MH_OK) {
        printf("[!] MH_CreateHook Failed With Error : %d \n", dwMinHookErr);
        return FALSE;
    }

    // Step 3 — enable the hook: the byte-patch is written to MessageBoxA's prologue.
    // Pass MH_ALL_HOOKS instead of &MessageBoxA to enable all created hooks at once.
    if ((dwMinHookErr = MH_EnableHook(&MessageBoxA)) != MH_OK) {
        printf("[!] MH_EnableHook Failed With Error : %d \n", dwMinHookErr);
        return FALSE;
    }

    return TRUE;
}


// ── Hook Removal ──────────────────────────────────────────────────────────────
// Disables the hook (restores original bytes) and uninitialises MinHook.
// MH_Uninitialize must be called only once; it cleans up the HOOK_ENTRY structure.
BOOL Unhook()
{
    DWORD dwMinHookErr = NULL;

    // Step 1 — disable the hook: the original prologue bytes are restored.
    // Pass MH_ALL_HOOKS instead of &MessageBoxA to disable all hooks at once.
    if ((dwMinHookErr = MH_DisableHook(&MessageBoxA)) != MH_OK) {
        printf("[!] MH_DisableHook Failed With Error : %d \n", dwMinHookErr);
        return FALSE;
    }

    // Step 2 — clean up the HOOK_ENTRY structure initialised by MH_Initialize.
    if ((dwMinHookErr = MH_Uninitialize()) != MH_OK) {
        printf("[!] MH_Uninitialize Failed With Error : %d \n", dwMinHookErr);
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
// ── Before hook: real MessageBoxA runs ───────────────────────────────────────
MessageBoxA(NULL, "What Do You Think About me?", "Original MsgBox", MB_OK | MB_ICONQUESTION);

// ── Install hook ──────────────────────────────────────────────────────────────
printf("[i] Installing The Hook ... ");
if (!InstallHook())
    return -1;
printf("[+] DONE \n");

// ── Hooked: MyMessageBoxA runs instead ───────────────────────────────────────
MessageBoxA(NULL, "i am Is Trash", "Original MsgBox", MB_OK | MB_ICONWARNING);

// ── Remove hook ───────────────────────────────────────────────────────────────
printf("[i] Removing The Hook ... ");
if (!Unhook())
    return -1;
printf("[+] DONE \n");

// ── After unhook: real MessageBoxA runs again ─────────────────────────────────
MessageBoxA(NULL, "Normal MsgBox Again", "Original MsgBox", MB_OK | MB_ICONINFORMATION);
```

**Build — MinHook Static Library**

Before compiling any project that uses MinHook, the `.lib` files must be built from source or downloaded from the releases page.

**Option A — Download pre-built binaries (fastest)**
```
https://github.com/TsudaKageyu/minhook/releases
```
Download the latest release zip, extract `libMinHook.x64.lib` and `libMinHook.x86.lib` from the `lib\` folder, and copy them to your project directory alongside `include\MinHook.h`.

**Option B — Build from source**

1. Clone the repository:
```cmd
git clone https://github.com/TsudaKageyu/minhook C:\dev\minhook
```

2. Open `build\VC17\MinHookVC17.sln` in Visual Studio 2022.

3. Build the `libMinHook` project in **Release | x64** configuration:
```
Output: build\VC17\lib\Release\x64\libMinHook.x64.lib
```

4. Build again in **Release | Win32** configuration:
```
Output: build\VC17\lib\Release\Win32\libMinHook.x86.lib
```

5. Copy both `.lib` files and `include\MinHook.h` to your project folder. The `#pragma comment` directives in the snippet link the correct one automatically based on the selected platform.

For additional help adding `.lib` files see [Microsoft's linker input documentation](https://learn.microsoft.com/en-us/cpp/build/reference/dot-lib-files-as-linker-input?view=msvc-170).

**Parameter Sources**

No external parameter sources — the target function pointer and detour function are global variables; the trampoline pointer is set by `MH_CreateHook` at runtime.
