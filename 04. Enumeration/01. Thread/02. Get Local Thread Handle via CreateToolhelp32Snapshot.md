## Get Local Thread Handle & Tid via CreateToolhelp32Snapshot

Enumerates all running threads on the system using `CreateToolhelp32Snapshot` with the `TH32CS_SNAPTHREAD` flag, then iterates through the snapshot with `Thread32First` and `Thread32Next` looking for a thread owned by the current process. Skips the main thread by comparing each thread ID against `dwMainThreadId`. Opens a handle to the first valid hijackable thread found with `OpenThread` and returns its ID and handle to the caller by reference.

**Usage**

Call `GetLocalThreadHandle` with the main thread ID to exclude, a pointer to receive the hijackable thread ID, and a pointer to receive its handle. Obtain the main thread ID before calling this function (e.g. via `GetCurrentThreadId` in `main`). On success, `*hThread` is ready to be passed to `HijackThread`. The caller is responsible for closing `*hThread` with `CloseHandle` after use.

- `IN DWORD dwMainThreadId`  Thread ID of the local process's main thread — excluded from hijacking candidates.
- `OUT DWORD* dwThreadId`  Receives the ID of a hijackable worker thread belonging to the current process.
- `OUT HANDLE* hThread`  Receives the `THREAD_ALL_ACCESS` handle to the hijackable thread.

**Return Value**

`BOOL`  Returns `TRUE` if a valid hijackable thread was found and a handle was successfully opened, otherwise `FALSE`.

- `windows.h`  `BOOL`, `DWORD`, `HANDLE`, `THREADENTRY32`, `IN`, `OUT`, `CreateToolhelp32Snapshot()`, `Thread32First()`, `Thread32Next()`, `OpenThread()`, `GetCurrentProcessId()`, `CloseHandle()`, `GetLastError()`
- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL GetLocalThreadHandle(IN DWORD dwMainThreadId, OUT DWORD* dwThreadId, OUT HANDLE* hThread) {

    DWORD           dwProcessId = GetCurrentProcessId();
    HANDLE          hSnapShot   = NULL;
    THREADENTRY32   Thr         = {
        .dwSize = sizeof(THREADENTRY32)
    };

    // Take a snapshot of all threads currently running on the system.
    hSnapShot = CreateToolhelp32Snapshot(TH32CS_SNAPTHREAD, NULL);
    if (hSnapShot == INVALID_HANDLE_VALUE) {
        printf("\n\t[!] CreateToolhelp32Snapshot Failed With Error : %d \n", GetLastError());
        goto _EndOfFunction;
    }

    // Retrieve information about the first thread in the snapshot.
    if (!Thread32First(hSnapShot, &Thr)) {
        printf("\n\t[!] Thread32First Failed With Error : %d \n", GetLastError());
        goto _EndOfFunction;
    }

    do {
        // Match threads owned by the current process while skipping the main thread.
        // Avoiding the main thread is required since suspending it would deadlock the process.
        if (Thr.th32OwnerProcessID == dwProcessId && Thr.th32ThreadID != dwMainThreadId) {

            // Open a handle to the first valid hijackable worker thread found.
            *dwThreadId = Thr.th32ThreadID;
            *hThread    = OpenThread(
                THREAD_ALL_ACCESS,  // Full access rights needed for suspend/context operations.
                FALSE,              // Do not inherit the handle.
                Thr.th32ThreadID    // ID of the thread to open.
            );

            if (*hThread == NULL)
                printf("\n\t[!] OpenThread Failed With Error : %d \n", GetLastError());

            break;
        }

    // Advance to the next thread entry in the snapshot.
    } while (Thread32Next(hSnapShot, &Thr));

_EndOfFunction:
    if (hSnapShot != NULL)
        CloseHandle(hSnapShot);
    if (*dwThreadId == NULL || *hThread == NULL)
        return FALSE;
    return TRUE;
}
```

    printf("[+] Hijackable thread %d opened with handle 0x%p\n", dwThreadId, hThread);
