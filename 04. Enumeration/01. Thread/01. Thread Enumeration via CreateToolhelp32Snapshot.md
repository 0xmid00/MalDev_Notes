## Thread Enumeration via CreateToolhelp32Snapshot

Enumerates all running threads on the system using `CreateToolhelp32Snapshot` with the `TH32CS_SNAPTHREAD` flag, iterates through the snapshot with `Thread32First` and `Thread32Next`, and prints the thread ID, owner PID, and owner process name to stdout for every entry in the snapshot. The process name is resolved per thread by opening a temporary handle with `OpenProcess` and calling `GetModuleBaseNameW`.

**Usage**

Call `PrintThreads` with no arguments. It prints the thread ID, owner PID, and owner process name of every thread currently visible in the snapshot to stdout.

**Return Value**

`BOOL`  Returns `TRUE` if the snapshot was successfully created and enumeration completed, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `HANDLE`, `WCHAR`, `MAX_PATH`, `THREADENTRY32`, `CreateToolhelp32Snapshot()`, `Thread32First()`, `Thread32Next()`, `OpenProcess()`, `CloseHandle()`, `GetLastError()`
- `psapi.h`  `GetModuleBaseNameW()`
- `stdio.h`  `printf()`, `wprintf()`


### Code

```c
#include <windows.h>
#include <psapi.h>
#include <stdio.h>


BOOL PrintThreads() {

    HANDLE          hSnapShot   = NULL;
    HANDLE          hProcess    = NULL;
    THREADENTRY32   Thr         = {
        .dwSize = sizeof(THREADENTRY32)
    };
    WCHAR           szProcName  [MAX_PATH];

    // Take a snapshot of all threads currently running on the system.
    hSnapShot = CreateToolhelp32Snapshot(TH32CS_SNAPTHREAD, NULL);
    if (hSnapShot == INVALID_HANDLE_VALUE) {
        printf("[!] CreateToolhelp32Snapshot Failed With Error : %d \n", GetLastError());
        goto _EndOfFunction;
    }

    // Retrieve information about the first thread in the snapshot.
    if (!Thread32First(hSnapShot, &Thr)) {
        printf("[!] Thread32First Failed With Error : %d \n", GetLastError());
        goto _EndOfFunction;
    }

    do {
        // Open a temporary handle to the owner process to resolve its name.
        hProcess = OpenProcess(
            PROCESS_QUERY_INFORMATION | PROCESS_VM_READ, // Minimum access needed for GetModuleBaseName.
            FALSE,                                       // Do not inherit the handle.
            Thr.th32OwnerProcessID                       // PID of the thread's owner process.
        );

        if (hProcess != NULL) {
            // Resolve the owner process name from its first loaded module.
            if (GetModuleBaseNameW(hProcess, NULL, szProcName, MAX_PATH) == 0)
                szProcName[0] = L'\0';  // Clear on failure so the field prints empty rather than stale data.

            CloseHandle(hProcess);
        }
        else {
            // Process could not be opened — likely insufficient privileges.
            szProcName[0] = L'\0';
        }

        // Print the thread ID, owner PID, and resolved process name.
        wprintf(L"[+] Thread ID : %d - Owner PID : %d - Process : \"%s\" \n",
            Thr.th32ThreadID,
            Thr.th32OwnerProcessID,
            szProcName
        );

    // Advance to the next thread entry in the snapshot.
    } while (Thread32Next(hSnapShot, &Thr));

_EndOfFunction:
    if (hSnapShot != NULL)
        CloseHandle(hSnapShot);
    return TRUE;
}
```

**Example**

```c
// Snapshot every thread on the system and print its ID + owner process.
PrintThreads();
```
