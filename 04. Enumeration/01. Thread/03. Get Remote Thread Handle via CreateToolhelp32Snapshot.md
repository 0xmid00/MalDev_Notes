## Get Remote Thread Handle & Tid via CreateToolhelp32Snapshot

Enumerates all running threads on the system using `CreateToolhelp32Snapshot` with the `TH32CS_SNAPTHREAD` flag, then iterates through the snapshot with `Thread32First` and `Thread32Next` looking for the first thread owned by the caller-supplied target PID. Opens a handle to the matched thread with `OpenThread` and returns its ID and handle to the caller by reference. Unlike local thread enumeration, the main thread of the remote process is a valid hijacking target and is not excluded.

**Usage**

Call `GetRemoteThreadHandle` with the target process PID, a pointer to receive the thread ID, and a pointer to receive the thread handle. On success, `*hThread` is ready to be passed to `HijackThread`. The caller is responsible for closing `*hThread` with `CloseHandle` after use.

- `IN DWORD dwProcessId`  PID of the target remote process whose thread to enumerate.
- `OUT DWORD* dwThreadId`  Receives the ID of the first thread belonging to the target process.
- `OUT HANDLE* hThread`  Receives the `THREAD_ALL_ACCESS` handle to the matched thread.

**Return Value**

`BOOL`  Returns `TRUE` if a thread belonging to the target process was found and a handle was successfully opened, otherwise `FALSE`.

### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL GetRemoteThreadHandle(IN DWORD dwProcessId, OUT DWORD* dwThreadId, OUT HANDLE* hThread) {

    HANDLE          hSnapShot   = NULL;
    THREADENTRY32   Thr         = {
        .dwSize = sizeof(THREADENTRY32)
    };

    // Take a snapshot of all threads currently running on the system.
    hSnapShot = CreateToolhelp32Snapshot(TH32CS_SNAPTHREAD, NULL);
    if (hSnapShot == INVALID_HANDLE_VALUE) {
        printf("\n\t[!] CreateToolhelp32Snapshot Failed With Error : %d \n", GetLastError());
        goto _EndOfFunction;
    }

    // Retrieve information about the first thread in the snapshot.
    if (!Thread32First(hSnapShot, &Thr)) {
        printf("\n\t[!] Thread32First Failed With Error : %d \n", GetLastError());
        goto _EndOfFunction;
    }

    do {
        // Match the first thread whose owner PID equals the target process PID.
        if (Thr.th32OwnerProcessID == dwProcessId) {

            // Open a handle to the matched remote thread.
            *dwThreadId = Thr.th32ThreadID;
            *hThread    = OpenThread(
                THREAD_ALL_ACCESS,  // Full access rights needed for suspend/context operations.
                FALSE,              // Do not inherit the handle.
                Thr.th32ThreadID    // ID of the thread to open.
            );

            if (*hThread == NULL)
                printf("\n\t[!] OpenThread Failed With Error : %d \n", GetLastError());

            break;
        }

    // Advance to the next thread entry in the snapshot.
    } while (Thread32Next(hSnapShot, &Thr));

_EndOfFunction:
    if (hSnapShot != NULL)
        CloseHandle(hSnapShot);
    if (*dwThreadId == NULL || *hThread == NULL)
        return FALSE;
    return TRUE;
}
```

**Example**

```c
DWORD  dwProcessId = 1234;   // PID of the remote target process.
DWORD  dwThreadId  = 0;
HANDLE hThread     = NULL;

// Find any thread belonging to the remote process (main thread included).
if (GetRemoteThreadHandle(dwProcessId, &dwThreadId, &hThread)) {
    printf("[+] Remote thread %d opened with handle 0x%p\n", dwThreadId, hThread);

    // ... pass hThread to HijackThread (see SetThreadContext notes) ...

    CloseHandle(hThread);
}
```
