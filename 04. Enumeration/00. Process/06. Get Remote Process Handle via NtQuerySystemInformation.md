## Get Remote Process Handle via NtQuerySystemInformation

Resolves `NtQuerySystemInformation` at runtime from `ntdll.dll` using `GetProcAddress`, then calls it twice — first with a `NULL` buffer to retrieve the required allocation size, then again with a `HeapAlloc`-ed buffer to populate an array of `SYSTEM_PROCESS_INFORMATION` structures. Iterates through the array comparing each process name case-insensitively with `_wcsicmp` against the caller-supplied target, then opens a handle to the match with the caller-supplied access rights. The heap buffer is freed using the initial address saved before the loop.

**Usage**

Call `GetRemoteProcessHandle` with the target process name, a pointer to receive the PID, a pointer to receive the process handle, and the desired process access rights. On success, `*pdwPid` holds the matched PID and `*phProcess` holds an open handle with the requested access. The caller is responsible for closing `*phProcess` with `CloseHandle` after use.

- `IN LPCWSTR szProcName`  Wide-string name of the target process to search for (e.g. `L"notepad.exe"`). Case-insensitive.
- `OUT DWORD* pdwPid`  Receives the PID of the matched process.
- `OUT HANDLE* phProcess`  Receives the handle to the matched process opened with `dwDesiredAccess`.
- `IN DWORD dwDesiredAccess`  Access rights to request when opening the process handle (e.g. `PROCESS_ALL_ACCESS`, `PROCESS_VM_READ`).

**Return Value**

`BOOL`  Returns `TRUE` if the target process was found and a handle was successfully opened, otherwise `FALSE`.

- `windows.h`  `BOOL`, `DWORD`, `HANDLE`, `PVOID`, `ULONG`, `ULONG_PTR`, `NTSTATUS`, `LPCWSTR`, `PULONG`, `IN`, `OUT`, `GetProcAddress()`, `GetModuleHandleW()`, `HeapAlloc()`, `HeapFree()`, `GetProcessHeap()`, `OpenProcess()`, `GetLastError()`

### Code

```c
#include <windows.h>
#include <winternl.h>
#include <stdio.h>


// Function pointer type for NtQuerySystemInformation resolved at runtime.
typedef NTSTATUS (NTAPI* fnNtQuerySystemInformation)(
    SYSTEM_INFORMATION_CLASS    SystemInformationClass,
    PVOID                       SystemInformation,
    ULONG                       SystemInformationLength,
    PULONG                      ReturnLength
);


BOOL GetRemoteProcessHandle(IN LPCWSTR szProcName, OUT DWORD* pdwPid, OUT HANDLE* phProcess, IN DWORD dwDesiredAccess) {

    fnNtQuerySystemInformation  pNtQuerySystemInformation   = NULL;
    ULONG                       uReturnLen1                 = NULL,
                                uReturnLen2                 = NULL;
    PSYSTEM_PROCESS_INFORMATION SystemProcInfo              = NULL;
    NTSTATUS                    STATUS                      = NULL;
    PVOID                       pValueToFree                = NULL;

    // Resolve NtQuerySystemInformation's address from ntdll.dll at runtime.
    pNtQuerySystemInformation = (fnNtQuerySystemInformation)GetProcAddress(
        GetModuleHandle(L"NTDLL.DLL"),
        "NtQuerySystemInformation"
    );
    if (pNtQuerySystemInformation == NULL) {
        printf("[!] GetProcAddress Failed With Error : %d\n", GetLastError());
        return FALSE;
    }

    // First call: pass NULL buffer to retrieve the required allocation size.
    // Expected to fail with STATUS_INFO_LENGTH_MISMATCH (0xC0000004).
    pNtQuerySystemInformation(SystemProcessInformation, NULL, NULL, &uReturnLen1);

    // Allocate a buffer large enough to hold the full SYSTEM_PROCESS_INFORMATION array.
    SystemProcInfo = (PSYSTEM_PROCESS_INFORMATION)HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, (SIZE_T)uReturnLen1);
    if (SystemProcInfo == NULL) {
        printf("[!] HeapAlloc Failed With Error : %d\n", GetLastError());
        return FALSE;
    }

    // Save the initial address before the loop so the buffer can be freed after iteration.
    pValueToFree = SystemProcInfo;

    // Second call: populate the allocated buffer with the process information array.
    STATUS = pNtQuerySystemInformation(SystemProcessInformation, SystemProcInfo, uReturnLen1, &uReturnLen2);
    if (STATUS != 0x0) {
        printf("[!] NtQuerySystemInformation Failed With Error : 0x%0.8X \n", STATUS);
        HeapFree(GetProcessHeap(), 0, pValueToFree);
        return FALSE;
    }

    while (TRUE) {

        // Skip entries with no image name and compare case-insensitively against the target.
        if (SystemProcInfo->ImageName.Length && _wcsicmp(SystemProcInfo->ImageName.Buffer, szProcName) == 0) {

            // Match found — save the PID and open a handle with the caller-supplied access rights.
            *pdwPid     = (DWORD)SystemProcInfo->UniqueProcessId;
            *phProcess  = OpenProcess(
                dwDesiredAccess,  // Access rights supplied by the caller.
                FALSE,  // Do not inherit the handle.
                (DWORD)SystemProcInfo->UniqueProcessId  // PID of the matched process.
            );
            break;
        }

        // NextEntryOffset of 0 signals the end of the array.
        if (!SystemProcInfo->NextEntryOffset)
            break;

        // Advance to the next SYSTEM_PROCESS_INFORMATION element in the array.
        SystemProcInfo = (PSYSTEM_PROCESS_INFORMATION)((ULONG_PTR)SystemProcInfo + SystemProcInfo->NextEntryOffset);
    }

    // Free using the initial address saved before the loop.
    HeapFree(GetProcessHeap(), 0, pValueToFree);

    // Return FALSE if either output was not populated.
    if (*pdwPid == NULL || *phProcess == NULL)
        return FALSE;
    else
        return TRUE;
}
```

**Example**

```c
DWORD  dwProcessId = 0;
HANDLE hProcess    = NULL;

// Locate notepad.exe via NtQuerySystemInformation and open it with full access.
if (GetRemoteProcessHandle(
        L"notepad.exe",
        &dwProcessId,
        &hProcess,
        PROCESS_ALL_ACCESS
    ))
{
    printf("[+] Found PID %d with handle 0x%p\n", dwProcessId, hProcess);

    // ... use hProcess ...

    CloseHandle(hProcess);
}
```
