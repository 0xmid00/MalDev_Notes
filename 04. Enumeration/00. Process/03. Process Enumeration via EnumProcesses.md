## Process Enumeration via EnumProcesses

Enumerates all running processes using `EnumProcesses` to obtain a PID array, then for each valid PID opens a handle with `OpenProcess`, retrieves its first module handle via `EnumProcessModules`, and resolves the process name with `GetModuleBaseNameW`. Only processes accessible at the current privilege level are printed — attempts to open elevated processes will fail silently and be skipped.

**Usage**

Call `PrintProcesses` with no arguments. It prints the name and PID of every accessible process to stdout.

**Return Value**

`BOOL`  Returns `TRUE` if `EnumProcesses` succeeded and enumeration completed, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `DWORD`, `HANDLE`, `HMODULE`, `WCHAR`, `MAX_PATH`, `OpenProcess()`, `CloseHandle()`, `GetLastError()`
- `psapi.h`  `EnumProcesses()`, `EnumProcessModules()`, `GetModuleBaseNameW()`
- `stdio.h`  `printf()`, `wprintf()`


### Code

```c
#include <windows.h>
#include <psapi.h>
#include <stdio.h>


BOOL PrintProcesses() {

    DWORD   adwProcesses    [1024 * 2],
            dwReturnLen1    = NULL,
            dwReturnLen2    = NULL,
            dwNmbrOfPids    = NULL;

    HANDLE  hProcess        = NULL;
    HMODULE hModule         = NULL;

    WCHAR   szProc          [MAX_PATH];

    // Retrieve the array of PIDs for all running processes.
    if (!EnumProcesses(adwProcesses, sizeof(adwProcesses), &dwReturnLen1)) {
        printf("[!] EnumProcesses Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Calculate the number of PIDs returned by dividing the output byte count by the size of one DWORD.
    dwNmbrOfPids = dwReturnLen1 / sizeof(DWORD);

    printf("[i] Number Of Processes Detected : %d \n", dwNmbrOfPids);

    for (int i = 0; i < dwNmbrOfPids; i++) {

        // Skip NULL PID entries.
        if (adwProcesses[i] != NULL) {

            // Open a handle to the process with read and query access.
            if ((hProcess = OpenProcess(PROCESS_QUERY_INFORMATION | PROCESS_VM_READ, FALSE, adwProcesses[i])) != NULL) {

                // Retrieve the first module handle in the process — required by GetModuleBaseName.
                if (!EnumProcessModules(hProcess, &hModule, sizeof(HMODULE), &dwReturnLen2)) {
                    printf("[!] EnumProcessModules Failed [ At Pid: %d ] With Error : %d \n", adwProcesses[i], GetLastError());
                }
                else {
                    // Resolve the process name from its first module handle.
                    if (!GetModuleBaseName(hProcess, hModule, szProc, sizeof(szProc) / sizeof(WCHAR))) {
                        printf("[!] GetModuleBaseName Failed [ At Pid: %d ] With Error : %d \n", adwProcesses[i], GetLastError());
                    }
                    else {
                        // Print the process index, name, and PID.
                        wprintf(L"[%0.3d] Process \"%s\" - Of Pid : %d \n", i, szProc, adwProcesses[i]);
                    }
                }

                CloseHandle(hProcess);
            }
        }
    }

    return TRUE;
}
```

**Example**

```c
// Print the name and PID of every accessible running process.
PrintProcesses();
```
