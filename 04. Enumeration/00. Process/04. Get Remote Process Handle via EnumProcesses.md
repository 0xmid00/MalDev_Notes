## Get Remote Process Handle via EnumProcesses

Enumerates all running processes using `EnumProcesses` to obtain a PID array, then for each valid PID opens a handle with the caller-supplied access rights, retrieves its first module handle via `EnumProcessModules`, resolves the process name with `GetModuleBaseNameW`, and compares it case-insensitively against the caller-supplied target name using `_wcsicmp`. Returns the matching PID and process handle to the caller by reference on the first match.

**Usage**

Call `GetRemoteProcessHandle` with the target process name, a pointer to receive the PID, a pointer to receive the process handle, and the desired process access rights. On success, `*pdwPid` holds the matched PID and `*phProcess` holds an open handle with the requested access. The caller is responsible for closing `*phProcess` with `CloseHandle` after use.

- `IN LPCWSTR szProcName`  Wide-string name of the target process to search for (e.g. `L"notepad.exe"`). Case-insensitive.
- `OUT DWORD* pdwPid`  Receives the PID of the matched process.
- `OUT HANDLE* phProcess`  Receives the handle to the matched process opened with `dwDesiredAccess`.
- `IN DWORD dwDesiredAccess`  Access rights to request when opening the process handle (e.g. `PROCESS_ALL_ACCESS`, `PROCESS_VM_READ`).

**Return Value**

`BOOL`  Returns `TRUE` if the target process was found and a handle was successfully opened, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `DWORD`, `HANDLE`, `HMODULE`, `LPCWSTR`, `WCHAR`, `MAX_PATH`, `IN`, `OUT`, `OpenProcess()`, `CloseHandle()`, `GetLastError()`
- `psapi.h`  `EnumProcesses()`, `EnumProcessModules()`, `GetModuleBaseNameW()`
- `stdio.h`  `printf()`, `wprintf()`


### Code

```c
#include <windows.h>
#include <psapi.h>
#include <stdio.h>


BOOL GetRemoteProcessHandle(IN LPCWSTR szProcName, OUT DWORD* pdwPid, OUT HANDLE* phProcess, IN DWORD dwDesiredAccess) {

    DWORD   adwProcesses    [1024 * 2],
            dwReturnLen1    = NULL,
            dwReturnLen2    = NULL,
            dwNmbrOfPids    = NULL;

    HANDLE  hProcess        = NULL;
    HMODULE hModule         = NULL;

    WCHAR   szProc          [MAX_PATH];

    // Retrieve the array of PIDs for all running processes.
    if (!EnumProcesses(adwProcesses, sizeof(adwProcesses), &dwReturnLen1)) {
        printf("[!] EnumProcesses Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Calculate the number of PIDs returned by dividing the output byte count by the size of one DWORD.
    dwNmbrOfPids = dwReturnLen1 / sizeof(DWORD);

    printf("[i] Number Of Processes Detected : %d \n", dwNmbrOfPids);

    for (int i = 0; i < dwNmbrOfPids; i++) {

        // Skip NULL PID entries.
        if (adwProcesses[i] != NULL) {

            // Open a handle to the process with the caller-supplied access rights.
            if ((hProcess = OpenProcess(dwDesiredAccess, FALSE, adwProcesses[i])) != NULL) {

                // Retrieve the first module handle in the process — required by GetModuleBaseName.
                if (!EnumProcessModules(hProcess, &hModule, sizeof(HMODULE), &dwReturnLen2)) {
                    printf("[!] EnumProcessModules Failed [ At Pid: %d ] With Error : %d \n", adwProcesses[i], GetLastError());
                }
                else {
                    // Resolve the process name from its first module handle.
                    if (!GetModuleBaseName(hProcess, hModule, szProc, sizeof(szProc) / sizeof(WCHAR))) {
                        printf("[!] GetModuleBaseName Failed [ At Pid: %d ] With Error : %d \n", adwProcesses[i], GetLastError());
                    }
                    else {
                        // Case-insensitive comparison against the caller-supplied target name.
                        if (_wcsicmp(szProcName, szProc) == 0) {
                            wprintf(L"[+] FOUND \"%s\" - Of Pid : %d \n", szProc, adwProcesses[i]);
                            // Return the PID and handle to the caller by reference.
                            *pdwPid     = adwProcesses[i];
                            *phProcess  = hProcess;
                            break;
                        }
                    }
                }

                CloseHandle(hProcess);
            }
        }
    }

    // Return FALSE if either output was not populated.
    if (*pdwPid == NULL || *phProcess == NULL)
        return FALSE;
    else
        return TRUE;
}
```

**Example**

```c
DWORD  dwProcessId = 0;
HANDLE hProcess    = NULL;

// Open a handle to notepad.exe with full access rights.
if (GetRemoteProcessHandle(
        L"notepad.exe",
        &dwProcessId,
        &hProcess,
        PROCESS_ALL_ACCESS
    ))
{
    printf("[+] Found PID %d with handle 0x%p\n", dwProcessId, hProcess);

    // ... use hProcess ...

    CloseHandle(hProcess);
}
```
