## Process Enumeration via NtQuerySystemInformation

Resolves `NtQuerySystemInformation` at runtime from `ntdll.dll` using `GetProcAddress`, then calls it twice — first with a `NULL` buffer to retrieve the required allocation size, then again with a `HeapAlloc`-ed buffer to populate an array of `SYSTEM_PROCESS_INFORMATION` structures. Iterates through the array printing each process name and PID to stdout. The heap buffer is freed using the initial address saved before the loop.

**Usage**

Call `PrintProcesses` with no arguments. It prints the name and PID of every process visible to `NtQuerySystemInformation` to stdout.

**Return Value**

`BOOL`  Returns `TRUE` if enumeration completed successfully, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `PVOID`, `ULONG`, `ULONG_PTR`, `NTSTATUS`, `PULONG`, `GetProcAddress()`, `GetModuleHandleW()`, `HeapAlloc()`, `HeapFree()`, `GetProcessHeap()`, `GetLastError()`
- `winternl.h`  `SYSTEM_PROCESS_INFORMATION`, `PSYSTEM_PROCESS_INFORMATION`, `SYSTEM_INFORMATION_CLASS`, `SystemProcessInformation`, `UNICODE_STRING`
- `stdio.h`  `printf()`, `wprintf()`


### Code

```c
#include <windows.h>
#include <winternl.h>
#include <stdio.h>


// Function pointer type for NtQuerySystemInformation resolved at runtime.
typedef NTSTATUS (NTAPI* fnNtQuerySystemInformation)(
    SYSTEM_INFORMATION_CLASS    SystemInformationClass,
    PVOID                       SystemInformation,
    ULONG                       SystemInformationLength,
    PULONG                      ReturnLength
);


BOOL PrintProcesses() {

    fnNtQuerySystemInformation  pNtQuerySystemInformation   = NULL;
    ULONG                       uReturnLen1                 = NULL,
                                uReturnLen2                 = NULL;
    PSYSTEM_PROCESS_INFORMATION SystemProcInfo              = NULL;
    NTSTATUS                    STATUS                      = NULL;
    PVOID                       pValueToFree                = NULL;

    // Resolve NtQuerySystemInformation's address from ntdll.dll at runtime.
    pNtQuerySystemInformation = (fnNtQuerySystemInformation)GetProcAddress(
        GetModuleHandle(L"NTDLL.DLL"),
        "NtQuerySystemInformation"
    );
    if (pNtQuerySystemInformation == NULL) {
        printf("[!] GetProcAddress Failed With Error : %d\n", GetLastError());
        return FALSE;
    }

    // First call: pass NULL buffer to retrieve the required allocation size.
    // Expected to fail with STATUS_INFO_LENGTH_MISMATCH (0xC0000004).
    pNtQuerySystemInformation(SystemProcessInformation, NULL, NULL, &uReturnLen1);

    // Allocate a buffer large enough to hold the full SYSTEM_PROCESS_INFORMATION array.
    SystemProcInfo = (PSYSTEM_PROCESS_INFORMATION)HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, (SIZE_T)uReturnLen1);
    if (SystemProcInfo == NULL) {
        printf("[!] HeapAlloc Failed With Error : %d\n", GetLastError());
        return FALSE;
    }

    // Save the initial address before the loop so the buffer can be freed after iteration.
    pValueToFree = SystemProcInfo;

    // Second call: populate the allocated buffer with the process information array.
    STATUS = pNtQuerySystemInformation(SystemProcessInformation, SystemProcInfo, uReturnLen1, &uReturnLen2);
    if (STATUS != 0x0) {
        printf("[!] NtQuerySystemInformation Failed With Error : 0x%0.8X \n", STATUS);
        HeapFree(GetProcessHeap(), 0, pValueToFree);
        return FALSE;
    }

    while (TRUE) {

        // Print the process name and PID if the entry has a valid image name.
        if (SystemProcInfo->ImageName.Length) {
            wprintf(L"[+] Process \"%s\" - PID : %d \n",
                SystemProcInfo->ImageName.Buffer,
                (DWORD)SystemProcInfo->UniqueProcessId
            );
        }

        // NextEntryOffset of 0 signals the end of the array.
        if (!SystemProcInfo->NextEntryOffset)
            break;

        // Advance to the next SYSTEM_PROCESS_INFORMATION element in the array.
        SystemProcInfo = (PSYSTEM_PROCESS_INFORMATION)((ULONG_PTR)SystemProcInfo + SystemProcInfo->NextEntryOffset);
    }

    // Free using the initial address saved before the loop.
    HeapFree(GetProcessHeap(), 0, pValueToFree);

    return TRUE;
}
```

**Example**

```c
// Query every running process via the NTAPI and print name + PID.
PrintProcesses();
```
