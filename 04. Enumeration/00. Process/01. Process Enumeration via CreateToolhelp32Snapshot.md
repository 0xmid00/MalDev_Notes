## Process Enumeration via CreateToolhelp32Snapshot

Enumerates all running processes using `CreateToolhelp32Snapshot` with the `TH32CS_SNAPPROCESS` flag, iterates through the snapshot with `Process32First` and `Process32Next`, and prints the name and PID of every process in the snapshot to stdout.

**Usage**

Call `PrintProcesses` with no arguments. It prints the name and PID of every process currently visible in the snapshot to stdout.

**Return Value**

`BOOL`  Returns `TRUE` if the snapshot was successfully created and enumeration completed, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `CloseHandle()`, `GetLastError()`
- `tlhelp32.h`  `PROCESSENTRY32`, `CreateToolhelp32Snapshot()`, `Process32First()`, `Process32Next()`
- `stdio.h`  `printf()`, `wprintf()`


### Code

```c
#include <windows.h>
#include <tlhelp32.h>
#include <stdio.h>


BOOL PrintProcesses() {

    // dwSize must be set before calling Process32First, per Microsoft documentation.
    PROCESSENTRY32 Proc = {
        .dwSize = sizeof(PROCESSENTRY32)
    };

    HANDLE hSnapShot = NULL;

    // Take a snapshot of all currently running processes.
    hSnapShot = CreateToolhelp32Snapshot(
        TH32CS_SNAPPROCESS, // Include all processes in the snapshot.
        NULL                // Snapshot the entire system, not a specific process.
    );
    if (hSnapShot == INVALID_HANDLE_VALUE) {
        printf("[!] CreateToolhelp32Snapshot Failed With Error : %d \n", GetLastError());
        goto _EndOfFunction;
    }

    // Seed the loop with the first process entry from the snapshot.
    if (!Process32First(hSnapShot, &Proc)) {
        printf("[!] Process32First Failed With Error : %d \n", GetLastError());
        goto _EndOfFunction;
    }

    do {
        // Print the process name and PID for each entry in the snapshot.
        wprintf(L"[+] Process \"%s\" - PID : %d \n", Proc.szExeFile, Proc.th32ProcessID);

    // Advance to the next process entry in the snapshot.
    } while (Process32Next(hSnapShot, &Proc));

_EndOfFunction:
    if (hSnapShot != NULL)
        CloseHandle(hSnapShot);
    return TRUE;
}
```

**Example**

```c
// Snapshot every running process and print its name + PID to stdout.
PrintProcesses();
```
