## Remote Process Enumeration via CreateToolhelp32Snapshot

Enumerates all running processes using a `CreateToolhelp32Snapshot` snapshot and locates a target process by name using a **case-insensitive comparison**. The caller specifies the desired process access rights through the `dwDesiredAccess` parameter, allowing the function to request permissions such as `PROCESS_QUERY_INFORMATION`, `PROCESS_VM_READ`, or `PROCESS_ALL_ACCESS`.

**Usage**

Call `GetRemoteProcessHandle` with the target process name, desired access rights, and two `OUT` pointers that receive the process ID and process handle. The process name comparison is case-insensitive, so the target name does not need to be lowercase. The caller is responsible for closing `hProcess` with `CloseHandle()` when it is no longer needed.

- `IN LPCWSTR szProcessName` Name of the target process to find. Comparison is case-insensitive (e.g. `L"Notepad.exe"` or `L"notepad.exe"`).
    
- `IN DWORD dwDesiredAccess` Access rights requested for the target process (e.g. `PROCESS_QUERY_INFORMATION`, `PROCESS_VM_READ`, `PROCESS_ALL_ACCESS`).
    
- `OUT DWORD* dwProcessId` Receives the process ID of the matched process.
    
- `OUT HANDLE* hProcess` Receives a handle to the matched process with the requested access rights.
    

**Return Value**

`BOOL` Returns `TRUE` if the target process was found and a valid handle was opened, otherwise `FALSE`.

**External Files**

- `windows.h` `LPCWSTR`, `DWORD`, `HANDLE`, `BOOL`, `IN`, `OUT`, `OpenProcess()`, `CloseHandle()`, `GetLastError()`
    
- `tlhelp32.h` `PROCESSENTRY32`, `CreateToolhelp32Snapshot()`, `Process32First()`, `Process32Next()`
    
- `stdio.h` `printf()`
    


### Code

```c
#include <windows.h>
#include <tlhelp32.h>
#include <stdio.h>


BOOL GetRemoteProcessHandle(
    IN LPCWSTR szProcessName,
    IN DWORD   dwDesiredAccess,
    OUT DWORD* dwProcessId,
    OUT HANDLE* hProcess
)
{
    // Initialize output parameters.
    *dwProcessId = 0;
    *hProcess    = NULL;

    // dwSize must be set before calling Process32First.
    PROCESSENTRY32 Proc = {
        .dwSize = sizeof(PROCESSENTRY32)
    };

    HANDLE hSnapShot = NULL;

    // Take a snapshot of all currently running processes.
    hSnapShot = CreateToolhelp32Snapshot(
        TH32CS_SNAPPROCESS,
        NULL
    );
    if (hSnapShot == INVALID_HANDLE_VALUE) {
        printf("[!] CreateToolhelp32Snapshot Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Seed the loop with the first process entry.
    if (!Process32First(hSnapShot, &Proc)) {
        printf("[!] Process32First Failed With Error : %d \n", GetLastError());
        CloseHandle(hSnapShot);
        return FALSE;
    }

    do {

        // Compare process names case-insensitively.
        if (_wcsicmp(Proc.szExeFile, szProcessName) == 0) {

            // Save the matched process ID.
            *dwProcessId = Proc.th32ProcessID;

            // Open the process with the access rights requested by the caller.
            *hProcess = OpenProcess(
                dwDesiredAccess,
                FALSE,
                Proc.th32ProcessID
            );

            if (*hProcess == NULL) {
                printf("[!] OpenProcess Failed With Error : %d \n", GetLastError());
                CloseHandle(hSnapShot);
                return FALSE;
            }

            break;
        }

    } while (Process32Next(hSnapShot, &Proc));

    CloseHandle(hSnapShot);

    // The process was not found.
    if (*hProcess == NULL)
        return FALSE;

    return TRUE;
}
```

**Example**

```c
DWORD dwProcessId = 0;
HANDLE hProcess = NULL;

if (GetRemoteProcessHandle(
        L"Notepad.exe",
        PROCESS_ALL_ACCESS,
        &dwProcessId,
        &hProcess
    ))
{
    printf("[+] Process Found : PID %d\n", dwProcessId);

    // Use hProcess...

    CloseHandle(hProcess);
}
```
