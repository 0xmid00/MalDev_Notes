## Payload Execution Control via Mutex

Prevents duplicate payload execution by creating a named mutex with `CreateMutexA` on each run. The first execution creates the mutex and proceeds. Every subsequent execution finds the mutex already exists — `GetLastError` returns `ERROR_ALREADY_EXISTS` — and skips the payload. The mutex persists for the lifetime of the process, ensuring the payload runs at most once per process instance.

**Usage**

Call `IsPayloadRunning` before executing the payload. If it returns `FALSE` the payload has not yet run and execution should proceed. If it returns `TRUE` a previous instance is already running and execution should be skipped. Define `PAYLOAD_CONTROL_STRING` as a unique name to avoid collisions with other applications.

- No parameters — the control string is taken from the `PAYLOAD_CONTROL_STRING` macro defined at compile time.

**Return Value**

`BOOL`  Returns `TRUE` if the named mutex already existed (payload is already running), otherwise `FALSE` (safe to execute the payload).

**External Files**

- `windows.h`  `HANDLE`, `BOOL`, `CreateMutexA()`, `GetLastError()`, `ERROR_ALREADY_EXISTS`

### Code

```c
#include <windows.h>

#define PAYLOAD_CONTROL_STRING  "MaldevAcademy"   // Unique name; change per project.


BOOL IsPayloadRunning()
{
    // Create a named mutex.
    // If the mutex name already exists in the system, CreateMutexA returns
    // a handle to the existing object and GetLastError returns ERROR_ALREADY_EXISTS.
    HANDLE hMutex = CreateMutexA(
        NULL,                   // Default security attributes.
        FALSE,                  // Caller does not request immediate ownership.
        PAYLOAD_CONTROL_STRING  // Named mutex — survives across calls in the same session.
    );

    if (hMutex != NULL && GetLastError() == ERROR_ALREADY_EXISTS)
        return TRUE;    // Mutex already existed — payload is already running.
    else
        return FALSE;   // Mutex was just created — payload is not yet running.
}
```

**Example**

```c
if (!IsPayloadRunning()) {
    // First execution — proceed with payload.
    CreateThread(NULL, NULL, Payload, NULL, NULL, NULL);
}
else {
    // Subsequent execution — payload already running, skip.
    printf("[+] Payload Is Already Running \n");
}
```

**Parameter Sources**

No external parameters — the control string is a compile-time macro.
