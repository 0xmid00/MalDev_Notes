## Payload Execution Control via Event

Prevents duplicate payload execution by creating a named event with `CreateEventA` on each run. The first execution creates the event and proceeds. Every subsequent execution finds the event already exists — `GetLastError` returns `ERROR_ALREADY_EXISTS` — and skips the payload. The event persists for the lifetime of the process, ensuring the payload runs at most once per process instance.

**Usage**

Call `IsPayloadRunning` before executing the payload. If it returns `FALSE` the payload has not yet run and execution should proceed. If it returns `TRUE` a previous instance is already running and execution should be skipped. Define `PAYLOAD_CONTROL_STRING` as a unique name to avoid collisions with other applications.

- No parameters — the control string is taken from the `PAYLOAD_CONTROL_STRING` macro defined at compile time.

**Return Value**

`BOOL`  Returns `TRUE` if the named event already existed (payload is already running), otherwise `FALSE` (safe to execute the payload).

**External Files**

- `windows.h`  `HANDLE`, `BOOL`, `CreateEventA()`, `GetLastError()`, `ERROR_ALREADY_EXISTS`

### Code

```c
#include <windows.h>

#define PAYLOAD_CONTROL_STRING  "MaldevAcademy"   // Unique name; change per project.


BOOL IsPayloadRunning()
{
    // Create a named auto-reset event in a non-signaled initial state.
    // If the event name already exists in the system, CreateEventA returns
    // a handle to the existing object and GetLastError returns ERROR_ALREADY_EXISTS.
    HANDLE hEvent = CreateEventA(
        NULL,                   // Default security attributes.
        FALSE,                  // Auto-reset: resets automatically after a waiting thread is released.
        FALSE,                  // Initial state: non-signaled.
        PAYLOAD_CONTROL_STRING  // Named event — survives across calls in the same session.
    );

    if (hEvent != NULL && GetLastError() == ERROR_ALREADY_EXISTS)
        return TRUE;    // Event already existed — payload is already running.
    else
        return FALSE;   // Event was just created — payload is not yet running.
}
```

**Example**

```c
if (!IsPayloadRunning()) {
    // First execution — proceed with payload.
    CreateThread(NULL, NULL, Payload, NULL, NULL, NULL);
}
else {
    // Subsequent execution — payload already running, skip.
    printf("[+] Payload Is Already Running \n");
}
```

**Parameter Sources**

No external parameters — the control string is a compile-time macro.
