## Payload Execution Control via Semaphore

Prevents duplicate payload execution by creating a named semaphore with `CreateSemaphoreA` on each run. The first execution creates the semaphore and proceeds. Every subsequent execution finds the semaphore already exists — `GetLastError` returns `ERROR_ALREADY_EXISTS` — and skips the payload. The semaphore persists for the lifetime of the process, ensuring the payload runs at most once per process instance.

**Usage**

Call `IsPayloadRunning` before executing the payload. If it returns `FALSE` the payload has not yet run and execution should proceed. If it returns `TRUE` a previous instance is already running and execution should be skipped. Define `PAYLOAD_CONTROL_STRING` as a unique name to avoid collisions with other applications.

- No parameters — the control string is taken from the `PAYLOAD_CONTROL_STRING` macro defined at compile time.

**Return Value**

`BOOL`  Returns `TRUE` if the named semaphore already existed (payload is already running), otherwise `FALSE` (safe to execute the payload).

**External Files**

- `windows.h`  `HANDLE`, `BOOL`, `CreateSemaphoreA()`, `GetLastError()`, `ERROR_ALREADY_EXISTS`

### Code

```c
#include <windows.h>

#define PAYLOAD_CONTROL_STRING  "MaldevAcademy"   // Unique name; change per project.


BOOL IsPayloadRunning()
{
    // Create a named counting semaphore with an initial and maximum count of 10.
    // If the semaphore name already exists in the system, CreateSemaphoreA returns
    // a handle to the existing object and GetLastError returns ERROR_ALREADY_EXISTS.
    HANDLE hSemaphore = CreateSemaphoreA(
        NULL,                   // Default security attributes.
        10,                     // Initial count.
        10,                     // Maximum count.
        PAYLOAD_CONTROL_STRING  // Named semaphore — survives across calls in the same session.
    );

    if (hSemaphore != NULL && GetLastError() == ERROR_ALREADY_EXISTS)
        return TRUE;    // Semaphore already existed — payload is already running.
    else
        return FALSE;   // Semaphore was just created — payload is not yet running.
}
```

**Example**

```c
if (!IsPayloadRunning()) {
    // First execution — proceed with payload.
    CreateThread(NULL, NULL, Payload, NULL, NULL, NULL);
}
else {
    // Subsequent execution — payload already running, skip.
    printf("[+] Payload Is Already Running \n");
}
```

**Parameter Sources**

No external parameters — the control string is a compile-time macro.
