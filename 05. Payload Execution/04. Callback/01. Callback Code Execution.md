## Callback Code Execution

Executes a payload by passing its address as a callback function pointer to a Windows API that accepts one. The payload is placed in the `.text` section of the binary using `__declspec(allocate(".text"))` so it inherits the section's `RX` permissions without needing `VirtualAlloc` or `VirtualProtect`. Only works in the local process address space. Uncomment one variant — each abuses a different API's callback parameter.

⚠️ **Variant 1 (`CreateTimerQueueTimer`) fires asynchronously** on a thread pool thread — the process must be kept alive after the call or the callback will never execute. The other three variants are synchronous and fire inline during the call.

**Usage**

Call `RunViaCallbackExecution` with the base address of the payload. The payload must reside in executable memory — place it in the `.text` section as shown in the example or allocate `RWX` memory manually beforehand. For Variant 1, keep the process alive after the call with `getchar()` or `Sleep`.

- `IN PVOID pPayload`  Base address of the payload to execute via callback.

**Return Value**

`BOOL`  Returns `TRUE` if the chosen callback API succeeded, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `HANDLE`, `PVOID`, `HMODULE`, `IN`, `WAITORTIMERCALLBACK`, `WNDENUMPROC`, `UILANGUAGE_ENUMPROCW`, `MUI_LANGUAGE_NAME`, `CreateTimerQueueTimer()`, `EnumChildWindows()`, `EnumUILanguagesW()`, `LoadLibraryA()`, `GetProcAddress()`, `GetCurrentProcess()`, `GetLastError()`

**Example**

```c
// Place the payload in the .text section so it inherits RX permissions
// without needing VirtualAlloc or VirtualProtect.
#pragma section(".text")
__declspec(allocate(".text")) const unsigned char Payload[] = {
    0xFC, 0x48, 0x83, 0xE4, /* ... */
};

RunViaCallbackExecution((PVOID)Payload);

// Required for Variant 1 (CreateTimerQueueTimer) — keeps the process alive
// so the async thread pool callback has time to fire before the process exits.
// Safe to include for all variants; has no effect on synchronous ones.
getchar();
```
