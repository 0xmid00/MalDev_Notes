## Local DLL Payload Execution via LoadLibraryA

Loads a DLL file from disk into the current process using `LoadLibraryA`, triggering the DLL's `DllMain` entry point and any payload embedded in its `DLL_PROCESS_ATTACH` handler. The DLL path is supplied by the caller at runtime.

**Usage**

Call `LoadLocalDll` with the full or relative path to the DLL file on disk. The DLL is mapped into the calling process and its entry point runs immediately.

- `IN LPCSTR szDllPath`  Null-terminated path to the DLL file to load; can be a full path or a filename if the DLL is in the current directory or system search path.

**Return Value**

`BOOL`  Returns `TRUE` if the DLL was loaded successfully, otherwise `FALSE`.

**External Files**

- `windows.h`  `LPCSTR`, `BOOL`, `IN`, `HMODULE`, `LoadLibraryA()`, `GetLastError()`, `GetCurrentProcessId()`
- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL LoadLocalDll(IN LPCSTR szDllPath)
{
    if (szDllPath == NULL)
        return FALSE;

    printf("[i] Loading \"%s\" Into The Current Process [ PID: %d ] \n", szDllPath, GetCurrentProcessId());

    // Load the DLL from disk into the current process.
    // This triggers DllMain with DLL_PROCESS_ATTACH, running the embedded payload.
    HMODULE hModule = LoadLibraryA(
        szDllPath   // Full or relative path to the DLL file on disk.
    );
    if (hModule == NULL) {
        printf("[!] LoadLibraryA Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("[+] DLL Loaded Successfully At Base Address: 0x%p \n", (PVOID)hModule);

    return TRUE;
}
```

**Example**

```c
// Load a payload DLL into the current process; its DllMain (DLL_PROCESS_ATTACH)
// fires immediately and runs the embedded payload.
LoadLocalDll("C:\\payloads\\PayloadDll.dll");
```
