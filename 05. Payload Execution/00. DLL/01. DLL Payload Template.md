## DLL Payload Template

A minimal DLL skeleton that executes a payload function when the DLL is loaded into a process. `MsgBoxPayload` is called from `DLL_PROCESS_ATTACH` inside `DllMain`, ensuring the payload runs automatically the moment the DLL is mapped. Replace `MsgBoxPayload` with any shellcode execution, hook installation, or other operation required by the target project.

**Usage**

Build this file as a DLL project. The payload in `MsgBoxPayload` runs automatically when the DLL is loaded by any process via `LoadLibraryA` or any other load mechanism. No explicit call is needed from the loader.

- `HMODULE hModule`  Handle to the DLL module; supplied by the OS loader.
- `DWORD dwReason`  Reason code for the call (`DLL_PROCESS_ATTACH`, `DLL_THREAD_ATTACH`, etc.).
- `LPVOID lpReserved`  Reserved; `NULL` for dynamic loads, non-`NULL` for static loads.

**Return Value**

`BOOL`  `DllMain` returns `TRUE` to signal successful initialisation. Returning `FALSE` on `DLL_PROCESS_ATTACH` causes the load to fail.

**External Files**

- `windows.h`  `HMODULE`, `DWORD`, `LPVOID`, `BOOL`, `APIENTRY`, `MessageBoxA()`
- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


VOID MsgBoxPayload()
{
    // Replace this with the intended payload logic.
    MessageBoxA(
        NULL,                       // No owner window.
        "Hacking With MaldevAcademy", // Message body.
        "Wow !",                    // Title bar text.
        MB_OK | MB_ICONINFORMATION  // OK button with info icon.
    );
}


BOOL APIENTRY DllMain(HMODULE hModule, DWORD dwReason, LPVOID lpReserved)
{
    switch (dwReason) {

        case DLL_PROCESS_ATTACH: {
            // Runs once when the DLL is first mapped into the process.
            // Execute the payload here.
            MsgBoxPayload();
            break;
        }

        case DLL_THREAD_ATTACH:
        case DLL_THREAD_DETACH:
        case DLL_PROCESS_DETACH:
            break;
    }

    return TRUE;
}
```

**Example**

```c
// The payload auto-runs from DllMain's DLL_PROCESS_ATTACH handler.
// Loading the compiled DLL into the current process triggers MsgBoxPayload.
LoadLibraryA("C:\\payloads\\PayloadDll.dll");
```
