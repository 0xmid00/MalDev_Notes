## PPID Spoofing 

Creates a new child process with a spoofed Parent Process ID (PPID) by building a `STARTUPINFOEXA` structure whose attribute list is updated with `PROC_THREAD_ATTRIBUTE_PARENT_PROCESS`. The attribute list is initialized with two calls to `InitializeProcThreadAttributeList` — the first determines the required buffer size and the second performs the initialization — then `UpdateProcThreadAttribute` sets the desired parent handle. `CreateProcessA` is finally called with `EXTENDED_STARTUPINFO_PRESENT` to honour the attribute list, making the child appear in tools such as Process Hacker as a child of the spoofed parent rather than the true caller.

**Usage**

Call `CreatePPidSpoofedProcess` with a handle to the desired parent process, the name of the executable to spawn (resolved under `%WINDIR%\System32\`), and three `OUT` pointers that receive the new process's PID, process handle, and thread handle.

- `IN HANDLE hParentProcess`  A handle to the process that will appear as the parent of the newly created process.
- `IN LPCSTR lpProcessName`  Name of the executable to create (e.g. `"RuntimeBroker.exe"`); resolved to `%WINDIR%\System32\<name>` internally.
- `OUT DWORD* dwProcessId`  Receives the PID of the newly created process.
- `OUT HANDLE* hProcess`  Receives a handle to the newly created process.
- `OUT HANDLE* hThread`  Receives a handle to the primary thread of the newly created process.

**Return Value**

`BOOL`  Returns `TRUE` if the process was created successfully and all three `OUT` parameters are populated, otherwise `FALSE`.

**External Files**

- `windows.h`  `HANDLE`, `LPCSTR`, `DWORD`, `BOOL`, `SIZE_T`, `CHAR`, `PPROC_THREAD_ATTRIBUTE_LIST`, `STARTUPINFOEXA`, `PROCESS_INFORMATION`, `IN`, `OUT`, `CreateProcessA()`, `InitializeProcThreadAttributeList()`, `UpdateProcThreadAttribute()`, `DeleteProcThreadAttributeList()`, `HeapAlloc()`, `GetProcessHeap()`, `GetEnvironmentVariableA()`, `RtlSecureZeroMemory()`, `CloseHandle()`, `GetLastError()`

### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL CreatePPidSpoofedProcess(IN HANDLE hParentProcess, IN LPCSTR lpProcessName, OUT DWORD* dwProcessId, OUT HANDLE* hProcess, OUT HANDLE* hThread)
{
    CHAR                        lpPath          [MAX_PATH * 2];
    CHAR                        WnDr            [MAX_PATH];

    SIZE_T                      sThreadAttList  = NULL;
    PPROC_THREAD_ATTRIBUTE_LIST pThreadAttList  = NULL;

    STARTUPINFOEXA              SiEx            = { 0 };
    PROCESS_INFORMATION         Pi              = { 0 };

    RtlSecureZeroMemory(&SiEx, sizeof(STARTUPINFOEXA));
    RtlSecureZeroMemory(&Pi,   sizeof(PROCESS_INFORMATION));

    // cb must be set to sizeof(STARTUPINFOEXA) when using EXTENDED_STARTUPINFO_PRESENT.
    SiEx.StartupInfo.cb = sizeof(STARTUPINFOEXA);

    // Build the full path to the target executable under System32.
    if (!GetEnvironmentVariableA("WINDIR", WnDr, MAX_PATH)) {
        printf("[!] GetEnvironmentVariableA Failed With Error : %d \n", GetLastError());
        return FALSE;
    }
    sprintf(lpPath, "%s\\System32\\%s", WnDr, lpProcessName);

    // First call: pass NULL for lpAttributeList to query the required buffer size.
    // This call is expected to fail with ERROR_INSUFFICIENT_BUFFER.
    InitializeProcThreadAttributeList(
        NULL,               // NULL — size-query call.
        1,                  // Number of attributes to store (one: parent process).
        NULL,               // Reserved — must be NULL.
        &sThreadAttList     // Receives the required buffer size in bytes.
    );

    // Allocate the attribute list buffer using the size returned above.
    pThreadAttList = (PPROC_THREAD_ATTRIBUTE_LIST)HeapAlloc(
        GetProcessHeap(),       // Use the process default heap.
        HEAP_ZERO_MEMORY,       // Zero the allocation.
        sThreadAttList          // Size determined by the first InitializeProcThreadAttributeList call.
    );
    if (pThreadAttList == NULL) {
        printf("[!] HeapAlloc Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Second call: pass the allocated buffer to perform the actual initialization.
    if (!InitializeProcThreadAttributeList(
        pThreadAttList,     // Allocated attribute list buffer.
        1,                  // Number of attributes (one: parent process).
        NULL,               // Reserved — must be NULL.
        &sThreadAttList     // Size of the buffer; must match the first call's output.
    )) {
        printf("[!] InitializeProcThreadAttributeList Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Set the PPID attribute: tell the OS which process should appear as the parent.
    if (!UpdateProcThreadAttribute(
        pThreadAttList,                         // Initialized attribute list to update.
        NULL,                                   // Reserved — must be NULL.
        PROC_THREAD_ATTRIBUTE_PARENT_PROCESS,   // Attribute to set: parent process override.
        &hParentProcess,                        // Pointer to the parent process handle.
        sizeof(HANDLE),                         // Size of the attribute value.
        NULL,                                   // Reserved — must be NULL.
        NULL                                    // Reserved — must be NULL.
    )) {
        printf("[!] UpdateProcThreadAttribute Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Attach the populated attribute list to the STARTUPINFOEXA structure.
    SiEx.lpAttributeList = pThreadAttList;

    // Create the process with EXTENDED_STARTUPINFO_PRESENT so CreateProcess
    // reads lpAttributeList from SiEx and applies the spoofed parent.
    if (!CreateProcessA(
        NULL,                           // No application name — use lpCommandLine.
        lpPath,                         // Full path to the executable to create.
        NULL,                           // Default process security attributes.
        NULL,                           // Default thread security attributes.
        FALSE,                          // Do not inherit handles.
        EXTENDED_STARTUPINFO_PRESENT,   // Required to honour lpAttributeList in SiEx.
        NULL,                           // Inherit parent's environment block.
        NULL,                           // Set to a specific path to change current directory.
        &SiEx.StartupInfo,              // Pointer to STARTUPINFOEXA cast as STARTUPINFOA.
        &Pi                             // Receives the new process and thread handles.
    )) {
        printf("[!] CreateProcessA Failed with Error : %d \n", GetLastError());
        return FALSE;
    }

    *dwProcessId    = Pi.dwProcessId;
    *hProcess       = Pi.hProcess;
    *hThread        = Pi.hThread;

    // Clean up the attribute list and close the parent handle — no longer needed.
    DeleteProcThreadAttributeList(pThreadAttList);
    CloseHandle(hParentProcess);

    if (*dwProcessId != NULL && *hProcess != NULL && *hThread != NULL)
        return TRUE;

    return FALSE;
}
```

**Example**

```c
HANDLE  hParentProcess  = NULL;
DWORD   dwParentPid     = 0;
DWORD   dwChildPid      = 0;
HANDLE  hChildProcess   = NULL;
HANDLE  hChildThread    = NULL;

// Step 1 — get a handle to the process that will appear as the parent.
GetRemoteProcessHandle(L"svchost.exe", &dwParentPid, &hParentProcess);

// Step 2 — spawn the child with the spoofed PPID.
CreatePPidSpoofedProcess(
    hParentProcess,         // Process that will appear as the parent.
    "RuntimeBroker.exe",    // Executable to create under System32.
    &dwChildPid,            // Receives the child's PID.
    &hChildProcess,         // Receives the child's process handle.
    &hChildThread           // Receives the child's thread handle.
);
```
