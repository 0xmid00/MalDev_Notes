## Syscalls Userland Hooking via MinHook (EDR Simulation)

Demonstrates how EDRs install userland hooks on NTDLL syscall stubs to intercept and monitor API calls at runtime. The DLL hooks `NtProtectVirtualMemory` using the MinHook library — the same technique real EDRs use to intercept higher-level WinAPIs such as `VirtualProtect` even when they are hidden from the IAT. `HookedNtProtectVirtualMemory` fires on every call and inspects the requested memory protection: `PAGE_EXECUTE_READ` regions are dumped to the console for analysis; `PAGE_EXECUTE_READWRITE` regions are dumped and then the process is terminated via `ExitProcess` to block payload execution. The hook is forwarded to the original function through the MinHook trampoline pointer `g_NtProtectVirtualMemory` to preserve normal execution for non-suspicious calls.

The DLL is compiled as a multi-file C project (`dllmain.c`, `hook.c`, `getmoduleoutput.c`, `Header.h`). On `DLL_PROCESS_ATTACH`, `DllMain` spawns a thread that calls `InstallHook`. Injecting this DLL into any process simulates EDR behaviour — any subsequent `VirtualProtect` call with an executable protection flag is intercepted, logged, and optionally blocked.

> This is an **educational proof-of-concept** that mirrors how real EDRs operate. It is not intended as a deployment-ready security product.

**Usage**

Compile as a DLL and inject into a target process. On `DLL_PROCESS_ATTACH`, `DllMain` automatically spawns a thread that calls `InstallHook`. Call `Unhook` to remove all hooks and clean up MinHook before unloading.

`InstallHook` and `Unhook` take no parameters.

**Return Value**

`BOOL`  `InstallHook` and `Unhook` each return `TRUE` on success or `FALSE` if any MinHook step fails.

**External Files**

- `windows.h`  `CreateThread()`, `CloseHandle()`, `GetProcAddress()`, `GetModuleHandleA()`, `GetStdHandle()`, `HeapAlloc()`, `HeapFree()`, `GetProcessHeap()`, `WriteConsoleA()`, `FreeConsole()`, `AllocConsole()`, `ExitProcess()`, `MessageBoxA()`
- `stdio.h`  `sprintf()`
- [MinHook.h](<0.files/Syscalls Userland Hooking/MinHook.h>)  ⚠️ Must be added manually — download from [github.com/TsudaKageyu/minhook](https://github.com/TsudaKageyu/minhook) and place alongside the source files. Provides `MH_Initialize()`, `MH_CreateHookApi()`, `MH_EnableHook()`, `MH_DisableHook()`, `MH_Uninitialize()`.
- [minhook.x64.lib](<0.files/Syscalls Userland Hooking/minhook.x64.lib>) / [minhook.x86.lib](<0.files/Syscalls Userland Hooking/minhook.x86.lib>)  ⚠️ Must be added manually — MinHook precompiled static libraries, linked automatically via `#pragma comment` in `hook.c`.

### Code

```c
// ─── Header.h ────────────────────────────────────────────────────────────────

#pragma once
#ifndef MYEDR
#define MYEDR

#pragma warning(disable: 4996)
#include <windows.h>
#include <stdio.h>

// PRINT macro: formats a string into a heap buffer and writes it to the
// console handle returned by ConsoleOutput(). Avoids printf IAT entries.
#define PRINT(STR, ...)                                                                  \
    if (1) {                                                                             \
        LPSTR Buffer = (LPSTR)HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, 1024);      \
        if (Buffer != NULL) {                                                            \
            int len = sprintf(Buffer, STR, __VA_ARGS__);                                 \
            WriteConsoleA(ConsoleOutput(), Buffer, len, NULL, NULL);                     \
            HeapFree(GetProcessHeap(), 0, Buffer);                                       \
        }                                                                                \
    }

BOOL   InstallHook();
HANDLE ConsoleOutput();
VOID   ReportError(LPSTR pFunctionName, DWORD dwError);
VOID   BlockExecution(PVOID pBaseAddress, SIZE_T sSize, BOOL Terminat);
BOOL   Unhook();

#endif


// ─── dllmain.c ───────────────────────────────────────────────────────────────

#define _CRT_SECURE_NO_WARNINGS
#include <windows.h>
#include <stdio.h>
#include "Header.h"

BOOL APIENTRY DllMain(
    HMODULE hModule,
    DWORD   ul_reason_for_call,
    LPVOID  lpReserved)
{
    switch (ul_reason_for_call)
    {
    case DLL_PROCESS_ATTACH:
    {
        // Spawn a thread to install the hook so DllMain returns quickly.
        HANDLE hThread = CreateThread(
            NULL,                                   // Default security attributes.
            0,                                      // Default stack size.
            (LPTHREAD_START_ROUTINE)&InstallHook,   // Thread entry: installs the hook.
            NULL,                                   // No argument passed.
            0,                                      // Start immediately.
            NULL                                    // Thread ID not captured.
        );
        if (hThread) {
            CloseHandle(hThread);
            break;
        }
    };
    case DLL_THREAD_ATTACH:
    case DLL_THREAD_DETACH:
    {
        // Remove all hooks when any thread detaches.
        Unhook();
        break;
    };
    case DLL_PROCESS_DETACH:
        break;
    }
    return TRUE;
}


// ─── getmoduleoutput.c ───────────────────────────────────────────────────────

#include <windows.h>
#include <stdio.h>
#include "Header.h"

// Uncomment TARGET_GUI for GUI processes; keep TARGET_CLI for console processes.
// #define TARGET_GUI
#define TARGET_CLI

// Cached console output handle — initialised once on first call.
HANDLE g_hConsoleOutput = NULL;

HANDLE ConsoleOutput()
{
    if (g_hConsoleOutput != NULL)
        return g_hConsoleOutput;

#ifdef TARGET_GUI
    // GUI processes have no console — free the dummy one then allocate a real one.
    if (!FreeConsole())
        return NULL;
    if (!AllocConsole())
        return NULL;
#endif

    if ((g_hConsoleOutput = GetStdHandle(STD_OUTPUT_HANDLE)) == NULL)
        return NULL;

    return g_hConsoleOutput;
}

// pFunctionName must be a printf-style format string, e.g.
// "[!] SomeFunc Failed With Error %d\n".
VOID ReportError(LPSTR pFunctionName, DWORD dwError)
{
    PRINT(pFunctionName, dwError);
}


// ─── hook.c ──────────────────────────────────────────────────────────────────

#include <windows.h>
#include <stdio.h>
#include "Header.h"
#include "MinHook.h"

// Link the correct MinHook static lib depending on target architecture.
#ifdef _M_X64
#pragma comment(lib, "minhook.x64.lib")
#endif
#ifdef _M_IX86
#pragma comment(lib, "minhook.x86.lib")
#endif

typedef NTSTATUS(NTAPI* fNtProtectVirtualMemory)(
    HANDLE  ProcessHandle,      // Handle to the process whose memory is being changed.
    PVOID*  BaseAddress,        // Pointer to the base address of the region.
    PULONG  NumberOfBytesToProtect, // Size of the region in bytes.
    ULONG   NewAccessProtection,    // Requested new protection (e.g. PAGE_EXECUTE_READWRITE).
    PULONG  OldAccessProtection     // Receives the previous protection.
);

// g_NtProtectVirtualMemory — MinHook trampoline; calling this invokes the real
// NtProtectVirtualMemory without re-entering the hook (no infinite loop).
fNtProtectVirtualMemory g_NtProtectVirtualMemory = NULL;

// p_NtProtectVirtualMemory — direct pointer to the target; used for logging only.
fNtProtectVirtualMemory p_NtProtectVirtualMemory = NULL;


// ── Detour Function ───────────────────────────────────────────────────────────
// Fires instead of NtProtectVirtualMemory on every call while the hook is active.
// Intercepts RX and RWX requests, dumps the affected memory region, and
// terminates the process on RWX to block payload execution.
NTSTATUS NTAPI HookedNtProtectVirtualMemory(
    HANDLE  ProcessHandle,
    PVOID*  BaseAddress,
    PULONG  NumberOfBytesToProtect,
    ULONG   NewAccessProtection,
    PULONG  OldAccessProtection)
{
    // PAGE_EXECUTE_READWRITE — dump the region and terminate (block execution).
    if (NewAccessProtection == PAGE_EXECUTE_READWRITE) {
        PRINT("\t\t[+] Detect : PAGE_EXECUTE_READWRITE <!> \n")
        BlockExecution(*BaseAddress, *NumberOfBytesToProtect, TRUE);
    }

    // PAGE_EXECUTE_READ — dump the region for analysis; do not terminate.
    if (NewAccessProtection == PAGE_EXECUTE_READ) {
        PRINT("\t\t[+] Detect : PAGE_EXECUTE_READ <!> \n")
        BlockExecution(*BaseAddress, *NumberOfBytesToProtect, FALSE);
    }

    // Forward all calls (suspicious or not) to the real function via the trampoline.
    return g_NtProtectVirtualMemory(
        ProcessHandle,
        BaseAddress,
        NumberOfBytesToProtect,
        NewAccessProtection,
        OldAccessProtection
    );
}


// ── Hook Installation ─────────────────────────────────────────────────────────
// Initialises MinHook, creates the hook on NtProtectVirtualMemory via
// MH_CreateHookApi, and enables all hooks with MH_ALL_HOOKS.
BOOL InstallHook()
{
    DWORD dwMinHookErr = NULL;

    // Step 1 — initialise MinHook's internal HOOK_ENTRY structure.
    if ((dwMinHookErr = MH_Initialize()) != MH_OK) {
        ReportError("[!] MH_Initialize Failed With Error %d\n", dwMinHookErr);
        return FALSE;
    }

    // Log the target function's address for reference.
    p_NtProtectVirtualMemory = (fNtProtectVirtualMemory)GetProcAddress(
        GetModuleHandleA("NTDLL.DLL"), "NtProtectVirtualMemory"
    );
    PRINT("[+] NtProtectVirtualMemory Address : %p\n", (PVOID)p_NtProtectVirtualMemory);

    // Step 2 — create the hook by module and export name.
    //   MH_CreateHookApi resolves the target internally and stores the
    //   trampoline pointer in g_NtProtectVirtualMemory.
    if ((dwMinHookErr = MH_CreateHookApi(
        L"NTDLL.DLL",                           // Module exporting the target function.
        "NtProtectVirtualMemory",               // Name of the function to hook.
        HookedNtProtectVirtualMemory,           // Detour function to execute instead.
        (LPVOID*)&g_NtProtectVirtualMemory      // Receives the trampoline pointer.
    )) != MH_OK) {
        ReportError("[!] MH_CreateHookApi Failed With Error %d\n", dwMinHookErr);
        return FALSE;
    }

    // Step 3 — activate all registered hooks; byte-patch is written now.
    if ((dwMinHookErr = MH_EnableHook(MH_ALL_HOOKS)) != MH_OK) {
        ReportError("[!] MH_EnableHook Failed With Error %d\n", dwMinHookErr);
        return FALSE;
    }

    return TRUE;
}


// ── Memory Dump + Block ───────────────────────────────────────────────────────
// Prints the raw bytes of the intercepted memory region in hex (16 per row).
// If Terminat is TRUE, prompts and terminates the process to block execution.
VOID BlockExecution(PVOID pBaseAddress, SIZE_T sSize, BOOL Terminat)
{
    PRINT("\n===================== [ Dump ] ==================\n")

    // Dump the memory region byte by byte, 16 per row.
    for (int i = 0; i < sSize; i++) {
        if (i % 16 == 0)
            PRINT("\n\t\t")
        PRINT("%0.2X ", ((PBYTE)pBaseAddress)[i]);  // Cast base to PBYTE for byte indexing.
    }

    PRINT("\n===================== [ Dump ] ==================\n")

    // RWX detected — prompt the operator then kill the process.
    if (Terminat) {
        MessageBoxA(NULL, "BLOCK ? ", "BLOCK", MB_OK);
        ExitProcess(1);
    }
}


// ── Hook Removal ──────────────────────────────────────────────────────────────
// Disables all active hooks (restores original prologue bytes) and releases
// MinHook's internal structures.
BOOL Unhook()
{
    DWORD dwMinHookErr = NULL;

    // Step 1 — disable all hooks: original bytes are restored to each prologue.
    if ((dwMinHookErr = MH_DisableHook(MH_ALL_HOOKS)) != MH_OK) {
        PRINT("[!] MH_DisableHook Failed With Error : %d \n", dwMinHookErr);
        return FALSE;
    }

    // Step 2 — release the HOOK_ENTRY structures created by MH_Initialize.
    if ((dwMinHookErr = MH_Uninitialize()) != MH_OK) {
        PRINT("[!] MH_Uninitialize Failed With Error : %d \n", dwMinHookErr);
        return FALSE;
    }

    return TRUE;
}
```

**Example**

```c
// ── Inject MalDevEdr.dll into a target process ────────────────────────────────
// Once injected, DllMain fires automatically and spawns a thread to call
// InstallHook. From this point any VirtualProtect call in the target process
// goes through HookedNtProtectVirtualMemory.

// ── What happens when the target calls VirtualProtect(..., PAGE_EXECUTE_READWRITE, ...) ──
//   1. NtProtectVirtualMemory is intercepted by HookedNtProtectVirtualMemory.
//   2. The affected memory region is dumped to the console in hex.
//   3. MessageBoxA prompts the operator.
//   4. ExitProcess(1) terminates the target — payload is blocked.

// ── What happens when the target calls VirtualProtect(..., PAGE_EXECUTE_READ, ...) ──
//   1. NtProtectVirtualMemory is intercepted.
//   2. The memory region is dumped to the console for analysis.
//   3. Execution continues normally — process is not terminated.

// ── To cleanly remove all hooks before unloading ─────────────────────────────
Unhook();
```

**Parameter Sources**

No external parameter sources — the hook target (`NtProtectVirtualMemory`) and detour function are compile-time constants. The trampoline pointer `g_NtProtectVirtualMemory` is populated at runtime by `MH_CreateHookApi`.
