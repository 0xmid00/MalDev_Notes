## Direct Syscall Detection via PROCESS_INSTRUMENTATION_CALLBACK (Nirvana)

Installs a kernel-to-user transition hook using the undocumented `NtSetInformationProcess` class `PROCESS_INSTRUMENTATION_CALLBACK` (class 40). Every time the kernel returns to user mode — after any syscall completes — it jumps to `InstrumentationCallbackThunk` (the assembly thunk) instead of the original return address. The thunk saves all registers, passes `R10` (the real return address the kernel intended) to the C callback `InstrumentationCallback`, restores all registers, and then `jmp r10` to the real return address so execution continues transparently.

`InstrumentationCallback` classifies the return address against four trusted module ranges (`ntdll`, `win32u`, `kernelbase`, `user32`) pre-populated by `GetBaseAddresses`. Any return that lands outside all trusted ranges is flagged as a suspicious direct syscall — shellcode, manually mapped DLLs, or any code that invokes the `syscall` instruction directly instead of going through NTDLL stubs will be caught.

A TEB-offset recursion guard (`TEB+0x2EC`, the `InstrumentationCallbackDisabled` flag used by Windows itself) prevents the callback from re-entering itself when `printf` or other helper functions internally issue their own syscalls.

> **x64 only.** Requires the companion `.asm` file compiled with MASM (`ml64.exe`). Add `InstrumentationCallbackThunk.asm` to the Visual Studio project and set its build tool to **Microsoft Macro Assembler**.

**Usage**

Call `GetBaseAddresses` once before installing the hook to populate the trusted module ranges. Resolve `NtSetInformationProcess` from `ntdll.dll` with `GetProcAddress`, fill a `PROCESS_INSTRUMENTATION_CALLBACK_INFORMATION` struct with `Callback = InstrumentationCallbackThunk`, and pass it to `NtSetInformationProcess` with class `40`. To remove the hook, repeat the call with `Callback = NULL`.

- No reusable function parameters — the hook and callback are installed via a single `NtSetInformationProcess` call in `main`.

**Return Value**

`NtSetInformationProcess` → `NTSTATUS`  Returns `0` (`STATUS_SUCCESS`) on success. The instrumentation callback itself returns `VOID`; the thunk handles the return path via `jmp r10`.

**External Files**

- `windows.h`  `ULONG_PTR`, `DWORD`, `PVOID`, `ULONG`, `BOOLEAN`, `NTSTATUS`, `NTAPI`, `LONG`, `NtCurrentTeb()`, `GetModuleHandleA()`, `GetProcAddress()`, `InterlockedIncrement()`, `VirtualAlloc()`, `VirtualFree()`
- `stdio.h`  `printf()`

### Code

```c
// ─── InstrumentationCallbackThunk.asm ────────────────────────────────────────
// Companion MASM file — compile with ml64.exe.
// Add to Visual Studio project; set Build Tool to "Microsoft Macro Assembler".
//
// extern InstrumentationCallback:PROC
//
// .code
//
// InstrumentationCallbackThunk PROC
//     ; When the kernel calls us:
//     ;   R10 = real user-mode return address (where the kernel intended to jump)
//     ;   RCX = this thunk address (placed there by the kernel)
//
//     mov     gs:[2d8h], r10      ; Save real return address in TEB.InstrumentationCallbackSp
//
//     ; Save all volatile and non-volatile registers before the C call.
//     push    rax
//     push    rcx
//     push    rdx
//     push    rbx
//     push    rsi
//     push    rdi
//     push    rbp
//     push    r8
//     push    r9
//     push    r10                 ; Also keep return address on the stack.
//     push    r11
//     push    r12
//     push    r13
//     push    r14
//     push    r15
//     ; 15 x 8 = 0x78 bytes pushed -> RSP is 8-byte aligned, not yet 16-byte.
//
//     sub     rsp, 8              ; Align RSP to 16 bytes (0x78 + 8 = 0x80).
//     sub     rsp, 20h            ; Allocate shadow space for the C call.
//
//     mov     rcx, r10            ; Pass real return address as first argument.
//     call    InstrumentationCallback  ; VOID InstrumentationCallback(ULONG_PTR Rip)
//
//     add     rsp, 20h            ; Release shadow space.
//     add     rsp, 8              ; Undo 16-byte alignment pad.
//
//     ; Restore all registers in reverse order.
//     pop     r15
//     pop     r14
//     pop     r13
//     pop     r12
//     pop     r11
//     pop     r10                 ; R10 = real return address.
//     pop     r9
//     pop     r8
//     pop     rbp
//     pop     rdi
//     pop     rsi
//     pop     rbx
//     pop     rdx
//     pop     rcx
//     pop     rax
//     ; RSP is now restored to the original user-mode value.
//
//     jmp     r10                 ; Jump to the real return address - transparent.
//
// InstrumentationCallbackThunk ENDP
// END
```

```c
// ─── main.c ──────────────────────────────────────────────────────────────────

#include <windows.h>
#include <stdio.h>

// ── Types ─────────────────────────────────────────────────────────────────────

// Descriptor passed to NtSetInformationProcess for class 40.
typedef struct _PROCESS_INSTRUMENTATION_CALLBACK_INFORMATION {
    ULONG   Version;    // Must be 0.
    ULONG   Reserved;   // Must be 0.
    PVOID   Callback;   // Address of the thunk; NULL to remove the hook.
} PROCESS_INSTRUMENTATION_CALLBACK_INFORMATION;

typedef NTSTATUS(NTAPI* pNtSetInformationProcess)(
    HANDLE  ProcessHandle,          // Handle to the target process.
    ULONG   ProcessInformationClass,// 40 = ProcessInstrumentationCallback.
    PVOID   ProcessInformation,     // Pointer to the descriptor struct.
    ULONG   ProcessInformationLength// sizeof(descriptor).
);

// ProcessInformationClass value that installs the instrumentation callback.
#define PROCESS_INSTRUMENTATION_CALLBACK    40

// Returns TRUE if Rip lies strictly inside [Base, Base + Size).
#define RIP_SANITY_CHECK(Rip, Base, Size) \
    ( ((Rip) > (Base)) && ((Rip) < ((Base) + (Size))) )


// ── Global State ──────────────────────────────────────────────────────────────

// Count of callback invocations — incremented atomically on each syscall return.
volatile LONG g_Count = 0;

// Forward declaration of the assembly thunk (InstrumentationCallbackThunk.asm).
extern void InstrumentationCallbackThunk(void);

// Trusted module ranges — base address + SizeOfImage for each module.
// Populated once by GetBaseAddresses() before the hook is installed.
static ULONG_PTR g_NtdllBase        = 0;   static DWORD g_NtdllSize        = 0;
static ULONG_PTR g_W32UBase         = 0;   static DWORD g_W32USize         = 0;
static ULONG_PTR g_KernelBaseBase   = 0;   static DWORD g_KernelBaseSize   = 0;
static ULONG_PTR g_User32Base       = 0;   static DWORD g_User32Size       = 0;


// ── GetBaseAddresses ──────────────────────────────────────────────────────────
// Reads the base address and SizeOfImage of each trusted module from their
// in-memory PE headers. Must be called before InstallHook so the callback
// does not compare against zero and flag every legitimate syscall.
VOID GetBaseAddresses(VOID)
{
    PIMAGE_DOS_HEADER piDH;
    PIMAGE_NT_HEADERS piNH;

    // ntdll.dll — always present; contains all NT syscall stubs.
    g_NtdllBase = (ULONG_PTR)GetModuleHandleA("ntdll.dll");
    piDH = (PIMAGE_DOS_HEADER)g_NtdllBase;
    piNH = (PIMAGE_NT_HEADERS)(g_NtdllBase + piDH->e_lfanew);
    g_NtdllSize = piNH->OptionalHeader.SizeOfImage;

    // win32u.dll — user-mode stubs for win32k (NtUser* / NtGdi* syscalls).
    g_W32UBase = (ULONG_PTR)GetModuleHandleA("win32u.dll");
    if (g_W32UBase) {
        piDH = (PIMAGE_DOS_HEADER)g_W32UBase;
        piNH = (PIMAGE_NT_HEADERS)(g_W32UBase + piDH->e_lfanew);
        g_W32USize = piNH->OptionalHeader.SizeOfImage;
    }

    // kernelbase.dll — where most Win32 API bodies actually live.
    g_KernelBaseBase = (ULONG_PTR)GetModuleHandleA("kernelbase.dll");
    if (g_KernelBaseBase) {
        piDH = (PIMAGE_DOS_HEADER)g_KernelBaseBase;
        piNH = (PIMAGE_NT_HEADERS)(g_KernelBaseBase + piDH->e_lfanew);
        g_KernelBaseSize = piNH->OptionalHeader.SizeOfImage;
    }

    // user32.dll — user-mode callback dispatch for window messages.
    g_User32Base = (ULONG_PTR)GetModuleHandleA("user32.dll");
    if (g_User32Base) {
        piDH = (PIMAGE_DOS_HEADER)g_User32Base;
        piNH = (PIMAGE_NT_HEADERS)(g_User32Base + piDH->e_lfanew);
        g_User32Size = piNH->OptionalHeader.SizeOfImage;
    }
}


// ── InstrumentationCallback (C side) ─────────────────────────────────────────
// Called by InstrumentationCallbackThunk on every kernel → user transition.
// Rip is the value the kernel placed in R10 — the real user-mode return address.
//
// CAUTION: Do NOT call anything that issues a syscall (printf, malloc, etc.)
// from inside this function without disabling the callback first. The recursion
// guard below (TEB+0x2EC) prevents re-entry but does not handle other callers.
VOID InstrumentationCallback(ULONG_PTR Rip)
{
    // TEB+0x2EC is the InstrumentationCallbackDisabled flag used internally by
    // Windows to prevent recursive callback invocation.
    ULONG_PTR  pTeb      = (ULONG_PTR)NtCurrentTeb();
    BOOLEAN*   pDisabled = (BOOLEAN*)(pTeb + 0x02EC);

    if (*pDisabled)
        return;             // Already inside a callback — bail immediately.

    *pDisabled = TRUE;      // Set the guard before doing anything else.

    InterlockedIncrement(&g_Count);     // Atomic counter increment.

    // Read the trusted ranges into locals (they are set-once in main).
    ULONG_PTR ntdllBase      = g_NtdllBase;        DWORD ntdllSize      = g_NtdllSize;
    ULONG_PTR w32uBase       = g_W32UBase;         DWORD w32uSize       = g_W32USize;
    ULONG_PTR kbBase         = g_KernelBaseBase;   DWORD kbSize         = g_KernelBaseSize;
    ULONG_PTR user32Base     = g_User32Base;       DWORD user32Size     = g_User32Size;

    // ── Classify the return address ───────────────────────────────────────────
    if      (RIP_SANITY_CHECK(Rip, ntdllBase,  ntdllSize))  { /* ntdll — normal.       */ }
    else if (RIP_SANITY_CHECK(Rip, w32uBase,   w32uSize))   { /* win32u — normal.      */ }
    else if (RIP_SANITY_CHECK(Rip, kbBase,     kbSize))     { /* kernelbase — normal.  */ }
    else if (RIP_SANITY_CHECK(Rip, user32Base, user32Size)) { /* user32 — normal.      */ }
    else {
        // Return address is outside every trusted module.
        // This indicates a direct syscall from shellcode, a manually mapped
        // DLL, or any code that invokes `syscall` without going through NTDLL.
        // NOTE: In production, write to a lock-free ring buffer here instead
        // of printf to avoid the syscall → recursion risk.
        printf("[SYSCALL-DETECT] Kernel returns to unverified module: 0x%p\n",
            (void*)Rip);
    }

    *pDisabled = FALSE;     // Release the guard so the next callback can fire.
}


// ── main ──────────────────────────────────────────────────────────────────────
int main(void)
{
    // Step 1 — populate trusted module ranges BEFORE installing the hook.
    GetBaseAddresses();

    // Step 2 — resolve NtSetInformationProcess from ntdll at runtime.
    pNtSetInformationProcess NtSIP =
        (pNtSetInformationProcess)GetProcAddress(
            GetModuleHandleA("ntdll.dll"),
            "NtSetInformationProcess"   // Undocumented — not in the standard headers.
        );

    // Step 3 — build the callback descriptor.
    PROCESS_INSTRUMENTATION_CALLBACK_INFORMATION nirvana = { 0 };
    nirvana.Version  = 0;                               // Must be 0.
    nirvana.Reserved = 0;                               // Must be 0.
    nirvana.Callback = (PVOID)InstrumentationCallbackThunk; // Assembly thunk address.

    // Step 4 — install the hook.
    NTSTATUS st = NtSIP(
        GetCurrentProcess(),                // Target: current process.
        PROCESS_INSTRUMENTATION_CALLBACK,   // Class 40.
        &nirvana,                           // Descriptor with thunk address.
        sizeof(nirvana)                     // Must match the struct size exactly.
    );

    // Step 5 — exercise a few syscalls; the callback will observe each one.
    PVOID mem = VirtualAlloc(NULL, 1024, MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);
    VirtualFree(mem, 0, MEM_RELEASE);

    // Step 6 — REMOVE the hook BEFORE calling printf.
    // printf → WriteFile → NtWriteFile, which would re-enter the callback.
    // Set Callback = NULL to tell the kernel to stop calling us.
    nirvana.Callback = NULL;
    NtSIP(GetCurrentProcess(), PROCESS_INSTRUMENTATION_CALLBACK, &nirvana, sizeof(nirvana));

    printf("[*] Hook removed.\n");
    printf("[*] status = 0x%X\n", st);
    printf("[*] count  = %d\n", g_Count);

    getchar();
    return 0;
}
```

```c
// ── Expected output for a clean (non-hooked) run ─────────────────────────────
// [*] Hook removed.
// [*] status = 0x0
// [*] count  = N          ← N = number of syscall returns observed

// ── Expected output when a direct syscall is detected ────────────────────────

// [*] Hook removed.
// [*] status = 0x0
// [*] count  = N

// ── To add more trusted modules (e.g. wow64.dll) ─────────────────────────────
// Add a new pair of globals and populate them in GetBaseAddresses() the same
// way ntdll.dll is handled. Add a new RIP_SANITY_CHECK branch in
// InstrumentationCallback to whitelist the range.
```

**Parameter Sources**

No external parameter sources — all module handles are resolved internally by `GetBaseAddresses()` and all hook configuration is built inline in `main()`.
