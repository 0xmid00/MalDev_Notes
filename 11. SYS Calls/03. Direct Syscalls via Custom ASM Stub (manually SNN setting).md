## Direct Syscalls via Custom ASM Stub (manually SNN setting)

Implements a direct syscall for any NT function by hand — no tool required. A `.h` file declares the NT function prototype so the C compiler knows the calling convention. A `.asm` file implements the stub: it reads `OSMajorVersion`, `OSMinorVersion`, and `OSBuildNumber` directly from the PEB via the `GS` register, branches to the correct Syscall Service Number (SSN) for the detected Windows version, then executes the `syscall` instruction inline, bypassing any user-mode hooks placed in `ntdll.dll`. Add a new `PROC`/`ENDP` block in the `.asm` and a matching prototype in the `.h` for each additional NT function needed.

⚠️ SSNs change between Windows versions and builds — verify the correct SSN for each target version from the [Windows x64 Syscall Table](https://j00ru.vexillium.org/syscalls/nt/64/) before hardcoding.
⚠️ x64 only. Requires MASM enabled in Visual Studio: Project → Build Customizations → enable MASM. Set the `.asm` file's Item Type to "Microsoft Macro Assembler".

**Usage**

Add the `.h` and `.asm` files to the project. Include the header and call the NT function directly as if it were a normal WinAPI. The stub resolves the correct SSN at runtime and issues the syscall.

**External Files**

- `windows.h`  `HANDLE`, `PVOID`, `PSIZE_T`, `ULONG`, `PULONG`, `NTSTATUS`, `GetCurrentProcess()`
- `Header.h`  NT function prototypes — one per syscall stub in `Source.asm`.
- `Source.asm`  MASM x64 assembly stubs — one `PROC`/`ENDP` block per NT function.

### Code

**Header.h**

```c
#pragma once
#include <windows.h>

#ifndef HEADER_H
#define HEADER_H

// Declare one prototype per NT function implemented in Source.asm.
NTSTATUS NtProtectVirtualMemory(
    HANDLE  ProcessHandle,          // Handle to the process whose memory to protect.
    PVOID*  BaseAddress,            // Pointer to the base address of the region.
    PSIZE_T NumberOfBytesToProtect, // Pointer to the size of the region in bytes.
    ULONG   NewAccessProtection,    // New memory protection value (e.g. PAGE_READONLY).
    PULONG  OldAccessProtection     // Receives the previous protection value.
);

#endif
```

**Source.asm**

```asm
.code


PUBLIC NtProtectVirtualMemory

NtProtectVirtualMemory PROC

    ; Load PEB pointer into RAX via the GS register.
    mov rax, gs:[60h]

    ; ---------------------------------------------------------------
    ; Step 1 — Check OSMajorVersion (PEB+0x118).
    ; ---------------------------------------------------------------
    cmp dword ptr [rax+118h], 5     ; Windows XP
    je  NtProtectVirtualMemory_Check_5_X_XXXX
    cmp dword ptr [rax+118h], 6     ; Windows Vista / 7
    je  NtProtectVirtualMemory_Check_6_X_XXXX
    cmp dword ptr [rax+118h], 10    ; Windows 10
    je  NtProtectVirtualMemory_Check_10_X_X_XXXX
    jmp NtProtectVirtualMemory_Unknown


    ; ---------------------------------------------------------------
    ; Step 2 — Check OSMinorVersion (PEB+0x11C) for major version 6.
    ; ---------------------------------------------------------------
NtProtectVirtualMemory_Check_6_X_XXXX:
    cmp dword ptr [rax+11Ch], 0     ; Windows Vista (6.0)
    je  NtProtectVirtualMemory_Check_6_0_XXXX
    cmp dword ptr [rax+11Ch], 1     ; Windows 7 (6.1)
    je  NtProtectVirtualMemory_Check_6_1_XXXX
    jmp NtProtectVirtualMemory_Unknown


    ; ---------------------------------------------------------------
    ; Step 3 — Check OSBuildNumber (PEB+0x120) for Windows 7.
    ; ---------------------------------------------------------------
NtProtectVirtualMemory_Check_6_1_XXXX:
    cmp dword ptr [rax+120h], 7600  ; Windows 7 SP0
    je  NtProtectVirtualMemory_Check_6_1_7600
    cmp dword ptr [rax+120h], 7601  ; Windows 7 SP1
    je  NtProtectVirtualMemory_Check_6_1_7601
    jmp NtProtectVirtualMemory_Unknown


    ; ---------------------------------------------------------------
    ; Set SSN per version and jump to epilogue.
    ; Verify SSNs at: https://j00ru.vexillium.org/syscalls/nt/64/
    ; ---------------------------------------------------------------
NtProtectVirtualMemory_Check_5_X_XXXX:
    mov eax, 4Dh                    ; SSN — Windows XP
    jmp NtProtectVirtualMemory_Epilogue

NtProtectVirtualMemory_Check_6_0_XXXX:
    mov eax, 4Dh                    ; SSN — Windows Vista
    jmp NtProtectVirtualMemory_Epilogue

NtProtectVirtualMemory_Check_6_1_7600:
    mov eax, 4Dh                    ; SSN — Windows 7 SP0
    jmp NtProtectVirtualMemory_Epilogue

NtProtectVirtualMemory_Check_6_1_7601:
    mov eax, 4Dh                    ; SSN — Windows 7 SP1
    jmp NtProtectVirtualMemory_Epilogue

NtProtectVirtualMemory_Check_10_X_X_XXXX:
    mov eax, 50h                    ; SSN — Windows 10
    jmp NtProtectVirtualMemory_Epilogue

NtProtectVirtualMemory_Unknown:
    ret                             ; Unknown/unsupported version — return without calling.

NtProtectVirtualMemory_Epilogue:
    mov r10, rcx                    ; Back up RCX (1st argument) into R10 — required by syscall ABI.
    syscall                         ; Issue the syscall — NTSTATUS returned in EAX.
    ret

NtProtectVirtualMemory ENDP

END
```

**Example**

```c
#include <windows.h>
#include <stdio.h>
#include "Header.h"


SIZE_T  size            = 1024;
ULONG   dwOldProtection = 0;

// Allocate a RW region to test protection change.
PVOID pBase = VirtualAlloc(NULL, size, MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);


// --- Direct syscall path ---
// Calls NtProtectVirtualMemory directly via the custom ASM stub.
// Bypasses any user-mode hooks in ntdll.dll — the syscall instruction
// is issued inline without passing through ntdll.
NTSTATUS status = NtProtectVirtualMemory(
    GetCurrentProcess(),    // Target process — current process.
    &pBase,                 // Base address of the region.
    &size,                  // Size of the region in bytes.
    PAGE_READONLY,          // New protection value.
    &dwOldProtection        // Receives the previous protection value.
);

if (status >= 0)
    printf("[+] NtProtectVirtualMemory (direct syscall) Succeeded\n");

// ---  Costom Direct syscall path (equivalent) ---
// [ FOR BETTER OBFUSCATION !!!] we can rename NtProtectVirtualMemory to another name ex. CostomNtProtectVirtualMemory in the both ASM code and int the c code and call it with CostomNtProtectVirtualMemory(...) . 

VirtualFree(pBase, 0, MEM_RELEASE);
```
