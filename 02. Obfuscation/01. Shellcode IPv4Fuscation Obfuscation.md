## Shellcode IPv4Fuscation  Obfuscation

Converts a shellcode buffer into a C-style array of IPv4 address strings by grouping every 4 bytes into one IPv4 address, with each byte represented as a decimal octet. The obfuscated output is printed to the console in a ready-to-copy C array format. The shellcode buffer must be a multiple of 4 bytes.

**Usage**

Call `GenerateIpv4Output` with the shellcode buffer and its size. The obfuscated IPv4 array is printed to the console; no heap allocation is performed by this function.

- `IN PBYTE pShellcode`  Base address of the shellcode buffer to obfuscate.
- `IN SIZE_T ShellcodeSize`  Size of `pShellcode` in bytes; must be a multiple of 4.

**Return Value**

`BOOL`  Returns `TRUE` if the output was generated successfully, otherwise `FALSE` if `pShellcode` is `NULL`, `ShellcodeSize` is zero, or `ShellcodeSize` is not a multiple of 4.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `SIZE_T`, `IN`
- `stdio.h`  `printf()`, `sprintf()`

### Code

```c
#include <windows.h>
#include <stdio.h>


// Helper: converts 4 raw bytes into a single IPv4 address string.
char* GenerateIpv4(int a, int b, int c, int d)
{
    unsigned char Output[32];

    // Format 4 decimal octets into a dotted IPv4 string.
    sprintf(Output, "%d.%d.%d.%d", a, b, c, d);

    return (char*)Output;
}


BOOL GenerateIpv4Output(IN PBYTE pShellcode, IN SIZE_T ShellcodeSize)
{
    if (pShellcode == NULL || ShellcodeSize == NULL || ShellcodeSize % 4 != 0)
        return FALSE;

    printf("char* Ipv4Array[%d] = { \n\t", (int)(ShellcodeSize / 4));

    // 'c' tracks how many bytes have been consumed toward the current IPv4 address.
    // Starts at 4 to trigger generation on the very first iteration.
    int c = 4, counter = 0;
    char* IP = NULL;

    for (int i = 0; i < ShellcodeSize; i++) {

        // Every 4 bytes consumed, generate one IPv4 address.
        if (c == 4) {
            counter++;

            // Consume bytes [i .. i+3] to form one IPv4 address.
            IP = GenerateIpv4(
                pShellcode[i],      // First octet.
                pShellcode[i + 1],  // Second octet.
                pShellcode[i + 2],  // Third octet.
                pShellcode[i + 3]   // Fourth octet.
            );

            if (i == ShellcodeSize - 4) {
                // Last address — no trailing comma.
                printf("\"%s\"", IP);
                break;
            } else {
                printf("\"%s\", ", IP);
            }

            c = 1;

            // Insert a newline every 8 addresses to keep output readable.
            if (counter % 8 == 0)
                printf("\n\t");

        } else {
            c++;
        }
    }

    printf("\n};\n\n");
    return TRUE;
}
```

