## Shellcode MACFuscation Obfuscation

Converts a shellcode buffer into a C-style array of MAC address strings by grouping every 6 bytes into one MAC address, with bytes represented as two-digit hex octets separated by hyphens. The obfuscated output is always printed to the console. Optionally, the generated string array and its element count are saved into caller-supplied `OUT` pointers if they are non-`NULL`. The shellcode buffer must be a multiple of 6 bytes.

**Usage**

Call `GenerateMacOutput` with the shellcode buffer and its size. Pass valid pointers to `pMacArray` and `pNmbrOfElements` to receive the heap-allocated string array and its count, or pass `NULL` for both to use print-only mode. When the array is returned, the caller is responsible for freeing each string with `HeapFree` then freeing the array itself.

- `IN PBYTE pShellcode`  Base address of the shellcode buffer to obfuscate.
- `IN SIZE_T ShellcodeSize`  Size of `pShellcode` in bytes; must be a multiple of 6.
- `OUT CHAR*** pMacArray`  Optional. Receives the base address of the heap-allocated array of MAC string pointers. Pass `NULL` to skip.
- `OUT SIZE_T* pNmbrOfElements`  Optional. Receives the number of MAC strings in the array (`ShellcodeSize / 6`). Pass `NULL` to skip.

**Return Value**

`BOOL`  Returns `TRUE` if the output was generated successfully, otherwise `FALSE`.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `SIZE_T`, `IN`, `OUT`, `HeapAlloc()`, `HeapFree()`, `GetProcessHeap()`
- `stdio.h`  `printf()`, `sprintf()`

### Code

```c
#include <windows.h>
#include <stdio.h>


// Helper: formats 6 raw bytes into a heap-allocated MAC address string.
// Caller is responsible for freeing the returned buffer with HeapFree.
char* GenerateMAC(int a, int b, int c, int d, int e, int f)
{
    // Allocate a buffer large enough for the longest possible MAC address string.
    char* Output = (char*)HeapAlloc(GetProcessHeap(), 0, 64);
    if (Output == NULL)
        return NULL;

    // Format 6 hex octets into a hyphen-separated MAC address string.
    sprintf(Output, "%0.2X-%0.2X-%0.2X-%0.2X-%0.2X-%0.2X", a, b, c, d, e, f);

    return Output;
}


BOOL GenerateMacOutput(IN PBYTE pShellcode, IN SIZE_T ShellcodeSize, OUT CHAR*** pMacArray, OUT SIZE_T* pNmbrOfElements)
{
    if (pShellcode == NULL || ShellcodeSize == NULL || ShellcodeSize % 6 != 0)
        return FALSE;

    SIZE_T ElementCount = ShellcodeSize / 6;

    // Only allocate the output array if the caller supplied a non-NULL pointer.
    CHAR** MacArray = NULL;
    if (pMacArray != NULL) {
        MacArray = (CHAR**)HeapAlloc(GetProcessHeap(), 0, ElementCount * sizeof(CHAR*));
        if (MacArray == NULL)
            return FALSE;
    }

    printf("char* MacArray[%d] = {\n\t", (int)ElementCount);

    // 'c' tracks how many bytes have been consumed toward the current MAC address.
    // Starts at 6 to trigger generation on the very first iteration.
    int    c = 6, counter = 0;
    SIZE_T Index = 0;
    char*  Mac = NULL;

    for (int i = 0; i < ShellcodeSize; i++) {

        // Every 6 bytes consumed, generate one MAC address.
        if (c == 6) {
            counter++;

            // Consume bytes [i .. i+5] to form one MAC address.
            Mac = GenerateMAC(
                pShellcode[i],      // First octet.
                pShellcode[i + 1],  // Second octet.
                pShellcode[i + 2],  // Third octet.
                pShellcode[i + 3],  // Fourth octet.
                pShellcode[i + 4],  // Fifth octet.
                pShellcode[i + 5]   // Sixth octet.
            );
            if (Mac == NULL) {
                // Free already allocated strings before returning.
                if (MacArray != NULL) {
                    for (SIZE_T j = 0; j < Index; j++)
                        HeapFree(GetProcessHeap(), 0, MacArray[j]);
                    HeapFree(GetProcessHeap(), 0, MacArray);
                }
                return FALSE;
            }

            // Save the string pointer only if the caller requested the array.
            if (MacArray != NULL)
                MacArray[Index++] = Mac;

            if (i == ShellcodeSize - 6) {
                // Last address — no trailing comma.
                printf("\"%s\"", Mac);

                // If the array is not being saved, free the string now.
                if (MacArray == NULL)
                    HeapFree(GetProcessHeap(), 0, Mac);

                break;
            } else {
                printf("\"%s\", ", Mac);

                // If the array is not being saved, free the string now.
                if (MacArray == NULL)
                    HeapFree(GetProcessHeap(), 0, Mac);
            }

            c = 1;

            // Insert a newline every 6 addresses to keep output readable.
            if (counter % 6 == 0)
                printf("\n\t");

        } else {
            c++;
        }
    }

    printf("\n};\n\n");

    // Save outputs only if the caller supplied non-NULL pointers.
    if (pMacArray != NULL)
        *pMacArray = MacArray;

    if (pNmbrOfElements != NULL)
        *pNmbrOfElements = ElementCount;

    return TRUE;
}
```

**Example**

```c
unsigned char pShellcode[] = {
    0xFC, 0x48, 0x83, 0xE4, 0xF0, 0xE5,
    0xE2, 0x50, 0x41, 0x51, 0x52, 0x53
};  // Must be a multiple of 6 bytes.

CHAR**  pMacArray      = NULL;
SIZE_T  NmbrOfElements = 0;

// Pass non-NULL pointers to receive the heap-allocated string array.
if (GenerateMacOutput(pShellcode, sizeof(pShellcode), &pMacArray, &NmbrOfElements)) {
    for (SIZE_T i = 0; i < NmbrOfElements; i++)
        HeapFree(GetProcessHeap(), 0, pMacArray[i]);  // Free each string...
    HeapFree(GetProcessHeap(), 0, pMacArray);          // ...then the array.
}
```
