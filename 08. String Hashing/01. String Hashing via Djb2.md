## String Hashing via Djb2

Computes a 32-bit hash of an input string using the Djb2 algorithm. Each character updates a running hash with `hash = ((hash << INITIAL_SEED) + hash) + c`. Both ASCII (`PCHAR`) and wide-character (`PWCHAR`) variants are provided. `INITIAL_HASH` seeds the initial value to randomize output; `INITIAL_SEED` controls the shift amount. Changing either constant produces a different hash family, making the algorithm harder to fingerprint.

**Usage**

Call `HashStringDjb2A` with a null-terminated ASCII string or `HashStringDjb2W` with a null-terminated wide-character string. The returned `DWORD` is the hash of the input.

- `IN PCHAR String`  Null-terminated ASCII string to hash (`HashStringDjb2A`).
- `IN PWCHAR String`  Null-terminated wide-character string to hash (`HashStringDjb2W`).

**Return Value**

`DWORD`  Returns the 32-bit Djb2 hash of the input string.

**External Files**

- `windows.h`  `DWORD`, `ULONG`, `INT`, `PCHAR`, `PWCHAR`, `IN`

### Code

```c
#include <windows.h>

#define INITIAL_HASH    3731    // Seed value — change to produce a different hash family.
#define INITIAL_SEED    7       // Bit-shift amount used in each iteration.


// Compute Djb2 hash of a null-terminated ASCII string.
DWORD HashStringDjb2A(IN PCHAR String)
{
    ULONG Hash = INITIAL_HASH;
    INT   c    = 0;

    // For each character: Hash = (Hash << INITIAL_SEED) + Hash + c
    while (c = *String++)
        Hash = ((Hash << INITIAL_SEED) + Hash) + c;

    return Hash;
}


// Compute Djb2 hash of a null-terminated wide-character string.
DWORD HashStringDjb2W(IN PWCHAR String)
{
    ULONG Hash = INITIAL_HASH;
    INT   c    = 0;

    // Same algorithm as the ASCII variant — wide chars are consumed one WCHAR at a time.
    while (c = *String++)
        Hash = ((Hash << INITIAL_SEED) + Hash) + c;

    return Hash;
}
```

**Example**

```c
DWORD dwHashA = HashStringDjb2A("0xmid00");
DWORD dwHashW = HashStringDjb2W(L"0xmid00");

printf("Djb2 ASCII : 0x%0.8X\n", dwHashA);
printf("Djb2 Wide  : 0x%0.8X\n", dwHashW);
```

**Parameter Sources**

No external parameter sources — the input string is supplied directly by the caller.
