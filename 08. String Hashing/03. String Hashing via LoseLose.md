## String Hashing via LoseLose

Computes a 32-bit hash of an input string using an improved LoseLose algorithm. The original LoseLose simply sums ASCII character values, which produces poor distribution and frequent collisions. The improved variant additionally multiplies the hash by `(c + INITIAL_SEED)` after each addition step to increase randomization. Both ASCII (`PCHAR`) and wide-character (`PWCHAR`) variants are provided.

**Usage**

Call `HashStringLoseLoseA` with a null-terminated ASCII string or `HashStringLoseLoseW` with a null-terminated wide-character string. The returned `DWORD` is the hash of the input.

- `IN PCHAR String`  Null-terminated ASCII string to hash (`HashStringLoseLoseA`).
- `IN PWCHAR String`  Null-terminated wide-character string to hash (`HashStringLoseLoseW`).

**Return Value**

`DWORD`  Returns the 32-bit LoseLose hash of the input string.

**External Files**

- `windows.h`  `DWORD`, `ULONG`, `INT`, `PCHAR`, `PWCHAR`, `IN`

### Code

```c
#include <windows.h>

#define INITIAL_SEED    2   // Added to each character before multiplication to increase entropy.


// Compute improved LoseLose hash of a null-terminated ASCII string.
DWORD HashStringLoseLoseA(IN PCHAR String)
{
    ULONG Hash = 0;
    INT   c    = 0;

    while (c = *String++) {
        Hash += c;                      // Original LoseLose: sum ASCII values.
        Hash *= c + INITIAL_SEED;       // Improvement: multiply to reduce collisions.
    }

    return Hash;
}


// Compute improved LoseLose hash of a null-terminated wide-character string.
DWORD HashStringLoseLoseW(IN PWCHAR String)
{
    ULONG Hash = 0;
    INT   c    = 0;

    // Same algorithm as the ASCII variant — wide chars consumed one WCHAR at a time.
    while (c = *String++) {
        Hash += c;
        Hash *= c + INITIAL_SEED;
    }

    return Hash;
}
```

**Example**

```c
DWORD dwHashA = HashStringLoseLoseA("0xmid00");
DWORD dwHashW = HashStringLoseLoseW(L"0xmid00");

printf("LoseLose ASCII : 0x%0.8X\n", dwHashA);
printf("LoseLose Wide  : 0x%0.8X\n", dwHashW);
```

**Parameter Sources**

No external parameter sources — the input string is supplied directly by the caller.
