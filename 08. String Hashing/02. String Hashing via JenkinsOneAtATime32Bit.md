## String Hashing via JenkinsOneAtATime32Bit

Computes a 32-bit hash of an input string using the JenkinsOneAtATime32Bit algorithm. Each character updates the running hash with three mixing steps (`+= c`, `+= hash << 10`, `^= hash >> 6`), followed by three final avalanche steps after the loop. Both ASCII (`PCHAR`) and wide-character (`PWCHAR`) variants are provided. The algorithm produces good hash distribution and a low collision rate.

**Usage**

Call `HashStringJenkinsOneAtATime32BitA` with a null-terminated ASCII string or `HashStringJenkinsOneAtATime32BitW` with a null-terminated wide-character string. The returned `UINT32` is the hash of the input.

- `IN PCHAR String`  Null-terminated ASCII string to hash (`HashStringJenkinsOneAtATime32BitA`).
- `IN PWCHAR String`  Null-terminated wide-character string to hash (`HashStringJenkinsOneAtATime32BitW`).

**Return Value**

`UINT32`  Returns the 32-bit Jenkins hash of the input string.

**External Files**

- `windows.h`  `UINT32`, `SIZE_T`, `PCHAR`, `PWCHAR`, `IN`, `lstrlenA()`, `lstrlenW()`

### Code

```c
#include <windows.h>

#define INITIAL_SEED    7   // Shift amount used in the per-character mixing step.


// Compute JenkinsOneAtATime32Bit hash of a null-terminated ASCII string.
UINT32 HashStringJenkinsOneAtATime32BitA(IN PCHAR String)
{
    SIZE_T Index  = 0;
    UINT32 Hash   = 0;
    SIZE_T Length = lstrlenA(String);

    // Per-character mixing: accumulate, shift-add, XOR-shift.
    while (Index != Length) {
        Hash += String[Index++];        // Add the character value.
        Hash += Hash << INITIAL_SEED;   // Shift-add for avalanche.
        Hash ^= Hash >> 6;              // XOR-shift for bit dispersion.
    }

    // Final avalanche — ensures all input bits affect all output bits.
    Hash += Hash << 3;
    Hash ^= Hash >> 11;
    Hash += Hash << 15;

    return Hash;
}


// Compute JenkinsOneAtATime32Bit hash of a null-terminated wide-character string.
UINT32 HashStringJenkinsOneAtATime32BitW(IN PWCHAR String)
{
    SIZE_T Index  = 0;
    UINT32 Hash   = 0;
    SIZE_T Length = lstrlenW(String);

    // Same algorithm as the ASCII variant — wide chars consumed one WCHAR at a time.
    while (Index != Length) {
        Hash += String[Index++];
        Hash += Hash << INITIAL_SEED;
        Hash ^= Hash >> 6;
    }

    Hash += Hash << 3;
    Hash ^= Hash >> 11;
    Hash += Hash << 15;

    return Hash;
}
```

**Example**

```c
UINT32 uHashA = HashStringJenkinsOneAtATime32BitA("0xmid00");
UINT32 uHashW = HashStringJenkinsOneAtATime32BitW(L"0xmid00");

printf("Jenkins ASCII : 0x%0.8X\n", uHashA);
printf("Jenkins Wide  : 0x%0.8X\n", uHashW);
```

No external parameter sources — the input string is supplied directly by the caller.
