## String Hashing via Rotr32

Computes a 32-bit hash of an input string using the Rotr32 algorithm. For each character, a 32-bit right rotation (`HashStringRotr32Sub`) is applied to the current hash value and the character's ASCII value is added to the result. The rotation is computed as `(Value >> Count) | (Value << ((-Count) & Mask))` where `Count` is `INITIAL_SEED`. Both ASCII (`PCHAR`) and wide-character (`PWCHAR`) variants are provided. Rotr32 produces good hash distribution and a low collision rate.

**Usage**

Call `HashStringRotr32A` with a null-terminated ASCII string or `HashStringRotr32W` with a null-terminated wide-character string. The returned `INT` is the hash of the input.

- `IN PCHAR String`  Null-terminated ASCII string to hash (`HashStringRotr32A`).
- `IN PWCHAR String`  Null-terminated wide-character string to hash (`HashStringRotr32W`).

**Return Value**

`INT`  Returns the 32-bit Rotr32 hash of the input string.

**External Files**

- `windows.h`  `UINT32`, `DWORD`, `INT`, `PCHAR`, `PWCHAR`, `IN`, `lstrlenA()`, `lstrlenW()`
- `limits.h`  `CHAR_BIT`

### Code

```c
#include <windows.h>
#include <limits.h>

#define INITIAL_SEED    5   // Rotation count applied to the hash on each iteration.


// Helper: performs a 32-bit right rotation of Value by Count positions.
UINT32 HashStringRotr32Sub(UINT32 Value, UINT Count)
{
    DWORD Mask = (CHAR_BIT * sizeof(Value) - 1);   // Mask = 31 for a 32-bit value.
    Count &= Mask;                                  // Clamp count to valid rotation range.

#pragma warning(push)
#pragma warning(disable : 4146)     // Suppress unary minus on unsigned type warning.
    // Right-rotate: shift right by Count, OR with left-shift by (32 - Count).
    return (Value >> Count) | (Value << ((-Count) & Mask));
#pragma warning(pop)
}


// Compute Rotr32 hash of a null-terminated ASCII string.
INT HashStringRotr32A(IN PCHAR String)
{
    INT Value = 0;

    for (INT Index = 0; Index < lstrlenA(String); Index++)
        // Rotate current hash right by INITIAL_SEED, then add the next character.
        Value = String[Index] + HashStringRotr32Sub(Value, INITIAL_SEED);

    return Value;
}


// Compute Rotr32 hash of a null-terminated wide-character string.
INT HashStringRotr32W(IN PWCHAR String)
{
    INT Value = 0;

    for (INT Index = 0; Index < lstrlenW(String); Index++)
        // Same algorithm as the ASCII variant — wide chars consumed one WCHAR at a time.
        Value = String[Index] + HashStringRotr32Sub(Value, INITIAL_SEED);

    return Value;
}
```

**Example**

```c
INT iHashA = HashStringRotr32A("0xmid00");
INT iHashW = HashStringRotr32W(L"0xmid00");

printf("Rotr32 ASCII : 0x%0.8X\n", iHashA);
printf("Rotr32 Wide  : 0x%0.8X\n", iHashW);
```

**Parameter Sources**

No external parameter sources — the input string is supplied directly by the caller.
