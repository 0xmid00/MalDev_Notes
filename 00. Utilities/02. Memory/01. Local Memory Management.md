# Local Memory Management

>Demonstrates multiple methods for allocating  memory within the current process using `malloc`, `HeapAlloc`, and `LocalAlloc` and Freeing.


---

## malloc

Allocates memory blocks.

 **Usage**
 
Call `malloc` with the number of bytes to allocate.

-  `IN SIZE_T sSize`    The number of bytes to allocate.
- `OUT pAddress` Pointer to the the allocated memory .

**Return Value**

`void*`   Returns the address of the allocated memory on success, or `NULL` if the allocation fails.

** External Files**

- `stdlib.h`  `malloc()` 
- `string.h`  `memcpy()`


### Code
```c
#include <stdio.h>
#include <stdlib.h>

void MyMemory(IN SIZE_T sSize)
{
// Allocate 100 bytes of memory.
    PVOID pAddress = malloc(100);
    
// Write data to the allocated memory. 
const char* cString = "0xmid00";
memcpy( pAddress, cString, strlen(cString) + 1 );

// Free the allocated memory. 
free(pAddress); 

    return pAddress;
}
```

**Example**

```c
// Allocate 100 bytes from the CRT heap, use it, then free.
PVOID pAddress = malloc(100);
if (pAddress == NULL)
    return 1;

const char* cString = "0xmid00";
memcpy(pAddress, cString, strlen(cString) + 1);

free(pAddress);
```

## HeapAlloc

Allocates a block of memory from a specified heap.

**Usage**

Call `HeapAlloc` with a heap handle, allocation flags, and the number of bytes to allocate.
-  `IN HANDLE hHeap`  A handle to the heap from which the memory is allocated.
- `IN DWORD dwFlags`  Allocation options that control how the memory is allocated.
- `IN SIZE_T dwBytes`  The number of bytes to allocate.
- `IN LPVOID pAddress` Pointer to the allocated memory.


**Return Value**
`LPVOID`   Returns the address of the allocated memory on success, or `NULL` if the allocation fails.

** External Files**
- `Windows.h` — `HeapAlloc()`, `GetProcessHeap()`, `HeapFree()`
- `string.h` — `memcpy()`, `strlen()`

### Code
```c
#include <Windows.h>
#include <string.h>

LPVOID MyMemory(IN SIZE_T dwBytes)
{
    // Get a handle to the current process heap.
    HANDLE hHeap = GetProcessHeap();

    // Allocate memory from the process heap.
    LPVOID pAddress = HeapAlloc(
        hHeap,
        HEAP_ZERO_MEMORY,
        dwBytes
    );

    if (pAddress == NULL)
        return NULL;

    // Write data to the allocated memory.
    const char* cString = "0xmid00";

    memcpy(
        pAddress,
        cString,
        strlen(cString) + 1
    );

    // Return the address of the allocated memory.
    return pAddress;
}

```

**Example**

```c
SIZE_T dwBytes = 100;

// Allocate dwBytes from the process heap, zero-initialised.
LPVOID pAddress = HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, dwBytes);
if (pAddress == NULL)
    return 1;

// ... use pAddress ...

HeapFree(GetProcessHeap(), 0, pAddress);
```

## VirtualAlloc

Reserves, commits, or changes the state of a region of pages in the virtual address space of the calling process.

**Usage**

Call `VirtualAlloc` with the desired address, allocation type, and memory protection.

- `LPVOID lpAddress` — The starting address of the region to allocate. Use `NULL` to let the system determine the address.
- `SIZE_T dwSize` — The size of the region to allocate, in bytes.
- `DWORD flAllocationType` — The type of memory allocation, such as `MEM_RESERVE` or `MEM_COMMIT`.
- `DWORD flProtect` — The memory protection for the allocated region, such as `PAGE_READWRITE`.

**Return Value**

`LPVOID` — Returns the base address of the allocated region on success, or `NULL` if the allocation fails.

**External Files**

- `Windows.h` — `VirtualAlloc()`, `VirtualFree()`
- `string.h` — `memcpy()`, `strlen()`

### Code

```c
#include <Windows.h>
#include <string.h>

LPVOID MyMemory(IN SIZE_T dwSize)
{
    // Allocate committed, read/write memory.
    LPVOID pAddress = VirtualAlloc(
        NULL,
        dwSize,
        MEM_COMMIT | MEM_RESERVE,
        PAGE_READWRITE
    );

    if (pAddress == NULL)
        return NULL;

    // Write data to the allocated memory.
    const char* cString = "0xmid00";

    memcpy(
        pAddress,
        cString,
        strlen(cString) + 1
    );
    
// Option 2: Fill the allocated memory with a byte value. 
    RtlFillMemory(pAddress, dwSize, 0x41);
    
    // Return the address of the allocated memory.
    return pAddress;
}
```

**Example**

```c
SIZE_T dwSize = 4096;

// Reserve + commit a RW page region; the OS picks the base address.
LPVOID pAddress = VirtualAlloc(NULL, dwSize, MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);
if (pAddress == NULL)
    return 1;

// ... use pAddress ...

VirtualFree(pAddress, 0, MEM_RELEASE);
```

## realloc

Reallocates a previously allocated memory block to a new size.

**Usage**

Call `realloc` with a pointer to an existing memory block and the new size.

- `OUT void *ptr`  A pointer to the memory block previously allocated by `malloc`, `calloc`, or `realloc`.
- `IN size_t size`  The new size of the memory block in bytes.

**Return Value**

`void *`  Returns the address of the resized memory block on success, or `NULL` if the reallocation fails. If `size` is zero and `ptr` is not `NULL`, the behavior is implementation-defined.

**External Files**

- `stdlib.h`  `realloc()`, `malloc()`, `free()`
- `string.h`  `memcpy()`, `strlen()`

### Code

```c
#include <stdlib.h>
#include <string.h>

void* MyMemory(IN size_t size)
{
    // the Allocate the initial memory block:  size_t size = 16;

    void *pAddress = malloc(size);

    if (pAddress == NULL)
        return NULL;

    // Write data to the allocated memory.
    const char *cString = "0xmid00";

    memcpy(
        pAddress,
        cString,
        strlen(cString) + 1
    );

    // Increase the size of the memory block.
    size = 32;

    void *pNewAddress = realloc(
        pAddress,
        size
    );

    if (pNewAddress == NULL)
    {
        // The original block is still valid if realloc() fails.
        free(pAddress);
        return NULL;
    }

    // realloc() may return a different address.
    pAddress = pNewAddress;

    // Write additional data to the resized memory.
    const char *cNewString = "0xmid00 example";

    memcpy(
        pAddress,
        cNewString,
        strlen(cNewString) + 1
    );
    // Return the address of the resized memory block.
    return pAddress;
}

```

**Example**

```c
void* pAddress = malloc(16);
if (pAddress == NULL)
    return 1;

// Grow the block to 32 bytes; realloc may move it, so reassign.
void* pNewAddress = realloc(pAddress, 32);
if (pNewAddress == NULL) {
    free(pAddress);   // The original block is still valid on failure.
    return 1;
}
pAddress = pNewAddress;

free(pAddress);
```
