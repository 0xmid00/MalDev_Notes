## Buffer Padding to Arbitrary Byte Boundary

Pads an input buffer to the nearest multiple of a caller-supplied block size by allocating a zeroed heap buffer, copying the original data into it, and returning the new buffer and its padded size. The function is general-purpose and works with any algorithm or operation that requires aligned input, such as AES (16 bytes), DES (8 bytes), or any custom boundary.

**Usage**

Call `PaddBuffer` with the input buffer and its size, the desired block size alignment, and two `OUT` pointers that receive the padded buffer address and its padded size. The padded buffer is heap-allocated by the function; the caller is responsible for freeing it with `HeapFree`.

- `IN PBYTE InputBuffer`  Base address of the buffer to pad.
- `IN SIZE_T InputBufferSize`  Size of `InputBuffer` in bytes.
- `IN SIZE_T BlockSize`  The byte boundary to align to (e.g. `16` for AES, `8` for DES). Must be greater than zero.
- `OUT PBYTE* OutputPaddedBuffer`  Receives the base address of the heap-allocated padded buffer.
- `OUT SIZE_T* OutputPaddedSize`  Receives the size of the padded buffer in bytes; always a multiple of `BlockSize`.

**Return Value**

`BOOL`  Returns `TRUE` if the padded buffer was successfully allocated and populated, otherwise `FALSE`.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `SIZE_T`, `IN`, `OUT`, `HeapAlloc()`, `GetProcessHeap()`, `ZeroMemory()`
- `string.h`  `memcpy()`


### Code

```c
#include <windows.h>
#include <string.h>


BOOL PaddBuffer(IN PBYTE InputBuffer, IN SIZE_T InputBufferSize, IN SIZE_T BlockSize, OUT PBYTE* OutputPaddedBuffer, OUT SIZE_T* OutputPaddedSize)
{
    PBYTE  PaddedBuffer = NULL;
    SIZE_T PaddedSize   = NULL;

    if (InputBuffer == NULL || InputBufferSize == 0 || BlockSize == 0)
        return FALSE;

    // If the buffer is already aligned to BlockSize, no padding is needed.
    if (InputBufferSize % BlockSize == 0) {
        *OutputPaddedBuffer = InputBuffer;
        *OutputPaddedSize   = InputBufferSize;
        return TRUE;
    }

    // Calculate the nearest size that is a multiple of BlockSize.
    PaddedSize = InputBufferSize + BlockSize - (InputBufferSize % BlockSize);

    // Allocate the padded buffer.
    PaddedBuffer = (PBYTE)HeapAlloc(
        GetProcessHeap(),   // Use the process default heap.
        0,                  // No flags; memory is not zeroed by default.
        PaddedSize          // Size rounded up to the next BlockSize boundary.
    );
    if (PaddedBuffer == NULL)
        return FALSE;

    // Zero the allocation so trailing padding bytes are clean.
    ZeroMemory(PaddedBuffer, PaddedSize);

    // Copy the original buffer into the padded allocation.
    memcpy(
        PaddedBuffer,       // Destination: the newly allocated padded buffer.
        InputBuffer,        // Source: the original input buffer.
        InputBufferSize     // Copy only the original data; trailing bytes remain zero.
    );

    *OutputPaddedBuffer = PaddedBuffer;
    *OutputPaddedSize   = PaddedSize;

    return TRUE;
}
```

**Example**

```c
unsigned char pInput[]      = { 0xFC, 0x48, 0x83, 0xE4, 0xF0 };  // 5 bytes
SIZE_T        sInputSize   = sizeof(pInput);
PBYTE         pPadded      = NULL;
SIZE_T        sPaddedSize  = 0;

// Pad the 5-byte buffer up to the next 16-byte boundary for AES.
PaddBuffer(pInput, sInputSize, 16, &pPadded, &sPaddedSize);

// sPaddedSize == 16; trailing bytes are zero.
printf("[+] Padded to %lld bytes\n", (LONGLONG)sPaddedSize);

HeapFree(GetProcessHeap(), 0, pPadded);
```
