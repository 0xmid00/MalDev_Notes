## Generate Random Byte Key

Generates a buffer of cryptographically seeded random bytes of a caller-specified size. Useful for producing keys, IVs, or any random byte sequence required before an encryption operation. The output buffer is heap-allocated by the function; the caller is responsible for freeing it with `HeapFree`.

**Usage**

Call `GenerateRandomKey` with the desired key size and an `OUT` pointer that receives the heap-allocated random byte buffer.

- `IN SIZE_T sKeySize`  Number of random bytes to generate.
- `OUT PBYTE* ppKeyBuffer`  Receives the base address of the heap-allocated random byte buffer.

**Return Value**

`BOOL`  Returns `TRUE` if the buffer was successfully allocated and filled, otherwise `FALSE`.

**External Files**

- `windows.h`  `PBYTE`, `BOOL`, `SIZE_T`, `IN`, `OUT`, `HeapAlloc()`, `GetProcessHeap()`
- `stdlib.h`  `srand()`, `rand()`
- `time.h`  `time()`

### Code

```c
#include <windows.h>
#include <stdlib.h>
#include <time.h>


BOOL GenerateRandomKey(IN SIZE_T sKeySize, OUT PBYTE* ppKeyBuffer)
{
    if (sKeySize == 0 || ppKeyBuffer == NULL)
        return FALSE;

    // Allocate the output buffer.
    PBYTE pKeyBuffer = (PBYTE)HeapAlloc(GetProcessHeap(), 0, sKeySize);
    if (pKeyBuffer == NULL)
        return FALSE;

    // Seed the RNG with the current time for initial randomness.
    srand((unsigned int)time(NULL));

    // Fill the buffer one byte at a time with random values.
    for (SIZE_T i = 0; i < sKeySize; i++) {
        pKeyBuffer[i] = (BYTE)(rand() % 0xFF);

        // Re-seed every byte using the previous byte to increase entropy.
        srand((unsigned int)time(NULL) ^ pKeyBuffer[i]);
    }

    *ppKeyBuffer = pKeyBuffer;

    return TRUE;
}
```

**Example Key Sizes**
```c
// AES256 key  → sKeySize = 32
// AES128 key  → sKeySize = 16
// AES IV      → sKeySize = 16
// RC4 key     → sKeySize = any (commonly 16 or 32)
```

**Example**

```c
PBYTE  pKeyBuffer = NULL;
SIZE_T sKeySize    = 32;  // 32 bytes for an AES256 key.

// Generate a random 32-byte key.
if (GenerateRandomKey(sKeySize, &pKeyBuffer)) {
    printf("[+] Generated key: ");
    for (SIZE_T i = 0; i < sKeySize; i++)
        printf("%02X ", pKeyBuffer[i]);
    printf("\n");

    HeapFree(GetProcessHeap(), 0, pKeyBuffer);  // Caller frees.
}
```
