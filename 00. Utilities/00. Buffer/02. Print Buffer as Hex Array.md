## Print Buffer as Hex Array

Prints an input buffer to the console as a formatted C-style `unsigned char` hex array, with 16 bytes per line. Useful for dumping keys, IVs, encrypted payloads, or any arbitrary byte buffer in a ready-to-copy C array format.

**Usage**

Call `PrintHexData` with a label string, the buffer to print, and its size.

- `IN LPCSTR Name`  Label string used as the array variable name in the printed output.
- `IN PBYTE Data`  Base address of the buffer to print.
- `IN SIZE_T Size`  Size of `Data` in bytes.

**Return Value**

`VOID`  This function does not return a value.

**External Files**

- `windows.h`  `PBYTE`, `LPCSTR`, `SIZE_T`, `IN`
- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


VOID PrintHexData(IN LPCSTR Name, IN PBYTE Data, IN SIZE_T Size)
{
    if (Name == NULL || Data == NULL || Size == 0)
        return;

    printf("unsigned char %s[] = {", Name);

    for (int i = 0; i < Size; i++) {

        // Start a new indented line every 16 bytes.
        if (i % 16 == 0)
            printf("\n\t");

        // Print each byte as a zero-padded two-digit hex value.
        // Omit the trailing comma on the last byte.
        if (i < Size - 1)
            printf("0x%0.2X, ", Data[i]);
        else
            printf("0x%0.2X ", Data[i]);
    }

    printf("};\n\n");
}
```

**Example**

```c
unsigned char pKey[]  = { 0x3E, 0x31, 0xF4 /* ... */ };
SIZE_T        sKeySize = sizeof(pKey);

// Dump the key as a copy-pasteable C array named "pKey".
PrintHexData("pKey", pKey, sKeySize);
```
