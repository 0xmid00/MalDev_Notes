## Print Buffer as Raw Hex

Prints an input buffer to the console as a plain sequence of space-separated hexadecimal bytes. Unlike array-formatted printing, this function produces no C syntax, no variable names, and no commas — only the raw hex values. Useful for quick visual inspection of keys, IVs, payloads, or any arbitrary byte buffer.

**Usage**

Call `PrintHexBytes` with the buffer to print and its size.

- `IN PBYTE Data`  Base address of the buffer to print.
- `IN SIZE_T Size`  Size of `Data` in bytes.

**Return Value**

`VOID`  This function does not return a value.

**External Files**

- `windows.h`  `PBYTE`, `SIZE_T`, `IN`
- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


VOID PrintHexBytes(IN PBYTE Data, IN SIZE_T Size)
{
    if (Data == NULL || Size == 0)
        return;

    for (SIZE_T i = 0; i < Size; i++) {

        // Print each byte as a zero-padded two-digit hex value.
        printf("%0.2X ", Data[i]);

        // Insert a newline every 16 bytes for readability.
        if ((i + 1) % 16 == 0)
            printf("\n");
    }

    // Ensure output ends on a new line.
    printf("\n");
}
```

**Example Output**
```
3E 31 F4 00 50 B6 6E B8 F6 98 95 27 43 27 C0 55
EB DB E1 7F 05 FE 65 6D 0F A6 5B 00 33 E6 D9 0B
```

**Example**

```c
unsigned char pKey[]  = { 0x3E, 0x31, 0xF4 /* ... */ };
SIZE_T        sKeySize = sizeof(pKey);

// Dump the key as a plain space-separated hex sequence (no C syntax).
PrintHexBytes(pKey, sKeySize);
```
