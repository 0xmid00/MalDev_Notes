## Read File from Disk

Reads the entire contents of a file from disk into a heap-allocated buffer. Opens the file with `CreateFileW`, retrieves its size with `GetFileSizeEx`, allocates a buffer with `HeapAlloc`, reads the content with `ReadFile`, and closes the handle. Returns the buffer base address and file size to the caller by reference.

**Usage**

Call `ReadFileFromDisk` with the full path to the target file, a pointer to receive the buffer address, and a pointer to receive the file size. On success, `*ppFileBuffer` holds the heap buffer containing the file's content and `*psFileSize` holds its size in bytes. The caller is responsible for freeing `*ppFileBuffer` with `HeapFree` after use.

- `IN LPCWSTR szFileName`  Wide-string full path to the file to read (e.g. `L"C:\\payloads\\calc.bin"`).
- `OUT PBYTE* ppFileBuffer`  Receives the base address of the heap buffer containing the file's content.
- `OUT SIZE_T* psFileSize`  Receives the size of the file in bytes.

**Return Value**

`BOOL`  Returns `TRUE` if the file was successfully read into the allocated buffer, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `HANDLE`, `PBYTE`, `DWORD`, `SIZE_T`, `LARGE_INTEGER`, `LPCWSTR`, `IN`, `OUT`, `CreateFileW()`, `GetFileSizeEx()`, `ReadFile()`, `CloseHandle()`, `HeapAlloc()`, `HeapFree()`, `GetProcessHeap()`, `GetLastError()`
- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL ReadFileFromDisk(IN LPCWSTR szFileName, OUT PBYTE* ppFileBuffer, OUT SIZE_T* psFileSize) {

    HANDLE          hFile           = INVALID_HANDLE_VALUE;
    LARGE_INTEGER   liFileSize      = { 0 };
    PBYTE           pFileBuffer     = NULL;
    DWORD           dwBytesRead     = 0;
    BOOL            bSTATE          = TRUE;

    // Open a read-only handle to the target file.
    hFile = CreateFileW(
        szFileName,         // Full path to the file to open.
        GENERIC_READ,       // Read access only.
        FILE_SHARE_READ,    // Allow other processes to read the file concurrently.
        NULL,               // Default security attributes.
        OPEN_EXISTING,      // Fail if the file does not already exist.
        FILE_ATTRIBUTE_NORMAL, // No special file attributes.
        NULL                // No template file.
    );
    if (hFile == INVALID_HANDLE_VALUE) {
        printf("[!] CreateFileW Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Retrieve the file size.
    if (!GetFileSizeEx(hFile, &liFileSize) || liFileSize.QuadPart == 0) {
        printf("[!] GetFileSizeEx Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Allocate a heap buffer large enough to hold the entire file.
    pFileBuffer = (PBYTE)HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, (SIZE_T)liFileSize.QuadPart);
    if (pFileBuffer == NULL) {
        printf("[!] HeapAlloc Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Read the entire file into the allocated buffer.
    if (!ReadFile(
        hFile,                          // Handle to the opened file.
        pFileBuffer,                    // Buffer to receive the file content.
        (DWORD)liFileSize.QuadPart,     // Number of bytes to read.
        &dwBytesRead,                   // Receives the number of bytes actually read.
        NULL                            // Synchronous I/O — no OVERLAPPED structure.
    ) || dwBytesRead != (DWORD)liFileSize.QuadPart) {
        printf("[!] ReadFile Failed With Error : %d \n", GetLastError());
        HeapFree(GetProcessHeap(), 0, pFileBuffer);
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Return the buffer and file size to the caller by reference.
    *ppFileBuffer   = pFileBuffer;
    *psFileSize     = (SIZE_T)liFileSize.QuadPart;

_EndOfFunction:
    if (hFile != INVALID_HANDLE_VALUE)
        CloseHandle(hFile);
    return bSTATE;
}
```

**Example**

```c
PBYTE  pFileBuffer = NULL;
SIZE_T sFileSize   = 0;

// Read C:\payloads\calc.bin into a heap buffer.
if (ReadFileFromDisk(L"C:\\payloads\\calc.bin", &pFileBuffer, &sFileSize)) {
    printf("[+] Read %lld bytes from disk\n", (LONGLONG)sFileSize);
}

// ... use pFileBuffer / sFileSize ...

if (pFileBuffer)
    HeapFree(GetProcessHeap(), 0, pFileBuffer);
```
