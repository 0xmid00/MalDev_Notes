## Write File to Disk

Writes a buffer to a file on disk. Creates or overwrites the target file with `CreateFileW`, writes the buffer content with `WriteFile`, and closes the handle. Returns `TRUE` on success.

**Usage**

Call `WriteFileToDisk` with the full path to the target file, the buffer to write, and its size in bytes. If the file already exists it will be overwritten.

- `IN LPCWSTR szFileName`  Wide-string full path to the file to write (e.g. `L"C:\\output\\result.bin"`).
- `IN PBYTE pFileBuffer`  Base address of the buffer whose content will be written to disk.
- `IN SIZE_T sFileSize`  Size of `pFileBuffer` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` if the file was successfully written to disk, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `HANDLE`, `PBYTE`, `DWORD`, `SIZE_T`, `LPCWSTR`, `IN`, `CreateFileW()`, `WriteFile()`, `CloseHandle()`, `GetLastError()`
- `stdio.h`  `printf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL WriteFileToDisk(IN LPCWSTR szFileName, IN PBYTE pFileBuffer, IN SIZE_T sFileSize) {

    HANDLE  hFile           = INVALID_HANDLE_VALUE;
    DWORD   dwBytesWritten  = 0;
    BOOL    bSTATE          = TRUE;

    // Create or overwrite the target file.
    hFile = CreateFileW(
        szFileName,             // Full path to the file to create or overwrite.
        GENERIC_WRITE,          // Write access only.
        0,                      // No sharing — exclusive access during the write.
        NULL,                   // Default security attributes.
        CREATE_ALWAYS,          // Create new file; overwrite if it already exists.
        FILE_ATTRIBUTE_NORMAL,  // No special file attributes.
        NULL                    // No template file.
    );
    if (hFile == INVALID_HANDLE_VALUE) {
        printf("[!] CreateFileW Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Write the buffer content to the file.
    if (!WriteFile(
        hFile,              // Handle to the opened file.
        pFileBuffer,        // Buffer containing the data to write.
        (DWORD)sFileSize,   // Number of bytes to write.
        &dwBytesWritten,    // Receives the number of bytes actually written.
        NULL                // Synchronous I/O — no OVERLAPPED structure.
    ) || dwBytesWritten != (DWORD)sFileSize) {
        printf("[!] WriteFile Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    printf("[+] Successfully Written %d Bytes To \"%ls\" \n", dwBytesWritten, szFileName);

_EndOfFunction:
    if (hFile != INVALID_HANDLE_VALUE)
        CloseHandle(hFile);
    return bSTATE;
}
```
