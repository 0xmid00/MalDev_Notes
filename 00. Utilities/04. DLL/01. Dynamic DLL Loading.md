## Dynamic DLL Loading and Function Resolution

> Loads a DLL at runtime, retrieves an exported function address, and invokes the function through a function pointer.

**Usage**

Call `LoadLibraryA` to load the DLL, `GetProcAddress` to retrieve the exported function address, and cast the address to the appropriate function pointer type before invocation.

- `IN LPCSTR lpLibFileName`  The name or path of the DLL to load.
- `IN HMODULE hModule`  A handle to the loaded DLL.
- `IN LPCSTR lpProcName`  The name of the exported function to retrieve.
- `OUT FARPROC`  The address of the exported function.

**Return Value**

`HMODULE`  Returns a handle to the loaded DLL on success, or `NULL` if `LoadLibraryA` fails.

`FARPROC`  Returns the address of the exported function on success, or `NULL` if the function cannot be found.

**External Files**

- `Windows.h`  `LoadLibraryA()`, `GetProcAddress()`, `FreeLibrary()`


### Code

```c
#include <Windows.h>

typedef int (WINAPI* fnMessageBoxA)(
    HWND   hWnd,
    LPCSTR lpText,
    LPCSTR lpCaption,
    UINT   uType
);

int MyFunction(void)
{
    // Load the DLL into the current process.
    HMODULE hModule = LoadLibraryA("user32.dll");

    if (hModule == NULL)
        return 1;

    // Retrieve the address of the exported function.
    FARPROC pMessageBoxA = GetProcAddress(
        hModule,
        "MessageBoxA"
    );

    if (pMessageBoxA == NULL)
    {
        FreeLibrary(hModule);
        return 1;
    }

    // Cast the function address to the appropriate function pointer type.
    fnMessageBoxA MessageBoxA = (fnMessageBoxA)pMessageBoxA;

    // Invoke the dynamically resolved function.
    MessageBoxA(
        NULL,
        "0xmid00",
        "Dynamic Linking",
        MB_OK
    );

    // Unload the DLL.
    FreeLibrary(hModule);

    return 0;
}
````

**Example**

```c
// Load user32.dll at runtime, resolve MessageBoxA by name, and call it
// through a typed function pointer — no compile-time linkage required.
MyFunction();
```
