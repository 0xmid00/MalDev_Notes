## Write To Remote Process Memory

Writes a caller-supplied buffer into a remote process at a specified address using `WriteProcessMemory` and verifies that all bytes were written. Used as a helper when patching structures inside a suspended process such as overwriting `CommandLine.Buffer` in `RTL_USER_PROCESS_PARAMETERS`.

**Usage**

Call `WriteToTargetProcess` with a handle to the remote process, the remote address to write to, the source buffer, and its size in bytes.

- `IN HANDLE hProcess`  A `PROCESS_ALL_ACCESS` handle to the remote process to write into.
- `IN PVOID pAddressToWriteTo`  Remote address to overwrite (e.g. `pParms->CommandLine.Buffer`).
- `IN PVOID pBuffer`  Source buffer whose contents will be written to the remote process.
- `IN DWORD dwBufferSize`  Number of bytes to write from `pBuffer`.

**Return Value**

`BOOL`  Returns `TRUE` if all `dwBufferSize` bytes were written successfully, otherwise `FALSE`.

**External Files**

- `windows.h`  `HANDLE`, `PVOID`, `BOOL`, `DWORD`, `SIZE_T`, `IN`, `WriteProcessMemory()`, `GetLastError()`
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL WriteToTargetProcess(IN HANDLE hProcess, IN PVOID pAddressToWriteTo, IN PVOID pBuffer, IN DWORD dwBufferSize)
{
    SIZE_T sNmbrOfBytesWritten = NULL;

    if (!WriteProcessMemory(
        hProcess,               // Handle to the remote process.
        pAddressToWriteTo,      // Remote address to overwrite (e.g. CommandLine.Buffer).
        pBuffer,                // Source buffer to write into the remote process.
        dwBufferSize,           // Number of bytes to write.
        &sNmbrOfBytesWritten    // Receives the number of bytes actually written.
    ) || sNmbrOfBytesWritten != dwBufferSize) {
        printf("[!] WriteProcessMemory Failed With Error : %d \n", GetLastError());
        printf("[i] Bytes Written : %d Of %d \n", sNmbrOfBytesWritten, dwBufferSize);
        return FALSE;
    }

    return TRUE;
}
```
