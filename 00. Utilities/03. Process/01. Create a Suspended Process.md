## Create a Suspended  Process 

Creates a new process in a fully suspended state using `CreateProcessA` with the `CREATE_SUSPENDED` flag. Resolves the full binary path by reading the `WINDIR` environment variable with `GetEnvironmentVariableA` and appending `System32\<lpProcessName>`. Returns the process ID, process handle, and main thread handle to the caller by reference. The main thread ID is returned optionally , pass `NULL` to skip it. All threads in the created process start suspended, making them available for hijacking without calling `CreateRemoteThread`.

**Usage**

Call `CreateSuspendedProcess` with the target binary name and the required output pointers. Pass `NULL` for `dwThreadId` if the thread ID is not needed. On success, `*hThread` holds the suspended main thread handle ready to be passed to `HijackThread`. The caller is responsible for closing `*hProcess` and `*hThread` with `CloseHandle` after use.

- `IN LPCSTR lpProcessName`  Name of the binary to create under `System32` (e.g. `"notepad.exe"`).
- `OUT DWORD* dwProcessId`  Receives the PID of the newly created process.
- `OUT HANDLE* hProcess`  Receives the handle to the newly created process.
- `OUT HANDLE* hThread`  Receives the handle to the suspended main thread of the newly created process.
- `OUT DWORD* dwThreadId`  Receives the main thread ID of the newly created process. Pass `NULL` to skip.

**Return Value**

`BOOL`  Returns `TRUE` if the process was successfully created and all required output handles were populated, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `CHAR`, `DWORD`, `HANDLE`, `LPCSTR`, `MAX_PATH`, `STARTUPINFOA`, `PROCESS_INFORMATION`, `IN`, `OUT`, `CreateProcessA()`, `GetEnvironmentVariableA()`, `RtlSecureZeroMemory()`, `GetLastError()`
- `stdio.h`  `printf()`, `sprintf()`


### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL CreateSuspendedProcess(IN LPCSTR lpProcessName, OUT DWORD* dwProcessId, OUT HANDLE* hProcess, OUT HANDLE* hThread, OUT DWORD* dwThreadId) {

    CHAR                lpPath  [MAX_PATH * 2];
    CHAR                WnDr    [MAX_PATH];

    STARTUPINFOA        Si      = { 0 };
    PROCESS_INFORMATION Pi      = { 0 };

    // Zero out both structures before use.
    RtlSecureZeroMemory(&Si, sizeof(STARTUPINFOA));
    RtlSecureZeroMemory(&Pi, sizeof(PROCESS_INFORMATION));

    // cb must be set to the size of the STARTUPINFO structure.
    Si.cb = sizeof(STARTUPINFOA);

    // Resolve the Windows installation directory from the WINDIR environment variable.
    if (!GetEnvironmentVariableA("WINDIR", WnDr, MAX_PATH)) {
        printf("[!] GetEnvironmentVariableA Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Build the full path to the target binary under System32.
    sprintf(lpPath, "%s\\System32\\%s", WnDr, lpProcessName);
    printf("\n\t[i] Running : \"%s\" ... ", lpPath);

    // Create the process in a suspended state so all its threads start suspended.
    if (!CreateProcessA(
        NULL,               // No separate module name; path is in lpCommandLine.
        lpPath,             // Full path to the binary to create.
        NULL,               // Process handle not inheritable.
        NULL,               // Thread handle not inheritable.
        FALSE,              // Do not inherit handles from the calling process.
        CREATE_SUSPENDED,   // Create all threads in a suspended state.
        NULL,               // Inherit parent's environment block.
        NULL,               // Inherit parent's current directory.
        &Si,                // Pointer to the STARTUPINFO structure.
        &Pi                 // Receives process and thread handles and IDs.
    )) {
        printf("[!] CreateProcessA Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("[+] DONE \n");

    // Return the process ID and handles to the caller by reference.
    *dwProcessId    = Pi.dwProcessId;
    *hProcess       = Pi.hProcess;
    *hThread        = Pi.hThread;

    // Populate the thread ID only if the caller supplied a non-NULL pointer.
    if (dwThreadId != NULL)
        *dwThreadId = Pi.dwThreadId;

    if (*dwProcessId != NULL && *hProcess != NULL && *hThread != NULL)
        return TRUE;

    return FALSE;
}
```

**Example**

```c
DWORD  dwProcessId = 0;
HANDLE hProcess    = NULL,
       hThread     = NULL;
DWORD  dwThreadId  = 0;

// Spawn notepad.exe under System32 with its main thread suspended.
// Pass NULL as the final argument if the thread ID is not needed.
CreateSuspendedProcess("notepad.exe", &dwProcessId, &hProcess, &hThread, &dwThreadId);

// ... inject payload via InjectShellcodeToRemoteProcess, then HijackThread(hThread, pAddress) ...

CloseHandle(hProcess);
CloseHandle(hThread);
```
