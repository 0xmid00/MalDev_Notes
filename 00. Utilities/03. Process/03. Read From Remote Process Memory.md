## Read From Remote Process Memory

Allocates a zeroed heap buffer and reads a specified number of bytes from a remote process into it using `ReadProcessMemory`. The caller receives the base address of the heap-allocated buffer via `ppReadBuffer`. Used as a helper when reading structures such as `PEB` or `RTL_USER_PROCESS_PARAMETERS` from a suspended process.

**Usage**

Call `ReadFromTargetProcess` with a handle to the remote process, the address to read from, an `OUT` pointer to receive the allocated buffer, and the number of bytes to read. The caller is responsible for freeing the buffer with `HeapFree`.

- `IN HANDLE hProcess`  A `PROCESS_ALL_ACCESS` handle to the remote process to read from.
- `IN PVOID pAddress`  Remote address to begin reading from (e.g. `PBI.PebBaseAddress`).
- `OUT PVOID* ppReadBuffer`  Receives the base address of the heap-allocated buffer holding the read data.
- `IN DWORD dwBufferSize`  Number of bytes to read from `pAddress`.

**Return Value**

`BOOL`  Returns `TRUE` if all `dwBufferSize` bytes were read successfully, otherwise `FALSE`.

**External Files**

- `windows.h`  `HANDLE`, `PVOID`, `BOOL`, `DWORD`, `SIZE_T`, `IN`, `OUT`, `ReadProcessMemory()`, `HeapAlloc()`, `GetProcessHeap()`, `GetLastError()`
- `stdio.h`  `printf()`

### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL ReadFromTargetProcess(IN HANDLE hProcess, IN PVOID pAddress, OUT PVOID* ppReadBuffer, IN DWORD dwBufferSize)
{
    SIZE_T sNmbrOfBytesRead = NULL;

    // Allocate a zeroed heap buffer to receive the remote process data.
    *ppReadBuffer = HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, dwBufferSize);

    if (!ReadProcessMemory(
        hProcess,           // Handle to the remote process.
        pAddress,           // Remote address to read from (e.g. PEB base address).
        *ppReadBuffer,      // Local destination buffer.
        dwBufferSize,       // Number of bytes to read.
        &sNmbrOfBytesRead   // Receives the number of bytes actually read.
    ) || sNmbrOfBytesRead != dwBufferSize) {
        printf("[!] ReadProcessMemory Failed With Error : %d \n", GetLastError());
        printf("[i] Bytes Read : %d Of %d \n", sNmbrOfBytesRead, dwBufferSize);
        return FALSE;
    }

    return TRUE;
}
```
