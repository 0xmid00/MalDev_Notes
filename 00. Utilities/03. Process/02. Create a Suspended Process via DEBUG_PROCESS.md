## Create a Suspended Process via DEBUG_PROCESS

Creates a new process under the debugger using `CreateProcessA` with the `DEBUG_PROCESS` flag instead of `CREATE_SUSPENDED`. The `DEBUG_PROCESS` flag causes the OS to treat the calling process as a debugger, automatically suspending all threads of the newly created process until the debugger continues them. Resolves the full binary path by reading the `WINDIR` environment variable and appending `System32\<lpProcessName>`. Returns the process ID, process handle, and main thread handle to the caller by reference.

**Usage**

Call `CreateSuspendedProcess2` with the target binary name and three output pointers. On success `*hThread` holds the suspended main thread handle. The caller is responsible for closing `*hProcess` and `*hThread` with `CloseHandle` after use.

- `IN LPCSTR lpProcessName`  Name of the binary to create under `System32` (e.g. `"notepad.exe"`).
- `OUT DWORD* dwProcessId`  Receives the PID of the newly created process.
- `OUT HANDLE* hProcess`  Receives the handle to the newly created process.
- `OUT HANDLE* hThread`  Receives the handle to the suspended main thread of the newly created process.

**Return Value**

`BOOL`  Returns `TRUE` if the process was successfully created and all output handles were populated, otherwise `FALSE`.

### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL CreateSuspendedProcess2(IN LPCSTR lpProcessName, OUT DWORD* dwProcessId, OUT HANDLE* hProcess, OUT HANDLE* hThread) {

    CHAR                lpPath  [MAX_PATH * 2];
    CHAR                WnDr    [MAX_PATH];

    STARTUPINFOA        Si      = { 0 };
    PROCESS_INFORMATION Pi      = { 0 };

    // Zero out both structures before use.
    RtlSecureZeroMemory(&Si, sizeof(STARTUPINFOA));
    RtlSecureZeroMemory(&Pi, sizeof(PROCESS_INFORMATION));

    // cb must be set to the size of the STARTUPINFO structure.
    Si.cb = sizeof(STARTUPINFOA);

    // Resolve the Windows installation directory from the WINDIR environment variable.
    if (!GetEnvironmentVariableA("WINDIR", WnDr, MAX_PATH)) {
        printf("[!] GetEnvironmentVariableA Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    // Build the full path to the target binary under System32.
    sprintf(lpPath, "%s\\System32\\%s", WnDr, lpProcessName);
    printf("\n\t[i] Running : \"%s\" ... ", lpPath);

    // Create the process under the debugger.
    // DEBUG_PROCESS suspends all threads of the child process until
    // the debugger (this process) calls ContinueDebugEvent or detaches.
    if (!CreateProcessA(
        NULL,           // No separate module name; path is in lpCommandLine.
        lpPath,         // Full path to the binary to create.
        NULL,           // Process handle not inheritable.
        NULL,           // Thread handle not inheritable.
        FALSE,          // Do not inherit handles from the calling process.
        DEBUG_PROCESS,  // Treat calling process as debugger; suspends child threads automatically.
        NULL,           // Inherit parent's environment block.
        NULL,           // Inherit parent's current directory.
        &Si,            // Pointer to the STARTUPINFO structure.
        &Pi             // Receives process and thread handles and IDs.
    )) {
        printf("[!] CreateProcessA Failed With Error : %d \n", GetLastError());
        return FALSE;
    }

    printf("[+] DONE \n");

    // Return the process ID and handles to the caller by reference.
    *dwProcessId    = Pi.dwProcessId;
    *hProcess       = Pi.hProcess;
    *hThread        = Pi.hThread;

    if (*dwProcessId != NULL && *hProcess != NULL && *hThread != NULL)
        return TRUE;

    return FALSE;
}
```

**Example**

```c
DWORD  dwProcessId = 0;
HANDLE  hProcess    = NULL,
        hThread     = NULL;

// Spawn notepad.exe under System32 with the OS treating us as its debugger —
// all child threads start suspended and stay that way until we detach/continue.
CreateSuspendedProcess2("notepad.exe", &dwProcessId, &hProcess, &hThread);

// ... inject payload + queue EarlyBird APC, then DebugSetProcessKillOnExit(hProcess, FALSE) to detach ...

CloseHandle(hProcess);
CloseHandle(hThread);
```
