# Payload Placement in `.rsrc` Section

> Stores binary data as an `RCDATA` resource inside a Windows executable, retrieves the resource at runtime, and copies it into a writable buffer when the data needs to be modified.

## Resource Extraction and Buffer Copy

Retrieves an `RCDATA` resource using its resource identifier, obtains its address and size, then copies the resource data into a writable heap buffer.

**Usage**

Call `ExtractResource` with the module containing the resource and its resource identifier.

- `IN HMODULE hModule`  Handle to the module containing the resource. Use `NULL` for the current executable.
- `IN LPCWSTR lpName`  Identifier of the `RCDATA` resource, such as `IDR_RCDATA1`.

**Return Value**

`PVOID`  Returns the address of a writable buffer containing a copy of the resource data, or `NULL` if the operation fails.

**External Files**

- `Windows.h`  `FindResourceW()`, `LoadResource()`, `LockResource()`, `SizeofResource()`, `HeapAlloc()`, `HeapFree()`
- `resource.h`  Resource identifiers such as `IDR_RCDATA1`
- `string.h`  `memcpy()`

### Guided Setup

1. In Visual Studio, right-click **Resource Files** and select **Add > New Item**.
2. Select **Resource File** to create the `.rc` file.
3. Open **Resource View**, right-click the `.rc` file, and select **Add Resource**.
4. Select **Import** and choose the binary file.
5. When Visual Studio asks for the resource type, enter `RCDATA`.
6. The binary data is added to the `.rsrc` section when the project is compiled.
7. Visual Studio generates `resource.h`, which contains the resource identifier, such as `IDR_RCDATA1`.
8. Include `resource.h` in the source file to reference the resource.

### Code

```c
#include <Windows.h>
#include <string.h>
#include "resource.h"

PVOID ExtractResource(
    IN HMODULE hModule,
    IN LPCWSTR lpName
)
{
    HRSRC   hRsrc     = NULL;
    HGLOBAL hGlobal   = NULL;
    PVOID   pResource = NULL;
    PVOID   pBuffer   = NULL;
    DWORD   dwSize    = 0;

    // Locate the resource.
    hRsrc = FindResourceW(
        hModule,       // Module containing the resource. NULL = current executable.
        lpName,        // Resource identifier, such as IDR_RCDATA1.
        RT_RCDATA      // Resource type containing arbitrary binary data.
    );

    if (hRsrc == NULL)
        return NULL;

    // Load the resource.
    hGlobal = LoadResource(
        hModule,       // Module containing the resource.
        hRsrc          // Handle returned by FindResourceW.
    );

    if (hGlobal == NULL)
        return NULL;

    // Obtain a pointer to the resource data.
    // The returned resource memory should be treated as read-only.
    pResource = LockResource(
        hGlobal         // Handle returned by LoadResource.
    );

    if (pResource == NULL)
        return NULL;

    // Obtain the size of the resource.
    dwSize = SizeofResource(
        hModule,        // Module containing the resource.
        hRsrc           // Handle returned by FindResourceW.
    );

    if (dwSize == 0)
        return NULL;

    // Allocate writable memory for a copy of the resource.
    pBuffer = HeapAlloc(
        GetProcessHeap(), // Retrieve the current process heap.
        0,                 // No special allocation flags.
        dwSize             // Number of bytes to allocate.
    );

    if (pBuffer == NULL)
        return NULL;

    // Copy the read-only resource into the writable buffer.
    memcpy(
        pBuffer,        // Destination buffer.
        pResource,      // Source resource data.
        dwSize          // Number of bytes to copy.
    );

    return pBuffer;
}

int main(void)
{
    PVOID pBuffer = NULL;

    // Extract the RCDATA resource and create a writable copy.
    pBuffer = ExtractResource(
        NULL,                               // Current executable.
        MAKEINTRESOURCEW(IDR_RCDATA1)      // Resource identifier.
    );

    if (pBuffer == NULL)
        return 1;

    // pBuffer now contains a writable copy of the resource data.

    // Use or modify the buffer here.

    // Release the allocated buffer when it is no longer needed.
    HeapFree(
        GetProcessHeap(),  // Current process heap.
        0,                 // No special free flags.
        pBuffer            // Buffer returned by ExtractResource().
    );

    return 0;
}
```

**Example**

```c
PVOID pPayload = NULL;

// Extract the RCDATA resource into a writable heap buffer.
pPayload = ExtractResource(NULL, MAKEINTRESOURCEW(IDR_RCDATA1));
if (pPayload == NULL)
    return 1;

// pPayload now holds a writable copy of the embedded resource.
// Hand it off to whichever execution primitive the operator chose.

// Free the writable buffer when the payload is no longer needed.
HeapFree(GetProcessHeap(), 0, pPayload);
```
